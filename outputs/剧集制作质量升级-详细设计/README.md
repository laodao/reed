## 6. subagent 通用执行须知（各任务文档"执行须知"段的公共部分）

1. **必读顺序**：本任务文档全文 → `00-共享约定与工程规范.md`。
2. **范围白名单**：只允许改动任务文档"代码改动清单"列出的文件及其配套测试文件；需要触碰白名单外文件时，停下并在报告中说明理由，等待协调者批准。
3. **DoD（完成的定义）**：白名单内代码完成 + 新增单测全绿 + `npm run typecheck`、`npm run lint` 通过 + 现有 `tests/e2e/web/10-episode-production.spec.ts`、`16-episode-production-mp4-e2e.spec.ts` 不回归 + 任务文档全部 AC 逐条自验通过。**W0 修正**：全量 `test:unit` 按豁免基线执行（`wave0-基线失败清单.md`：failed 文件 ≤89 且用例 ≤122，无基线外新失败文件，新增测试必须全绿）。
4. **报告格式**：① 改动文件清单（新增/修改分开）；② 测试执行结果摘要（命令+通过/失败数）；③ 与设计的偏离点及理由；④ 遗留问题与建议。
5. **禁止事项**：不修改 `gen-task-registry` 契约（除非任务就是 T00）；不改既有 IPC channel 语义；不做设计外的"顺手重构"。
