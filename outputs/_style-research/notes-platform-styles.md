# 其他体裁风格笔记 C：知乎体 / 小红书清单体 / 口播脚本 / 干货教程（综合二手调研）

## C1 知乎高赞回答体
- **结构**：3秒开头钩子（悬念/痛点暴击/反常识）→ 痛点共鸣分析 → 结构化解决方案（分点分层）→ 金句/升华结尾
- **三幕节奏**："痛点暴击 → 原理拆解 → 动作模板"，制造"原来如此→确实如此→马上试试"的心理推进
- **身份感开场**："作为一个从0做到5w粉的人……""先说结论"——资历背书/结论先行是标配
- **爆款拆解公式**（搬运研究者总结）：标题吸引力 + 开头悬念钩子 + 故事结构；跨回答组合"A的故事+B的观点+C的金句"
- 语气：口语化、说理带例子、敢自曝经历（真实感=赞数）
- 长答案结构类似"个人色彩浓厚的干货文"；故事型回答则接近盐选小说（冲突前置、转折密集）

## C2 小红书清单体/种草体
- **标题五公式**：数字+结果（"7天/10个/3步"）；身份+痛点（打工人/宝妈/学生党）；反常识悬念（"别再XX"）；效果+人群（"去黄皮太狠了"）；细分人群+数字+解决方案
- **正文骨架**：痛点场景共鸣 → 清单体展开（emoji 分点，每点"方法+理由"）→ 亲测结果 → 互动引导（评论区问句）
- **300 字定律**：短文案靠"标题设计+叙事结构+情绪钩子+金句引爆"四件套
- 语气：闺蜜感/亲历感，第一人称，多感叹号但克制炫耀；"姐妹们""亲测""码住"
- 封面图与标题构成点击双因子（文案要给封面留视觉钩子）

## C3 短视频口播脚本
- **黄金 3 秒开头公式**：提问式 / 反常识 / 结果前置 / 痛点直击 / 悬念开场
- **三段结构**：黄金3秒钩子 → 核心干货层层递进（每 5-10 秒一个信息点/反转）→ 结尾互动引导（评论/关注/争议话题）
- **钩子手法**：反转、悬念、彩蛋（为完播率服务）；节奏紧凑无废话
- 口语化短句、每句独立成气口、避免长从句；"注意看""接下来这一幕"式引导语
- 算法适配：前 5 秒完播率决定分发——开头即高潮，不铺垫

## C4 干货教程/知识分享文
- **SCQA**：情景（共识场景）→ 冲突（核心矛盾）→ 疑问（读者心里的 why）→ 回答（方案）——适合问题引入式干货
- **金字塔原理**：结论先行 → MECE 分层关键理由 → 论据支撑——适合教程/方法论
- **黄金圈 Why-How-What**：先讲为什么（动机/意义）→ 怎么做 → 是什么——适合理念型内容
- 通用要素：痛点场景开场 → 分步/分点（每点带例子）→ 常见误区 → 行动清单 → 总结金句
- 与"清单体"区别：干货文重逻辑纵深，清单体重扫读效率

## 情感文补充（来自搜索总结，结合 C 类印证）
- 结构：故事引入 → 情绪共鸣 → 观点/案例支撑 → 金句升华
- 开头 3 行决定完读率：冲突场景/悬念提问/金句开场
- 选题锚点：婚姻、亲子、职场、原生家庭——大众情感痛点
- 标题：情绪词+反差/悬念
