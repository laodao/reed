# 其他体裁风格笔记 D：情感/成长"深度好文"体（洞见系样本《人到中年：低配生活，高配灵魂》一手精读）

## 核心风格："问答+故事排比+金句"的共鸣机器
- 标题：人生阶段+对仗口号（"低配生活，高配灵魂"）+（深度好文）后缀信任状；"第 N 篇深度好文"编号体系制造连载感
- 开头固定动作：知乎/后台热门问题引入（"人到中年，最大的感慨是什么？"）+ 高赞回答引用——UGC 开场天然共鸣

## 结构骨架
1. 热门问题 + 高赞回答开场（引出主题词：中年/独处/圈子）
2. 主体分 3-4 个小节，每节一个分论点（低配社交/低配物质/高配灵魂式对仗结构），小节含"深度好文"体标配小标题
3. 每节内部：名人故事（杨绛/莫言/苏轼）+ 身边素人故事（朋友/同学/亲戚）交替举证 → 提炼道理
4. 金句独立成段，高频出现（几乎每两三节一句加粗短句）
5. 结尾：点题升华 + "点个在看"式互动引导 + 祝愿式收尾（"愿你我都能……"）

## 招牌手法
- **对仗口号式概念**：低配/高配、断舍离、向内求——二元对立结构便于记忆传播
- **名人典故库**：杨绛、莫言、苏轼、季羡林——文化名人为道理背书（真实性让位于共鸣性）
- **素人故事贴地**：表哥、老同学、邻居——读者身边人替代感
- **"故事+道理"单元**：每节至少 2 个故事 1 个道理，道理永远在故事后
- **金句短段加粗**：转发截图的原料，密度全体裁最高
- 语气：温和说教、第二人称"你"高频、祝愿式收尾
- 与卢克文对比：零数据、零宏大叙事、零梗；全靠共鸣与典故；情绪基调暖而非燃

## 可复用模板
热门问题开场 → 对仗式分论点小节 →（名人故事+素人故事→道理）×N → 金句穿插 → 祝愿式收尾+互动引导
