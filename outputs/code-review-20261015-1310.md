**M1. 挂起审批卡跨域丢失且失去解锁入口**（d9f2a623）— `EpAgentPanel.vue:257` + `useEpAgentChat.ts:93,225`。`EpisodeStudio` 用 `:key="agentScope"` 换域即重挂载，`pendingChoice` 归零——agent 发出选择卡后用户切 tab，卡消失；后端 `listPendingChoices` 已支持按 scope 查询但**前端挂载时未调用恢复**。同时挂起轮次的 busy 键仍被持有，回原域再发消息报"上一轮仍在处理中"，而取消按钮因重挂载后 sending=false **不渲染——无 UI 解锁路径**（须换剧集或重启）。基点时面板不重挂载无此问题（行为回退）。建议：挂载时恢复 pendingChoice；取消按钮条件增加"同域存在挂起轮次"。

**M2. extractChapterEvents 空数组报失败——过渡章永久重跑烧 token**（f46fb7ff）— `longwriting-ai.service.ts:3879-3883`。成功判定 `arr.length > 0`：模型对极短过渡章返回 `{"items":[]}` 时记 `failedSteps('事件提取')`——**每次保存触发重跑烧 token**且文案误导；同提交另四个提取方法都把空数组当合法成功（关系演变处还专门注释），五个方法口径分裂。建议：空数组与解析失败区分。
