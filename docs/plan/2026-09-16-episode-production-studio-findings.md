## S-01 无"阶段就绪"状态机（优先级最高）

四个 tab（剧本/资产/分镜/合成）平铺且互不检查前置：剧本未定稿可拆分镜、资产未定妆可出关键帧、无关键帧可点视频（静默落 text2video）。一致性事故的每一环静默降级皆源于此。当日修复（D4-3 绑定守卫、superseded 生命周期）只是点状堵漏。

**建议**：统一的就绪状态机——每 tab 显示就绪/未就绪 + 缺什么 + 跳转入口；未就绪时阻断或显式确认降级。

## S-02 关键帧黑盒（优先级最高）

参考图模式的命脉是关键帧，但 Studio 无关键帧画廊：每镜首尾帧长什么样、用了哪张定妆图做参考，用户不可见，只能等视频出来。一致性核验只能靠查库/翻日志。

**建议**：分镜编辑器内嵌每镜首尾帧缩略图 + 换图/重生入口 + 参考图来源标注。

## S-03 分段不可控

多镜合一段只能按时间预算自动切（重新分段），不能手动指定分镜分组。分段直接决定 H3 prompt 结构与生成成本。

**建议**：分镜列表支持手动合并/拆分段落。

## S-04 制作助手能力断层

- 只能做到分镜/资产图，视频生成与合成导出不可达（须手动点）；
- maxCalls=1 单轮上限，建 3 个资产要三轮对话；
- 无当前 tab/项目状态感知；
- H11 核验只防谎报，弱模型理解力仍是瓶颈。

**建议**：补齐视频/导出动作（注意：`8a70bf6e` 提交已在旧链路加过后半程四工具，Studio agent 面板需对齐）；取消或放宽单轮上限；注入当前 tab 与项目状态快照。

## S-05 资产 tab 缺质量卡点和影响面提示

- 定妆图无"确认后才被引用"闸门（cogen spec D7 明确不做，阿蘅现代装事故证明坏图会无声流入下游）；
- 删除/重建资产不提示影响面（被多少关键帧/视频引用），无"重建定妆图→级联重生关键帧"选项。

## S-06 剧本 tab 只有整集覆盖式重拆

改一处对白/描述只能整集「重新拆分」（连带下游分镜/关键帧/视频全部作废）。本次为修对话说话人整集拆了三遍。

**建议**：场景级局部编辑 + 局部重生下游（只作废该场景的分镜/片段）。

## S-07 合成 tab 只读装配

时间线不可拖拽排序/修剪；配音按场景逐个生成（无"全部生成"）；导出无版本管理（每次覆盖，旧版无留档）。

## S-08 无自检/评估环节

系统产出后不做任何质检（人物一致性、剧本匹配度全靠用户肉眼）。

**建议**：低成本自检起步——关键帧与定妆图相似度、字幕与剧本对白覆盖率、片段时长与分镜偏差。

## S-09 成本与耗时不可见

turbo（约 4 分钟/段）vs 高质量（约 35 分钟/段）、百炼额度消耗，全程无展示无累计。

**建议**：生成前预估 + 项目级累计耗时/额度面板。
