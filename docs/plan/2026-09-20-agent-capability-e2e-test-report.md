## 观察到的纪律落地（对照系统提示词条目）

- 「先查目录再动手」：4 轮全部先调 discover_capabilities（①×1、③×2+技能、④×3）。
- 「绝不虚构」：③引用的工作流名称/版本与 `workflow_definitions` 表逐条吻合。
- 「缺参先问清、不编造」：③④都在执行前提出参数确认清单。
- 「工具失败如实转述、换路重试」：②web_search 失败后明确告知并改用网页抓取直连工具完成。
- 「UI 能力不冒充」：①引导去研讨室；④明说 cron 调度无法代办。

## 过程中的环境问题（非被测缺陷）

1. 首次轮次报 `AGENT_PROVIDER_NOT_CONFIGURED`：custom-model 模板有「空密钥挡板」，DB 直播 NULL key 的提供商被跳过——经设置 UI 写入 key 后恢复（挡板行为正确）。
