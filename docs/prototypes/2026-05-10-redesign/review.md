# 原型 v3 自审 review

> 审视维度：① 提高生成效果 ② 简化使用流程 ③ 逻辑清晰
> 检查范围：`index.html`（7 stage 主流程）+ `flows.html`（4 种创建方式）

---

## A. 字段重复 / 冲突（必修）

### A1 · 时长字段三处出现，无强约束

| 位置 | 字段 | 含义 |
|---|---|---|
| ① 立项 | 整体时长「60s」| 项目目标时长 |
| ④ 分镜 | 时长「4s」| 单分镜时长 |
| ⑥ 视频 | 时长（来自 ④ readonly）| 同 ④ |
| ⑦ 合成 | 时间线总长 | = ∑各分镜时长 |

**问题**：① 选 60s，但 ④ 各分镜手填加起来 75s，没人提醒。

**改**：
- ① 立项「整体时长」改名「**目标时长（预算）**」，仅 AI 拆分镜时作上限提示
- ⑦ 合成顶部显示「实际时长 47s / 目标 60s」对比条，超额 / 不足时用色块警示
- 不强制对齐 — 给用户决定权

### A2 · 画幅 / 分辨率 / 帧率 散在 ① 立项 + ⑦ 导出预设

**问题**：① 选了 16:9，⑦ 选「抖音 9:16 预设」会自动改吗？

**改**：
- ① 立项「画幅 + 分辨率 + 帧率」合并为单卡「输出规格」
- ⑦ 导出预设默认**继承** ①；切换平台时弹"是否更新项目规格"询问框
- 不允许 ① 与 ⑦ 同时存活两份不同值

### A3 · 「风格」三层散落

| 位置 | 字段 | 业务作用 |
|---|---|---|
| ① 立项 | 美术风格（国风工笔 等）| **全剧画风** — 影响每张图 |
| ③ 资产 | 角色 styleAnchors | **角色独特视觉**（少用） |
| ④ 分镜 | 相机风格（电影感/胶片）| **镜头美学**（不是画风） |

**问题**：用户分不清什么时候改哪个，常常在 ① 调了又在 ④ 重调。

**改**：
- ① 立项「美术风格」加 hint：「这是全剧画风，每个分镜默认套用，无需重复设置」
- ③ 资产 styleAnchors 默认隐藏（折叠到角色高级），仅特殊角色用
- ④ 相机风格改名「**镜头质感**」与"美术风格"区分；hint「与全剧画风正交，控制相机感」

### A4 · 三层「角色表情」覆盖关系不清

| 位置 | 字段 | 含义 |
|---|---|---|
| ③ 资产 | 角色性格 | 默认情感倾向（"焦虑型"）|
| ② 剧本 | 场景出场角色.expression | **该场景** 整体情绪 |
| ④ 分镜 | 出场角色.expression | **该镜头** 瞬间表情 |

**问题**：实际生成 prompt 用哪层？ ③ < ② < ④（越具体越优先），但原型 UI 没说。

**改**：
- ④ 分镜出场角色 placeholder 文字改成「来自 ② 场景默认：焦虑不安。改这里仅本镜头生效」
- 三层用同一字段名 `expression`，UI 上明确"覆盖来自上层"

### A5 · 「调整方向」语义模糊（最大 UX 雷点）

| 位置 | 字段 | 业务作用 |
|---|---|---|
| ⑤ 画面 | 调整方向（影响关键帧）| 关键帧重生 prompt 末尾 |
| ⑥ 视频 | （无）| 但用户期望也有 |

**问题**：⑤ 改了「调整方向」⑥ 视频会跟着变吗？答：不会。

**改**：
- ⑤ 字段改名「**关键帧调整方向**」并加 ⓘ「仅影响关键帧重生成」
- ⑥ 视频 panel 加独立字段「**视频调整方向**」（如「让运动慢一些 / 镜头更稳」），单独写入 video prompt 末尾

### A6 · 「场景描述」 vs 「画面描述」边界不清

- ② 剧本场景描述：「传统中式装潢，雕花木窗结霜，昏黄灯笼...」（整场氛围）
- ④ 分镜画面描述：「昏黄灯笼光晕笼罩下，李墨独坐...」（本镜头看到的）

**问题**：用户两处都写"灯笼" "茶馆"，重复啰嗦；下游 prompt 拼接也容易堆叠。

**改**：
- ④ 分镜「画面描述」textarea 上方加 readonly 引用「📍 来自 ② 场景：传统中式装潢，雕花木窗结霜...」
- 写本镜头描述时**不要重复场景级氛围**（hint 提醒）
- prompt 装配时由后端去重（场景级 + 分镜级 关键词重叠时去重）

## B. 可精简（必修 — 减少认知负担）

### B1 · 每 stage 重复的「分镜信息行」

```
④ 分镜：EP01_S01_SH02 · 近景·平视·静止
⑤ 画面：EP01_S01_SH02 · 近景·平视·静止·4s·首尾帧·2 帧
⑥ 视频：EP01_S01_SH02 · 4s · 首尾帧 · keyframes2video
```

**改**：
- 抽出一个「**当前分镜面包屑**」组件，固定在 stage 切换条下方
- 用户在 ④/⑤/⑥ 之间切换时面包屑信息一致
- 信息按 stage 加载相关字段（④ 显示镜头语言；⑤/⑥ 加生成状态）

### B2 · ⑤ 画面 + ⑥ 视频 左侧分镜 sidebar 重复

**问题**：用户在 ⑤ 选了 1.2 → 切到 ⑥ 重新选，浪费一次操作。

**改**：
- 选中分镜在 store 持久化
- ⑤ → ⑥ 切换时保留选择
- 或者 ⑤/⑥ 共用左侧 sidebar 显示生成状态：1.1 ✓画面✓视频 / 1.2 ✓画面 ○视频

### B3 · ④ 高级折叠区里的"3D 摆位 / 背景参考图"对 95% 用户无意义

- 当前折叠到 ④ 高级
- 但折叠条本身占空间，用户看到「▼ 高级」会试着展开

**改**：
- "3D 摆位"完全移到项目级"实验室功能"开关（默认关闭）
- 关闭时 ④ 不显示该字段
- 开启后才在 ④ 高级折叠内出现

### B4 · ⑦ 时间线 5 轨过满

- 视频 / 旁白 / 对白 / BGM / 字幕 = 5 轨

**改**：
- 自动隐藏空轨（无对白 → 隐藏对白轨）
- 默认显示「视频 + 主音轨（混合 旁白 + 对白）+ 字幕」3 轨
- 「展开音频细节」按钮才拆出对白 / 旁白 / BGM / 音效

### B5 · ① 立项「补充背景」textarea 与「故事世界 年代/地域/调性」字段重叠

```
年代：明代万历年间
地域：京城
调性：江湖风云
补充背景：朝局动荡，民间侠义之风盛行；茶馆为各路消息汇集之所。
```

**问题**：明显的"结构化字段 + 自由文本"组合，但下游可能只用一个。

**改**：
- 三结构字段够用 95% 场景；删除「补充背景」textarea
- 或者改成「补充提示词（高级）」明确标"会拼到 prompt"

## C. 逻辑清晰（必修 — 消除困惑点）

### C1 · 7 stage 不应严格线性

**实际工作流**：
- ② → ④ → ③ → ⑤（先看分镜要哪些资产，再去建资产）很常见
- 专业用户经常跳跃修改

**改**：
- 顶部 stage 切换条**任何 stage 都可点**，不禁用
- 每 stage 顶部加状态徽章：✓ 已完成 / ⚙ 进行中 / ○ 未开始
- 「下一步」按钮去掉强制性（改为软引导）

### C2 · ⑤ 画面 / ⑥ 视频 拆分对自媒体用户冗余

**自媒体场景**：用户填完 ④ 分镜，期望「一键生成视频」（不关心关键帧）。

**改**：
- 自媒体模式（① 立项「自媒体短剧」预设）下：
  - ⑤ + ⑥ **合并为一个"出片" stage**
  - 关键帧作为"中间产物"在生成进度条里展示，不暴露为独立 stage
- 专业模式下：保留 ⑤/⑥ 拆分，给精细控制

实施：项目级 `useAdvancedMode` 开关决定 stage 数量。

### C3 · 一致性参考链不可见（默认隐藏的子画布）

**问题**：当前「显示生成链路」开关默认关闭，用户不知道资产→关键帧→视频的传递。

**改**：
- 默认**开启**子画布连线（透明度优先）
- 给"关闭"留入口（专业用户专注时关闭）

### C4 · 「转场」配置位置矛盾

**业务事实**：转场是合成阶段事，但**用户在 ④ 分镜时就想说"这一镜后接淡入淡出"**。

**当前**：转场全在 ⑦ 合成配置 → 用户在 ④ 分不清下一镜怎么接。

**改**（折中）：
- ④ 分镜 stage 末尾加**单一字段**「⏭ 与下一镜衔接」(快切 / 淡入 / 叠化 三选一)
- 写到 storyboard.transitionType
- ⑦ 合成时间线点击转场 chip 可精调（duration / direction / easing / color）
- 简单选择放分镜级，精调放合成级

### C5 · 「调整方向」 vs 「画面描述」 vs 「运动描述」 三个 textarea 在 ④ + ⑤ + ⑥ 散落

| 字段 | 位置 | 业务作用 | 是否进 prompt |
|---|---|---|---|
| 画面描述 | ④ | 这一镜画面长什么样 | ✓ keyframe + ⚠ 历史 video |
| 运动描述 | ④ | 这一镜的动作 | ✓ video |
| 关键帧调整方向 | ⑤ | 重生关键帧的微调 | ✓ keyframe 末尾 |
| 视频调整方向（建议加）| ⑥ | 重生视频的微调 | ✓ video 末尾 |

**改**：
- 在 ④ 分镜 stage 显示 4 个 textarea 时，每个都加 ⓘ tooltip 说明"影响哪个生成环节、是否可在后续 stage 微调"
- 每个 textarea 标小图标显示**目标 stage**（🎞 影响关键帧 / 🎥 影响视频）

### C6 · 「我的库」引用后的修改去向不清

**问题**：从我的库引用「李墨」到新项目，新项目里改了表情 → 改的是新 binding 还是 user_asset 模板？

**改**：
- 引用后默认所有修改**仅本项目**（新 binding 独立）
- 角色编辑器顶部加「⚪ 仅本项目 / ⚪ 同步回我的库」单选，默认前者
- 选后者时改动同步到 user_asset，影响其他引用了的项目

## D. 提高生成效果（建议加强）

### D1 · 项目级风格锚定的传递路径不可见

**问题**：① 选了「国风工笔」，但 ⑤ 画面生成时用户看不到"这次生成将套用国风工笔"。

**改**：
- ⑤ 画面 stage 顶部加 readonly chip：「🎨 当前风格：国风工笔 [已应用]」
- 关键帧生成的 prompt 详情 dialog 里显示"风格锚定段：国风工笔, 8k, ..."

### D2 · 形象组应用透明度不足

**问题**：③ 资产 形象组勾了 5 张，但 ⑤ 画面生成时用户不一定知道这 5 张都被喂给 AI 了。

**改**：
- ⑤ 画面「本分镜资产引用」中角色卡显示「**🪪 形象组 5 张全部参与**」 + 缩略图条
- hover / 点击展开看具体哪 5 张

### D3 · AI 模型可见性

**问题**：① 高级里配了 5 个 model，但用户在 ⑤/⑥ 生成时不知道当前用哪个。

**改**：
- 每个 stage 的「生成」按钮上显示 model：「↻ 重生关键帧 (volcengine seedream 4.5)」
- 点击 button 旁的小图标可临时切换 model（用于 A/B 测）

### D4 · 跨分镜一致性预警

**业务**：角色身份要全剧统一。当前没有验证机制 — 用户改了某个分镜的资产挑图，可能与其他分镜不一致。

**改**（专业模式）：
- 在 ⑤ 画面 stage 加「一致性检查」按钮
- 后端用 face embedding 对比所有分镜的角色画面
- 不一致的分镜列表出来 + 一键"以主图为准重生"

## E. 简化使用流程（建议加强）

### E1 · 自媒体模式 stage 折叠

**业务**：自媒体用户对 7 stage 望而生畏。

**改**：
- ① 立项「题材类型」选「自媒体短剧」预设：
  - 自动跑 AI 一键模式（跳到 flows.html · AI 一键）
  - 标准通道下隐藏 ④ 分镜内的镜头语言细节字段（仅留画面描述）
  - ⑤+⑥ 合并展示
- 高级用户在「立项 → 高级 → 进入专业模式」切换

### E2 · 一键操作覆盖更多 stage

**当前**：只有 ⑤/⑥ 有「批量生成全部」。

**改**：
- ② 剧本「+ AI 拆所有场景」/ 「+ AI 写所有对白」
- ③ 资产「+ AI 生成所有主图」/ 「+ AI 生成所有形象组」
- ④ 分镜「+ AI 拆所有分镜」/ 「+ AI 自动配镜头语言」
- ⑦ 合成「+ AI 自动配 BGM」/ 「+ AI 自动加字幕」

每个 stage 都有「⚡ 一键 AI 跑完本环节」入口（业务文档分层介入策略）

### E3 · 历史版本回退

**业务**：用户多次重生关键帧后想回到第 2 次的效果。

**改**：
- 关键帧 / 视频 / 资产生成都默认保留**最近 5 个版本**
- ⑤/⑥ 关键帧卡 hover 显示「↺ 历史版本 (5 版)」
- 点击切换 / 比较

## F. 我额外想到的（值得考虑）

### F1 · 项目仪表板缺失

**业务文档 §11.3**：项目仪表板看整体进度。当前原型没有。

**建议**：项目列表点项目卡 → 进入"仪表板"页（不进 stage），上方进度环 + 下方各 stage 状态卡 + 「跳到 ⑤ 继续制作」按钮。

### F2 · ⑦ 合成 缺「试听 + 试看」

**业务**：合成前用户想"听一下当前效果是不是对的"。

**建议**：⑦ 合成顶部加「▶ 预渲染 30s 试看」按钮（低分辨率快速渲染前 30s）。

### F3 · 分镜批量编辑

**业务**：13 个分镜全部要「时长改 5s」 / 「景别都改近景」。

**建议**：④ 分镜列表上方加「☐ 批量选择」按钮 → 多选 → 批量改时长 / 景别 / 镜头风格。

### F4 · 「内容仿拍」与「我的库」结合

**场景**：用户用参考视频起步生成新内容，但想"角色用我的库里的李墨"。

**建议**：参考视频拆解后的"角色"列表中，点角色 → 弹「+ 新建 / 📚 从库选」二选一。

### F5 · 异常处理路径不明

**业务**：AI 生成失败 / Provider 限流 / 余额不足 — 当前 UI 不显示。

**建议**：每个 stage 顶部加状态条：「✓ provider 正常 / ⚠ 余额不足 / ❌ 限流中」+ 点击查看详情。

## 总结：原型 v3 → v4 修订方向

把 P0 全做了 + P1 选 1-2 项（C2 自媒体模式合并 / E2 一键 AI 扩展），原型即可定稿；P2 实施时按需。

**核心精神**：
- 字段语义边界清晰（A1-A6）
- 同一信息只出现一次（B1-B5）
- 让用户看见 AI 在做什么（D1-D3）
