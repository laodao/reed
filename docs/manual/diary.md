# 日记 使用手册

## 加入知识库

把日记内容作为一篇文档导入到指定知识库（KB），后续可以参与 RAG 检索。

### 操作

在日记编辑器顶部点击「导出 → 加入知识库」，弹出对话框：

- **列表为空** → 显示「去新建知识库 →」按钮，点击跳转到知识库管理页（建库流程在那里完成；建好回来再导入）
- **列表非空** → 选目标 KB，点「确定」

### 重复导入语义

同一篇日记多次导入到**同一**知识库时，**会更新已有文档**——不会产生重复。具体行为：

- 第一次导入：在 KB 里新建一篇文档（KB 文档计数 +1）；toast「已加入知识库」
- 之后导入（修改过日记后）：复用已有 KB 文档 ID，覆盖文件内容、清旧切片/向量、重新跑切分+embedding 流水线；toast「已更新到知识库」

不同知识库**互相独立**——同一日记导入到 KB-A 和 KB-B 是两条独立文档，各自维护。

### 何时按钮 disabled

- 日记内容为空（trim 后无字符）：菜单项 disabled，不允许导入空文档

### 失败场景与提示

| 场景 | 提示 |
|---|---|
| 知识库列表加载失败（网络 / DB 问题） | 对话框内显示错误条 + 重试按钮 |
| KB embedding 模型不可用 / 配额耗尽 | toast 显示后端错误信息原文 |
| 上次更新中 embedding 失败 | KB 里该文档 status='failed'；下次重新导入会再走一次 upsert，恢复后 status 转回 'completed' |

### 双端一致性

PC（Electron）和 Web 都支持此功能，行为完全一致。
