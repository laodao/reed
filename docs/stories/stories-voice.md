## VOC-001: 文本转语音(TTS)

### 用户故事

```
作为一个 用户
我想要 将文本转换为语音
以便 听取文本内容或生成配音
```

### 描述

**背景：**
用户可能需要将文本内容转换为语音，用于配音、听书、辅助阅读等场景。

**范围：**
- 文本输入
- 语音角色选择
- 语速音调调节
- 语音生成和播放
- 音频下载

**用户流程：**
1. 用户进入语音转换页面
2. 选择TTS标签页
3. 输入或粘贴要转换的文本
4. 选择语音角色
5. 调节语速、音调参数
6. 点击"生成语音"
7. 系统生成音频
8. 播放预览
9. 下载音频文件

### 验收标准

- [ ] 支持文本输入，最多10000字符
- [ ] 显示字符计数
- [ ] 提供至少8种语音角色：
  - [ ] 温柔女声
  - [ ] 活泼女声
  - [ ] 成熟女声
  - [ ] 温和男声
  - [ ] 阳光男声
  - [ ] 浑厚男声
  - [ ] 童声
  - [ ] 老年音
- [ ] 支持语速调节（0.5x - 2.0x）
- [ ] 支持音调调节（-10 到 +10）
- [ ] 支持音量调节（0% - 100%）
- [ ] 支持试听语音角色
- [ ] 生成时显示进度
- [ ] 生成完成后自动播放预览
- [ ] 内置音频播放器
- [ ] 支持下载MP3格式
- [ ] 长文本自动分段处理

### 技术说明

**涉及的组件：**
- 前端：VoiceView.vue, TextInput.vue, VoiceSelector.vue, AudioPlayer.vue
- 后端：tts.service.ts
- API：火山引擎豆包语音

**API接口：**
```typescript
// 生成语音
IPC.generateSpeech(params: {
  text: string,
  voice: string,
  speed: number,
  pitch: number,
  volume: number
}): Promise<Result<{
  audioPath: string,
  duration: number
}>>
```

**边界检查：**
| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 文本长度 | ≤10000字符 | "文本过长，请分段处理" |
| 空文本 | 不能为空 | "请输入要转换的文本" |
| 语速范围 | 0.5-2.0 | "语速超出有效范围" |

### 故事点数：5

**估算依据：**
- 文本输入界面：1点
- 语音角色选择：1.5点
- API集成：2点
- 播放器组件：0.5点

## VOC-002: 语音转文本(STT)

### 用户故事

```
作为一个 用户
我想要 将语音转换为文本
以便 将音频内容转为可编辑的文字
```

### 描述

**背景：**
用户可能需要将音频文件或实时录音转换为文本，用于会议记录、字幕制作等场景。

**范围：**
- 音频文件上传识别
- 实时录音转写
- 多语言支持
- 识别结果编辑导出

**用户流程：**
1. 用户进入语音转换页面
2. 选择STT标签页
3. 上传音频文件 或 点击开始录音
4. 系统进行语音识别
5. 显示识别结果
6. 用户可编辑和导出

### 验收标准

- [ ] 支持上传音频文件
- [ ] 支持拖拽音频文件
- [ ] 支持的音频格式：MP3, WAV, M4A
- [ ] 最大音频时长60分钟
- [ ] 最大文件大小100MB
- [ ] 支持实时录音转写
- [ ] 录音时显示录音时长
- [ ] 实时显示转写文本
- [ ] 支持暂停/停止录音
- [ ] 支持选择识别语言
- [ ] 显示识别置信度
- [ ] 识别结果可编辑
- [ ] 支持复制和导出

### 技术说明

**涉及的组件：**
- 前端：VoiceView.vue, AudioUploader.vue, RecordingPanel.vue
- 后端：stt.service.ts
- API：火山引擎豆包语音

**API接口：**
```typescript
// 识别音频文件
IPC.recognizeAudio(params: {
  audioPath: string,
  language: string
}): Promise<Result<{
  text: string,
  confidence: number,
  duration: number
}>>

// 开始录音
IPC.startRecording(): Promise<Result<void>>

// 停止录音并获取结果
IPC.stopRecording(): Promise<Result<{
  audioPath: string,
  text: string
}>>
```

**估算依据：**

- 实时录音：2点
- API集成：1.5点

作为一个 用户

用户对语音效果有不同需求，需要能够精细调节各项参数。

**范围：**
- 默认语音角色设置
- 默认语速音调设置
- 语音角色试听
- 参数预设

**用户流程：**
1. 用户在语音转换界面
2. 点击"高级设置"
3. 调节各项参数
4. 试听效果
5. 保存为默认设置

- [ ] 可设置默认音调
