## OCR-001: 图片上传与文字识别

### 用户故事

```
作为一个 用户
我想要 从图片中识别文字
以便 将图片内容转换为可编辑的文本
```

### 描述

**背景：**
用户经常需要从截图、扫描文档、照片等图片中提取文字内容。OCR识别功能可以帮助用户快速获取图片中的文字。

**范围：**
- 图片上传（点击/拖拽）
- 多种OCR引擎支持
- 多语言识别
- 识别结果显示

**用户流程：**
1. 用户进入OCR识别页面
2. 上传图片（点击或拖拽）
3. 选择OCR引擎和识别语言
4. 系统进行文字识别
5. 显示识别结果
6. 用户可查看识别置信度

### 验收标准

- [ ] 支持点击上传图片
- [ ] 支持拖拽图片到识别区域
- [ ] 支持粘贴剪贴板图片（Ctrl+V）
- [ ] 支持的图片格式：JPG, PNG, BMP, WEBP
- [ ] 单张图片最大支持20MB
- [ ] 支持选择OCR引擎：
  - [ ] Tesseract-OCR（本地）
  - [ ] 系统OCR（本地）
- [ ] 支持选择识别语言：
  - [ ] 简体中文
  - [ ] 繁体中文
  - [ ] 英语
  - [ ] 日语
  - [ ] 自动检测
- [ ] 显示识别进度
- [ ] 识别结果正确显示
- [ ] 显示识别置信度
- [ ] 上传前验证文件格式和大小

### 技术说明

**涉及的组件：**
- 前端：OcrView.vue, ImageUploader.vue, ResultDisplay.vue
- 后端：ocr.service.ts, ocr-engines/
- IPC：ocr-handler.ts

**API接口：**
```typescript
// 识别图片
IPC.recognizeImage(params: {
  imagePath: string,
  engine: 'tesseract' | 'system',
  language: string
}): Promise<Result<{
  text: string,
  confidence: number,
  blocks: TextBlock[]
}>>
```

**边界检查：**
| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 文件大小 | ≤20MB | "文件过大，请压缩后上传" |
| 文件格式 | JPG/PNG/BMP/WEBP | "不支持的文件格式" |
| 图片尺寸 | 50-10000px | "图片尺寸不符合要求" |

### 故事点数：5

**估算依据：**
- 图片上传组件：1.5点
- OCR引擎集成：2点
- 结果显示：1.5点

### 依赖

- SET-001（API密钥管理，如使用云端OCR）

## OCR-002: 识别结果编辑与导出

### 用户故事

```
作为一个 用户
我想要 编辑和导出识别结果
以便 修正错误并保存到文件
```

### 描述

**背景：**
OCR识别可能存在误差，用户需要能够编辑识别结果并导出为所需格式。

**范围：**
- 结果编辑
- 结果复制
- 多格式导出

**用户流程：**
1. 用户查看识别结果
2. 发现需要修改的内容
3. 直接编辑文本
4. 点击复制或导出
5. 选择导出格式
6. 保存到文件

### 验收标准

- [ ] 识别结果可直接编辑
- [ ] 编辑框显示行号
- [ ] 支持复制全部文本
- [ ] 支持复制选中文本
- [ ] 支持导出为TXT格式
- [ ] 支持导出为Markdown格式
- [ ] 支持导出为Word格式
- [ ] 导出时可选择保存位置
- [ ] 复制/导出成功显示提示
- [ ] 支持撤销/重做编辑操作

### 技术说明

**涉及的组件：**

- 后端：export.service.ts

**导出格式支持：**
- TXT：纯文本

### 故事点数：3

**估算依据：**

## OCR-003: 批量识别与历史记录

### 用户故事

```
作为一个 用户
我想要 批量识别多张图片并查看历史
以便 提高效率并回顾之前的识别
```

### 描述

**背景：**
用户可能需要同时处理多张图片，或者需要回顾之前的识别结果。

**范围：**
- 批量上传识别
- 识别历史记录
- 历史搜索和管理

**用户流程：**
1. 用户点击"批量识别"
2. 选择多张图片
3. 系统依次识别每张图片
4. 显示整体进度
5. 完成后可批量导出
6. 用户可在历史记录中查看

### 验收标准

- [ ] 支持批量选择多张图片
- [ ] 显示批量识别进度
- [ ] 显示每张图片的识别状态
- [ ] 支持暂停/继续批量任务
- [ ] 支持取消单个任务
- [ ] 批量完成后可一起导出
- [ ] 自动保存识别历史
- [ ] 历史按时间倒序排列
- [ ] 支持搜索历史内容
- [ ] 支持删除历史记录
- [ ] 点击历史可查看详情

### 技术说明

**涉及的组件：**
- 前端：BatchPanel.vue, HistoryList.vue
- 后端：ocr-batch.service.ts, ocr-history.service.ts
- 数据库：ocr_records表

**数据模型：**
```typescript
interface OCRRecord {
  id: string;
  imagePath: string;
  engine: string;
  language: string;
  result: string;
  confidence: number;
  status: 'pending' | 'processing' | 'completed' | 'failed';
  createdAt: Date;
}
```

**估算依据：**
- 批量处理：1.5点
- 历史管理：1.5点
