## IMG-001: 文生图基础功能

### 用户故事

```
作为一个 内容创作者
我想要 通过文字描述生成图像
以便 快速获得所需的视觉素材
```

### 描述

**背景：**
用户需要通过文字描述（Prompt）来生成图像，用于内容创作、设计参考等场景。

**范围：**
- 提示词输入
- 多模型支持
- 图像生成
- 结果展示

**用户流程：**
1. 用户进入图像生成页面
2. 选择生成模型
3. 输入提示词（描述想要的图像）
4. 可选输入负向提示词
5. 点击"生成"按钮
6. 系统调用API生成图像
7. 显示生成进度
8. 展示生成的图像

### 验收标准

- [ ] 支持输入正向提示词，最多1000字符
- [ ] 支持输入负向提示词（可选）
- [ ] 显示字符计数
- [ ] 支持的图像生成模型：
  - [ ] 通义万项
  - [ ] 火山引擎
  - [ ] 智谱
- [ ] 模型选择器显示在页面顶部
- [ ] 生成时显示进度指示
- [ ] 生成完成后显示图像
- [ ] 支持生成多张图像（1-4张）
- [ ] 空提示词不允许生成
- [ ] 敏感词检测和提示

### 技术说明

**涉及的组件：**
- 前端：ImageView.vue, PromptInput.vue, ImageDisplay.vue
- 后端：image.service.ts
- API：通义万项、火山引擎、智谱

**API接口：**
```typescript
// 生成图像
IPC.generateImage(params: {
  prompt: string,
  negativePrompt?: string,
  model: string,
  size: string,
  count: number
}): Promise<Result<{
  images: { url: string, seed: number }[],
  duration: number
}>>
```

### 故事点数：5

**估算依据：**
- 提示词输入界面：1.5点
- 多模型适配：2点
- 结果展示：1.5点

### 依赖

- SET-001（API密钥管理）

## IMG-002: 图像生成参数配置

### 用户故事

```
作为一个 内容创作者
我想要 自定义图像生成参数
以便 获得更符合需求的生成结果
```

### 描述

**背景：**
不同的场景需要不同尺寸、风格的图像，用户需要能够灵活配置生成参数。

**范围：**
- 图像尺寸选择
- 生成数量设置
- 风格选择
- 高级参数

**用户流程：**
1. 用户在图像生成界面
2. 展开"参数设置"面板
3. 选择图像尺寸
4. 设置生成数量
5. 选择图像风格
6. 可选设置高级参数
7. 点击生成

### 验收标准

- [ ] 支持选择图像尺寸：
  - [ ] 1024x1024（1:1）
  - [ ] 1024x1792（9:16）
  - [ ] 1792x1024（16:9）
  - [ ] 768x768
- [ ] 支持设置生成数量（1-4张）
- [ ] 支持选择图像风格：
  - [ ] 自动
  - [ ] 写实
  - [ ] 动漫
  - [ ] 油画
  - [ ] 水彩
  - [ ] 3D渲染
- [ ] 支持设置随机种子（可选）
- [ ] 参数设置面板可折叠
- [ ] 显示当前参数摘要
- [ ] 支持重置为默认参数

### 技术说明

**涉及的组件：**
- 前端：ImageSettings.vue, SizeSelector.vue, StyleSelector.vue

**参数模型：**
```typescript
interface ImageParams {
  size: '1024x1024' | '1024x1792' | '1792x1024' | '768x768';
  count: number;  // 1-4
  style: string;
  seed?: number;
}
```

### 故事点数：3

**估算依据：**
- 参数界面：1.5点
- 参数处理：1点
- UI优化：0.5点
