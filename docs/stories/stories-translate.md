## TRA-001: 文本翻译与语言检测

### 用户故事

```
作为一个 用户
我想要 将文本从一种语言翻译为另一种语言
以便 理解和使用不同语言的内容
```

### 描述

**背景：**
用户在工作和学习中经常需要进行跨语言的内容转换，翻译功能可以帮助用户快速理解外语内容或将内容翻译成其他语言。

**范围：**
- 文本翻译
- 自动语言检测
- 多翻译服务支持
- 原文译文对照

**用户流程：**
1. 用户进入翻译页面
2. 输入或粘贴要翻译的文本
3. 选择源语言（或自动检测）
4. 选择目标语言
5. 系统进行翻译
6. 显示翻译结果
7. 用户可复制或朗读结果

### 验收标准

- [ ] 支持文本输入，最多5000字符
- [ ] 显示字符计数
- [ ] 支持自动检测源语言
- [ ] 支持的语言：
  - [ ] 简体中文
  - [ ] 繁体中文
  - [ ] 英语
  - [ ] 日语
  - [ ] 韩语
  - [ ] 法语
  - [ ] 德语
  - [ ] 西班牙语
- [ ] 支持多种翻译服务
- [ ] 源语言和目标语言可互换
- [ ] 翻译结果实时显示
- [ ] 左右对照显示原文和译文
- [ ] 支持复制翻译结果
- [ ] 支持朗读原文和译文
- [ ] 显示检测到的语言
- [ ] 支持清空输入

### 技术说明

**涉及的组件：**
- 前端：TranslateView.vue, TextInput.vue, LanguageSelector.vue
- 后端：translate.service.ts
- API：火山翻译/百度翻译

**API接口：**
```typescript
// 翻译文本
IPC.translate(params: {
  text: string,
  sourceLanguage: string,  // 'auto' for auto-detect
  targetLanguage: string,
  service: string
}): Promise<Result<{
  translatedText: string,
  detectedLanguage?: string,
  confidence?: number
}>>
```

**边界检查：**
| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 文本长度 | ≤5000字符 | "文本过长，请分段翻译" |
| 空文本 | 不能为空 | "请输入要翻译的文本" |
| 相同语言 | 源/目标不能相同 | "源语言和目标语言相同" |

**估算依据：**
- 翻译界面布局：2点
- 语言选择器：1点
- API集成：1.5点

## TRA-002: 批量翻译与历史记录

### 用户故事

```
作为一个 用户
我想要 批量翻译多段文本并查看历史
以便 提高效率并回顾翻译内容
```

### 描述

**背景：**
用户可能需要同时翻译多段文本，或者需要回顾之前的翻译结果。

**范围：**
- 批量文本翻译
- 翻译历史记录
- 历史搜索和导出

**用户流程：**
1. 用户点击"批量翻译"
2. 输入多段文本（每行一段）
3. 选择源语言和目标语言
4. 系统依次翻译每段
5. 显示翻译进度
6. 完成后可批量导出

### 验收标准

- [ ] 支持批量输入多段文本
- [ ] 每行作为独立段落
- [ ] 显示批量翻译进度
- [ ] 显示每段翻译状态
- [ ] 支持暂停/继续批量任务
- [ ] 批量完成后可一起导出
- [ ] 自动保存翻译历史
- [ ] 历史按时间倒序排列
- [ ] 支持搜索历史内容
- [ ] 支持删除历史记录
- [ ] 点击历史可查看详情

### 技术说明

**涉及的组件：**
- 前端：BatchTranslate.vue, TranslateHistory.vue
- 后端：translate-batch.service.ts
- 数据库：translate_records表

**数据模型：**
```typescript
interface TranslateRecord {
  id: string;
  sourceText: string;
  targetText: string;
  sourceLanguage: string;
  targetLanguage: string;
  service: string;
  createdAt: Date;
}
```

### 故事点数：3

**估算依据：**
- 批量处理：1.5点
- 历史管理：1.5点

### 依赖

- TRA-001（文本翻译与语言检测）
