# 长文转剧集视频功能 PRD

## 一、产品概述

### 1.1 产品定位

将长文写作模块中的小说内容，自动转换为视频剧集，实现"文字到视频"的自动化生产流程。

### 1.2 目标用户

- 使用长文写作模块创作小说的用户
- 需要将文字作品转化为视频内容的创作者

### 1.3 核心价值

| 维度 | 描述 |
|------|------|
| 自动化 | AI 自动完成剧本生成、分镜设计、图像生成、配音、合成 |
| 一致性 | 保持角色外观、场景风格在整部剧集中的一致性 |
| 可控性 | 用户可以在每个环节审核和调整，确保质量 |

---

## 二、业务流程总览

### 2.1 阶段划分

视频制作流程分为 **5个阶段**：

```
阶段1: 项目配置    → 阶段2: 剧本生成    → 阶段3: 分镜设计    → 阶段4: 素材生成    → 阶段5: 视频合成
```

### 2.2 阶段详情

| 阶段 | 名称 | 核心目标 | 状态标识 |
|------|------|----------|----------|
| 阶段1 | 项目配置 | 创建项目、配置参数、绑定角色 | `draft` |
| 阶段2 | 剧本生成 | AI生成剧本、审核剧本内容 | `scripting` |
| 阶段3 | 分镜设计 | 将场景拆分为分镜、调整镜头参数 | `storyboarding` |
| 阶段4 | 素材生成 | 生成分镜画面、生成配音音频 | `producing` |
| 阶段5 | 视频合成 | 合成视频、预览、导出 | `completed` |

### 2.3 制作层级结构

```
项目 (VideoProject)
├── 剧集1 (VideoEpisode) - 对应小说章节
│   ├── 剧本 (EpisodeScript)
│   │   ├── 场景1 (SceneScript)
│   │   │   ├── 分镜1 (Storyboard)
│   │   │   ├── 分镜2 (Storyboard)
│   │   │   └── ...
│   │   ├── 场景2 (SceneScript)
│   │   └── ...
│   └── 音轨配置
├── 剧集2 (VideoEpisode)
├── ...
└── 角色绑定配置
```

**布局说明：**

| 区域 | 位置 | 功能 |
|------|------|------|
| 场景导航 | 剧本左侧边栏 | 列出所有场景，点击跳转 |
| 剧本正文 | 剧本右侧主区域 | 格式化显示剧本内容 |
| 章节梗概 | 剧本底部折叠 | 50-100字梗概概要 |

**剧本格式化显示：**

- 场景标题：**加粗显示**，如 `INT. 办公室 - 日`
- 角色名：居中显示，全大写
- 对白：缩进居中显示
- 括号提示：小字体，对白上方
- 转场：右对齐显示

**操作步骤：**

1. 选择剧集（左侧点击）
2. 点击"AI生成剧本"按钮
3. 系统调用AI生成：
   - 章节梗概（50-100字）
   - 完整剧本正文（标准格式）
   - 结构化场景数据（用于后续处理）
4. 自动保存数据
5. 剧本正文格式化显示
6. 场景导航自动填充
