# 语音助手模块 PRD

## 1. 产品概述

### 1.1 产品背景
语音交互是现代AI应用的重要交互方式。语音助手模块为用户提供完整的语音处理能力，包括语音识别、语音合成、声音复刻等功能，让用户能够通过语音与应用进行自然交互。

### 1.2 产品目标
- 提供高质量的文本转语音（TTS）服务
- 提供准确的语音转文本（STT/ASR）服务
- 支持个性化声音复刻，让用户拥有专属AI声音
- 支持语音合成，生成自然流畅的语音内容

### 1.3 目标用户
- 需要语音输入的用户
- 内容创作者（视频配音、有声读物）
- 需要语音辅助的视障用户
- 需要个性化语音的企业用户

## 2. 功能需求

### 2.1 功能架构

```
语音助手模块
├── 文本转语音 (TTS)
│   ├── 文本输入
│   ├── 声音选择（预置发音人/复刻声音）
│   ├── 语速/音调/音量调节
│   ├── 情感/风格设置
│   ├── 试听与下载
│   └── 历史记录
├── 语音转文本 (STT)
│   ├── 录音识别
│   ├── 文件上传识别
│   ├── 多语言支持
│   ├── 实时转写
│   └── 结果编辑
└── 语音复刻
    ├── 声音样本录制
    ├── 样本上传
    ├── 训练进度
    └── 复刻声音管理
```

### 2.2 文本转语音 (TTS)

#### 2.2.1 功能描述
将输入的文本转换为自然流畅的语音输出，支持预置发音人和用户复刻的声音。

#### 2.2.2 功能要点
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 文本输入 | 支持手动输入或粘贴文本，支持最大5000字符 | P0 |
| 声音选择 | 选择预置发音人或用户复刻的声音 | P0 |
| 语言选择 | 支持中文、英文、日文等多种语言 | P0 |
| 语速调节 | 支持0.5x-2.0x语速调节 | P1 |
| 音调调节 | 支持音调高低调节 | P1 |
| 音量调节 | 支持音量大小调节 | P1 |
| 情感设置 | 设置语音情感（开心、悲伤、平静等） | P2 |
| 风格设置 | 设置语音风格（播音、对话、朗读等） | P2 |
| 在线试听 | 生成前可试听效果 | P0 |
| 音频下载 | 支持下载生成的音频文件（MP3/WAV） | P0 |
| 历史记录 | 保存转换历史，可重新播放或下载 | P1 |

#### 2.2.3 交互流程
```
1. 用户输入/粘贴文本
2. 选择声音（预置发音人 或 复刻声音）
3. 选择语言
4. 调节语速、音调等参数（可选）
5. 设置情感、风格（可选）
6. 点击"试听"预览效果
7. 满意后点击"生成"
8. 等待生成完成
9. 在线播放或下载音频文件
```

### 2.3 语音转文本 (STT)

#### 2.3.1 功能描述
将语音内容转换为文本，支持录音和文件上传两种方式。

#### 2.3.2 功能要点
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 录音识别 | 支持实时录音并转写为文本 | P0 |
| 文件上传 | 支持上传音频文件进行识别（mp3/wav/m4a） | P0 |
| 多语言识别 | 支持中文、英文、中英混合等 | P0 |
| 实时转写 | 录音过程中实时显示识别结果 | P1 |
| 标点预测 | 自动添加标点符号 | P1 |
| 结果编辑 | 支持对识别结果进行编辑修正 | P0 |
| 复制结果 | 一键复制识别文本 | P0 |
| 历史记录 | 保存识别历史 | P1 |
| 音频限制 | 单次音频最大60分钟，文件最大100MB | P0 |

#### 2.3.3 交互流程

**录音识别流程：**
```
1. 用户点击"开始录音"
2. 系统请求麦克风权限
3. 用户开始说话，界面显示录音状态
4. 实时显示识别结果
5. 用户点击"停止录音"
6. 显示完整识别结果
7. 用户可编辑、复制结果
```

**文件上传流程：**
```
1. 用户点击"上传音频"
2. 选择本地音频文件
3. 系统进行音频识别
4. 显示识别进度
5. 识别完成后显示结果
6. 用户可编辑、复制结果
```

### 2.4 语音复刻

#### 2.4.1 功能描述
通过上传或录制声音样本，训练生成个性化的复刻声音，用于语音合成。

#### 2.4.2 功能要点
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 样本录制 | 在线录制声音样本 | P0 |
| 样本上传 | 上传已有的音频样本 | P0 |
| 样本要求 | 至少需要10秒-5分钟的清晰语音 | P0 |
| 训练进度 | 显示模型训练进度 | P0 |
| 复刻声音列表 | 管理已创建的复刻声音 | P0 |
| 声音预览 | 预览复刻声音效果 | P0 |
| 声音命名 | 为复刻声音设置名称 | P1 |
| 声音删除 | 删除不需要的复刻声音 | P1 |
| 训练限制 | 每个用户最多创建10个复刻声音 | P1 |

#### 2.4.3 交互流程
```
1. 用户进入"语音复刻"页面
2. 选择"录制样本"或"上传样本"
3. 按提示录制/上传声音样本
4. 填写声音名称
5. 点击"开始训练"
6. 等待训练完成（显示进度）
7. 训练完成后可预览效果
8. 在文本转语音中使用复刻声音
```

### 3.2 数据存储

#### 3.2.1 数据库表结构

**语音历史记录表 (voice_records)**
```sql
CREATE TABLE voice_records (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,              -- 'tts' | 'stt'
  status TEXT NOT NULL DEFAULT 'pending',

  -- TTS相关
  input_text TEXT,
  output_audio_path TEXT,
  voice_id TEXT,
  voice_name TEXT,
  language TEXT,
  speed REAL DEFAULT 1.0,
  pitch REAL DEFAULT 0,
  volume REAL DEFAULT 1.0,
  emotion TEXT,
  style TEXT,

  -- STT相关
  input_audio_path TEXT,
  output_text TEXT,
  audio_duration INTEGER,

  -- 通用字段
  provider_id TEXT,
  model_id TEXT,
  favorite INTEGER DEFAULT 0,
  created_at TEXT NOT NULL
);
```

**复刻声音表 (cloned_voices)**
```sql
CREATE TABLE cloned_voices (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  status TEXT NOT NULL,            -- 'training' | 'ready' | 'failed'
  sample_audio_path TEXT,
  sample_duration INTEGER,
  voice_id TEXT,                   -- 服务商返回的声音ID
  preview_audio_path TEXT,
  provider_id TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT
);
```

### 3.3 API 设计

#### 3.3.1 IPC 通道定义

```typescript
// 文本转语音
'tts:generate'           // 生成语音
'tts:providers'          // 获取TTS提供商列表
'tts:voices'             // 获取可用发音人列表

// 语音转文本
'stt:recognize'          // 语音识别
'stt:providers'          // 获取STT提供商列表

// 语音复刻
'voice:clone'            // 创建复刻声音
'voice:list'             // 获取复刻声音列表
'voice:get'              // 获取单个复刻声音
'voice:delete'           // 删除复刻声音
'voice:preview'          // 预览复刻声音
'voice:progress'         // 训练进度（事件）

// 通用
'voice:history'          // 获取历史记录
'voice:delete-record'    // 删除历史记录
'voice:toggle-favorite'  // 切换收藏
'voice:download'         // 下载音频
```

## 5. 非功能需求

### 5.1 性能要求
- TTS生成：短文本（<500字）< 5秒，长文本按比例增加
- STT识别：实时转写延迟 < 1秒
- 语音复刻训练：根据样本长度，通常5-30分钟

### 5.2 可用性要求
- 音频格式支持：MP3、WAV、M4A、OGG
- 采样率：支持 16kHz、22.05kHz、44.1kHz
- 最大并发：支持同时处理多个任务

### 5.3 安全要求
- 音频文件本地缓存加密
- API密钥安全存储
- 敏感语音内容不记录日志
