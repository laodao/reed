# 知识库系统

## 1. 功能概述

知识库系统用于管理和检索用户上传的文档内容，为 AI 对话和内容生成提供外部知识支撑。通过 Embedding 模型将文档向量化存储，支持混合检索，在 AI 回复中标注引用来源。

### 2.3 检索功能

#### FR-KB-008 知识库检索

**需求描述**：系统根据用户查询检索相关内容

**检索方式**：
- **向量检索**：使用 Embedding 模型计算查询向量，检索相似度最高的片段
- **关键词检索**：使用 BM25 算法进行关键词匹配
- **混合检索**：结合向量检索和关键词检索结果，加权排序

**检索流程**：
```
用户查询 → 向量化 → 向量检索 + 关键词检索 → 结果融合 → 返回 Top-K 片段
```

**返回信息**：
- 片段内容
- 来源文档名称
- 来源位置（页码/章节/行号）

## 4. 业务规则

### 4.1 知识库规则

| 规则 | 说明 |
|------|------|
| 数量限制 | 最多创建 20 个知识库 |
| 命名规则 | 1-50 字符，不可重复 |
| Embedding 模型 | 创建后不可修改 |

| 规则 | 说明 |
|------|------|
| 文件大小 | 单个文件最大 50MB |

| 同名处理 | 同名文件覆盖更新，重新生成向量 |
| 总容量 | 单个知识库最大 1GB |

### 4.3 检索规则

| 参数 | 默认值 |
|------|--------|
| 返回片段数 | Top-5 |
| 片段长度 | 500 字符 |
| 相似度阈值 | 0.7 |

## 5. 边界情况

### 5.1 Embedding 服务不可用

**场景**：云端 API 不可用或本地模型未加载

**处理**：
- 文档处理时显示错误："Embedding 服务暂不可用，请检查配置"
- 已处理完成的文档可正常检索
- 提供重试按钮

### 5.2 知识库存储空间不足

**场景**：知识库容量达到上限

**处理**：
- 上传时检查容量
- 显示提示："知识库容量已满，请删除部分文档后再上传"

### 5.3 检索无结果

**场景**：查询内容与知识库文档不相关

**处理**：
- 显示提示："未在知识库中找到相关内容"
- AI 可选择使用自身知识回答或提示用户更换查询

### 5.4 文档处理失败

**场景**：文档格式损坏或编码无法识别

**处理**：
- 显示失败状态和具体错误原因
- 提供重试和删除选项
- 常见错误：
  - 文件损坏
  - 不支持的编码格式
  - PDF 为扫描件且 OCR 失败
