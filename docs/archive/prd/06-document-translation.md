# 文档翻译系统

## 1. 功能概述

文档翻译系统提供文本和文件的翻译功能，支持多种语言互译。用户可以输入文本直接翻译，也可以上传 Markdown、TXT、Word 等格式的文件进行翻译。基于现有的 AI 提供商配置，调用支持多语言的模型完成翻译。

## 2. 功能需求

### 2.1 文本翻译

#### FR-TR-001 文本翻译

**需求描述**：用户可以输入文本进行翻译

**前置条件**：
- 至少配置了一个支持翻译的 AI 提供商

**操作流程**：
1. 选择源语言和目标语言
2. 在左侧输入框输入待翻译文本
3. 点击"翻译"按钮
4. 右侧显示翻译结果
5. 可以复制翻译结果

**界面布局**：
```
┌─────────────────────────────────────────────────────────────┐
│ 源语言: [自动检测 ▼]              目标语言: [英语 ▼]        │
├─────────────────────────────────────────────────────────────┤
│ ┌───────────────────────┐   ┌───────────────────────┐      │
│ │                       │   │                       │      │
│ │  输入待翻译文本...     │   │  翻译结果             │      │
│ │                       │   │                       │      │
│ │                       │   │                       │      │
│ │                       │   │                       │      │
│ └───────────────────────┘   └───────────────────────┘      │
│ 字数: 0/5000                  [复制结果]                    │
├─────────────────────────────────────────────────────────────┤
│                        [翻译]                                │
└─────────────────────────────────────────────────────────────┘
```

#### FR-TR-003 实时翻译

**需求描述**：用户可以开启实时翻译模式

**操作流程**：
1. 开启"实时翻译"开关
2. 用户输入文本时，自动触发翻译
3. 无需点击翻译按钮

**业务规则**：
- 输入停止 500ms 后自动触发翻译
- 翻译过程中显示加载状态

### 2.2 文件翻译

#### FR-TR-004 上传文件翻译

**需求描述**：用户可以上传文件进行翻译

**前置条件**：
- 文件格式为 Markdown、TXT 或 Word

**操作流程**：
1. 切换到"文件翻译"标签页
2. 点击上传区域或拖拽文件
3. 选择源语言和目标语言
4. 点击"翻译"按钮
5. 等待翻译完成
6. 下载翻译后的文件

**界面布局**：
```
┌─────────────────────────────────────────────────────────────┐
│ [文本翻译]    [文件翻译]                                     │
├─────────────────────────────────────────────────────────────┤
│ 源语言: [自动检测 ▼]              目标语言: [英语 ▼]        │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────────┐ │
│ │                                                         │ │
│ │                    📄                                   │ │
│ │              点击或拖拽上传文件                          │ │
│ │           支持 .md .txt .docx 格式                       │ │
│ │                                                         │ │
│ └─────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                        [翻译]                                │
└─────────────────────────────────────────────────────────────┘
```

**支持格式**：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| Markdown | .md | Markdown 文档 |
| 纯文本 | .txt | 纯文本文件 |
| Word | .docx | Microsoft Word 文档 |

## 5. 业务规则

### 5.1 翻译提示词

系统使用以下提示词模板：

```
你是一个专业的翻译助手。请将以下文本从{源语言}翻译成{目标语言}。

要求：
1. 保持原文的语气和风格
2. 准确传达原文含义
3. 使用地道的表达方式
4. 如果原文有专业术语，保持术语准确性

原文：
{用户输入的文本}

请直接输出翻译结果，不要添加任何解释。
```

### 5.2 文件翻译规则

- Word 文档保持原有格式（标题、段落、列表等）
- Markdown 文件保持原有格式（标题、列表、链接等）
- 翻译完成后保留原文件结构

### 5.3 历史记录规则

- 翻译历史保存最近 100 条记录
- 收藏的翻译不限数量
- 历史记录包含：原文、译文、语言对、时间

## 6. 边界情况

### 6.1 无可用提供商

**场景**：用户未配置任何 AI 提供商

**处理**：
- 显示提示："暂无可用的翻译服务，请先在设置中配置 AI 提供商"
- 提供"去设置"按钮跳转到提供商配置页面

### 6.2 翻译失败

**场景**：翻译过程中出错

**处理**：
- 显示错误提示
- 显示具体错误原因
- 提供"重试"按钮

### 6.3 文本过长

**场景**：用户输入超过 5000 字符

**处理**：
- 显示字符计数（红色）
- 禁用翻译按钮
- 提示："文本超过 5000 字符限制"

### 6.4 文件格式不支持

**场景**：用户上传不支持的文件格式

**处理**：
- 显示错误提示："不支持的文件格式，请上传 .md、.txt 或 .docx 文件"

### 6.5 文件过大

**场景**：上传文件超过 5MB

**处理**：
- 显示错误提示："文件大小超过限制（最大 5MB）"

### 6.6 语言检测失败

**场景**：自动检测源语言失败

**处理**：
- 提示用户手动选择源语言
- 显示："无法自动检测语言，请手动选择"

### 6.7 历史记录为空

**场景**：用户首次使用或清空了历史

**处理**：
- 左侧边栏显示空状态
- 提示："还没有翻译记录，开始翻译吧！"

### 6.8 网络中断

**场景**：翻译过程中网络中断

**处理**：
- 显示"网络连接失败，请检查网络"
- 提供"重试"按钮

### 6.9 Word 文件解析失败

**场景**：Word 文件格式损坏或不支持

**处理**：
- 显示错误提示："文件解析失败，请检查文件是否损坏"
- 建议用户尝试将文件另存为新格式后重试
