# 图像生成系统

## 1. 功能概述

图像生成系统提供文生图功能，基于现有的 AI 提供商配置，用户输入文本描述后 AI 生成对应图像。支持多种尺寸、风格、质量等参数配置。

## 2. 功能需求

### 2.1 图像生成

#### FR-IMG-001 文生图

**需求描述**：用户可以输入文本描述生成图像

**前置条件**：
- 至少配置了一个支持图像生成的提供商

**操作流程**：
1. 选择图像提供商和模型
2. 输入提示词描述想要生成的图像
3. 选择图像尺寸和数量
4. （可选）展开高级选项，设置风格、质量、种子等
5. 点击"生成图像"按钮
6. 等待生成完成，显示生成的图像

**参数说明**：

#### FR-IMG-007 下载图像

**需求描述**：用户可以下载生成的图像到本地

**操作流程**：
1. 在图像详情区域点击"下载图像"按钮
2. 系统弹出文件保存对话框
3. 用户选择保存位置
4. 图像保存成功，显示提示

**业务规则**：
- 默认文件名：`image_时间戳.png`

---

#### FR-IMG-008 删除图像

**需求描述**：用户可以删除不需要的图像

**操作流程**：
1. 在图像详情区域点击"删除"按钮
2. 弹出确认对话框
3. 用户确认后删除

**业务规则**：
- 删除图像记录的同时，删除本地存储的图像文件
- 删除后，右侧显示空状态

---

#### FR-IMG-009 使用相同参数重新生成

**需求描述**：用户可以使用历史图像的参数重新生成

**操作流程**：
1. 在图像详情区域点击"使用相同参数重新生成"
2. 参数自动填充到生成面板
3. 用户可以修改参数
4. 点击生成按钮

### 2.3 提供商与模型

#### FR-IMG-010 图像提供商复用

**需求描述**：图像生成使用现有的 AI 提供商配置系统

**业务规则**：
- 图像生成提供商在设置页面的"提供商配置"中统一管理
- 提供商可以同时提供文本模型和图像模型
- 模型类型通过 `type` 字段区分（text/multimodal/image 等）
- 只有包含 `image` 类型模型的提供商才在图像页面显示

**界面布局**：

```
│ 阿里百炼                                            ▼       │
```


## 4. 参数配置

### 4.1 尺寸选项

| 值 | 显示名称 | 说明 |
|----|----------|------|
| 512x512 | 512×512 | 正方形，小尺寸 |
| 1024x1024 | 1024×1024 | 正方形，标准尺寸 |
| 1024x768 | 1024×768 | 横向，标准尺寸 |
| 768x1024 | 768×1024 | 纵向，标准尺寸 |

### 4.2 数量选项

- 1 张
- 2 张
- 4 张

### 4.3 风格选项

| 值 | 显示名称 |
|----|----------|
| realistic | 写实 |
| anime | 动漫 |
| oil_painting | 油画 |
| watercolor | 水彩 |
| sketch | 素描 |
| 3d_render | 3D渲染 |

### 4.4 质量选项

| 值 | 显示名称 |
|----|----------|
| standard | 标准 |
| hd | 高清 |

### 4.5 种子值

- 范围：-1 到 2147483647
- -1 表示随机
- 固定种子值可用于复现生成结果

## 5. 业务规则

### 5.1 提示词规则

| 字段 | 验证规则 |
|------|----------|
| 提示词 | 必填，1-1000 字符 |
| 负面提示词 | 选填，最多 500 字符 |

### 5.2 生成限制

- 单次生成最多 4 张图像
- 生成超时时间：120 秒
- 并发生成：1 个任务（生成中时禁用生成按钮）

### 5.3 存储规则

- 生成的图像存储在用户数据目录
- 图像格式：PNG（优先）或 JPG
- 文件命名：`{taskId}.{ext}`

## 6. 边界情况

### 6.1 无可用提供商

**场景**：用户未配置任何支持图像生成的提供商

**处理**：
- 模型选择区域显示空状态
- 提示："暂无可用的图像生成提供商，请先在设置中配置"
- 提供"去设置"按钮跳转到提供商配置页面

### 6.2 生成失败

**场景**：图像生成过程中出错

**处理**：
- 在生成面板显示错误提示（红色 Alert）
- 显示具体错误原因（如：内容违规、API 限流、网络错误）
- 提供"重试"按钮

### 6.3 提示词违规

**场景**：提示词包含敏感内容

**处理**：
- 显示错误："提示词包含不适当内容，请修改"
- 生成按钮保持禁用

### 6.4 网络中断

**场景**：生成过程中网络中断

**处理**：
- 显示"网络连接失败，请检查网络"
- 任务状态标记为"失败"
- 提供"重试"按钮

### 6.5 历史记录为空

**场景**：用户首次使用或清空了历史

**处理**：
- 左侧边栏显示空状态
- 提示："还没有生成过图像，开始创作吧！"
- 右侧显示引导提示

### 6.6 未选中图像

**场景**：用户未在历史列表中选择图像

**处理**：
- 右侧结果区域显示空状态
- 提示："选择一张图像查看详情，或开始生成新图像"
