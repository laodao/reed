# AI 提供商系统

## 1. 功能概述

AI 提供商系统用于管理多个 AI 服务提供商的配置，包括 API 密钥、模型列表、连接参数等。

#### FR-PROV-003 编辑提供商配置

**需求描述**：用户可以修改已配置的提供商信息

**操作流程**：
1. 在提供商列表中点击"编辑"按钮
2. 显示编辑对话框，预填充当前配置
3. 修改配置信息
4. 点击"保存"更新配置

**可编辑内容**：
- 配置名称
- API 密钥（显示为掩码，可重新输入）
- 基础 URL
- 自定义请求头
- 启用/禁用状态
- 是否默认

---

#### FR-PROV-004 删除提供商配置

**需求描述**：用户可以删除不再需要的提供商配置

**操作流程**：
1. 在提供商列表中点击"删除"按钮
2. 系统检查是否有关联的对话
3. 如果有关联对话，提示用户：
   - "此提供商关联了 X 个对话，删除后这些对话将无法继续使用，是否继续？"
4. 用户确认后删除

**业务规则**：
- 删除提供商时，关联的对话保留，但提供商配置 ID 置空
- 正在使用的提供商（有正在进行的对话）不能删除

---

#### FR-PROV-005 测试连接

**需求描述**：用户可以测试提供商配置是否正确

**操作流程**：
1. 在配置页面点击"测试连接"按钮
2. 系统使用配置的 API 密钥发送测试请求
3. 显示测试结果

**测试内容**：
- 验证 API 密钥是否有效
- 验证基础 URL 是否可达
- 获取可用模型列表

**结果反馈**：
- 成功：显示"连接成功，发现 X 个可用模型"
- 失败：显示具体错误原因（如密钥无效、网络超时等）

---

#### FR-PROV-006 设为默认

**需求描述**：用户可以设置默认的提供商

**操作流程**：
1. 在提供商卡片上点击"设为默认"按钮
2. 该提供商变为默认提供商
3. 之前的默认提供商取消默认标记

**业务规则**：
- 只能有一个默认提供商
- 创建新对话时，默认使用此提供商

## 4. 业务规则

### 4.1 配置验证

| 字段 | 验证规则 |
|------|----------|
| 配置名称 | 必填，1-50 字符，不能重复 |
| API 密钥 | 必填，格式根据提供商类型验证 |
| 基础 URL | 选填，必须是有效的 URL 格式 |

### 4.2 启用/禁用规则

- 禁用的提供商不在对话界面的模型选择器中显示
- 禁用的提供商的对话仍然可以查看，但不能继续对话
- 重新启用后，对话可以继续

### 4.3 默认提供商规则

- 新建对话时，默认使用默认提供商的默认模型
- 如果没有设置默认提供商，使用第一个启用的提供商
- 如果没有任何启用的提供商，提示用户配置

## 5. 边界情况

### 5.1 API 密钥过期

**场景**：保存的 API 密钥已过期或被撤销

**处理**：
- 对话时显示错误："API 密钥无效，请检查配置"
- 提供跳转到编辑页面的链接

### 5.2 模型不可用

**场景**：已配置的模型被提供商下架

**处理**：
- 模型列表中标记为"不可用"
- 尝试使用时显示错误提示

### 5.3 网络超时

**场景**：连接提供商 API 超时

**处理**：
- 显示超时错误
- 提供"重试"按钮
- 建议检查网络或更换基础 URL
