【成熟硬朗风 · 面部专业描述】
纵向三庭：三庭比例端正，中庭饱满，下庭颏部方正有力，面部重心下沉，凸显成熟硬朗气场。
骨骼与皮肉：骨相突出、线条分明，颧骨立体，下颌角明确，颏部棱角清晰，无柔弱感。
眉眼：浓眉剑眉，眉骨突出；目光深邃坚毅，眼窝略深，眼神锐利有神。
鼻部 / 下颌：鼻梁高挺，鼻翼略宽；下颌线条硬朗，方正下颌角。
