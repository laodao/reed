剧集制作 · 新设计原型

基于 docs/superpowers/specs/2026-05-02-episode-production-pipeline-design.md 的设计稿做的高保真静态原型。 数据全是硬编码 mock，仅展示交互形态和 UI 结构。点击下面卡片查看各阶段。

原型说明：静态 HTML（Tailwind CDN + 自定义 shell.css）， 浏览器直接打开 file:// 即可，不需要起服务器。 所有按钮 / 链接均无后端逻辑，仅做视觉效果展示。 数据 mock 自一个虚构的"江湖故事"剧集项目。

设计要点

  • 顶部进度条：6 阶段始终可见，软引导（可任意跳转，缺前置时弹提示）
  • 左侧资产侧栏：4 大类（角色 / 地点 / 物品 / 语音）+ 数字徽章，任何阶段都能查 / 编辑资产
  • 底部迷你时间线：始终可见，预览当前已生产分镜的累计时长
  • 双来源标签：linked_lw（来自长文）/ standalone（剧集独立）
  • 九宫格：时间顺序的 N 张关键帧（2~9，按复杂度可调；UI 默认 3×3 视觉布局）
  • 3D 占位：3D 标签预留（本 phase 不实现）
