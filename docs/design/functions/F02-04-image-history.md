| 属性 | 值 |

## 3. 数据设计

```typescript
// 历史记录查询参数
interface HistoryQuery {
  page: number
  pageSize: number
  favorite?: boolean       // 只看收藏
  provider?: string        // 按提供商筛选
  dateRange?: [Date, Date] // 日期范围
}

// 历史记录响应
interface HistoryResponse {
  images: ImageRecord[]
  total: number
  hasMore: boolean
}
```

## 4. 函数设计

```typescript
/**
 * 加载历史记录
 * @param query - 查询参数
 * @returns Promise<HistoryResponse>
 */
async function loadHistory(query: HistoryQuery): Promise<HistoryResponse>

/**
 * 切换收藏状态
 * @param imageId - 图像ID
 */
async function toggleFavorite(imageId: string): Promise<void>

/**
 * 删除图像
 * @param imageId - 图像ID
 */
async function deleteImage(imageId: string): Promise<void>

/**
 * 复制提示词
 * @param prompt - 提示词内容
 */
function copyPrompt(prompt: string): void
```
