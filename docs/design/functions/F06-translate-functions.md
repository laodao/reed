# M06 - 翻译模块功能设计

## F06-01 文本翻译

### 功能概述
| 属性 | 值 |
|-----|-----|
| 功能编号 | F06-01 |
| 功能名称 | 文本翻译 |
| 优先级 | P0 |
| 描述 | 翻译输入的文本 |

### 界面
```
┌─────────────────────────────────────────────────────────────────────────┐
│  翻译                                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│  ┌────────────────────────────┐  ┌────────────────────────────────────┐│
│  │ 源语言: [自动检测 ▼]       │  │ 目标语言: [英语 ▼]                 ││
│  ├────────────────────────────┤  ├────────────────────────────────────┤│
│  │                            │  │                                    ││
│  │  你好，世界！              │  │  Hello, world!                     ││
│  │  这是一段测试文本。        │  │  This is a test text.              ││
│  │                            │  │                                    ││
│  │                            │  │                                    ││
│  ├────────────────────────────┤  ├────────────────────────────────────┤│
│  │ 字数: 18    [清空]         │  │ [复制] [朗读]                      ││
│  └────────────────────────────┘  └────────────────────────────────────┘│
│                                                                          │
│                         [⇄ 交换语言]                                     │
│                                                                          │
│  翻译引擎: [通义千问 ▼]                                                  │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 函数
```typescript
/**
 * 翻译文本
 * @param request - 翻译请求
 * @returns Promise<TranslateResponse>
 */
async function translate(request: TranslateRequest): Promise<TranslateResponse>

interface TranslateRequest {
  text: string           // 要翻译的文本（最多10000字）
  sourceLang?: string    // 源语言（空则自动检测）
  targetLang: string     // 目标语言
  provider?: string      // 提供商
}

interface TranslateResponse {
  success: boolean
  translatedText: string // 翻译结果
  detectedLang?: string  // 检测到的源语言
  confidence?: number    // 检测置信度
}
```

## F06-02 语言检测

### 功能概述
| 属性 | 值 |
|-----|-----|
| 功能编号 | F06-02 |
| 功能名称 | 语言检测 |
| 优先级 | P1 |
| 描述 | 自动检测文本的语言 |

### 函数
```typescript
/**
 * 检测语言
 * @param text - 文本内容
 * @returns Promise<LanguageDetectResult>
 */
async function detectLanguage(text: string): Promise<LanguageDetectResult>

interface LanguageDetectResult {
  language: string       // 语言代码
  confidence: number     // 置信度 0-1
  alternatives?: {       // 备选语言
    language: string
    confidence: number
  }[]
}
```
