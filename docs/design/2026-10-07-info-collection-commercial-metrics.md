# 信息搜集模块：商用验收指标（终版：3 门 1 星）

- 日期：2026-10-07
- 状态：**待评审**
- 关联：主设计 `docs/design/2026-10-07-info-collection-design.md`（§4 质量体系）
- 修订：v3 精简至 4 项并逐项做可行性审核——砍掉不可行门槛（成本 ±20%、TTFV 硬门槛），修正小样本不可行判据（+10pt/零子类回退）

## 0. 两条原则（先于一切指标）

1. **宽进严出**：严格标准只设在**验收层**（评测集、发布判定），**永远不设在采集运行时**。运行时一切失败（抓取失败/引句不匹配/恒等式不平/复核不一致）都降级为"待审/标注/手动导入"，**不存在"指标太严导致采不到数据"的结局**——数据宁多收待审，出口由人审与验收把关。
2. **只留"可能失败、失败有后果"的指标**：结构性保证归测试套件 CI 断言（快照 100%、日志完整率、熔断器等——是"做完"的定义，坏了是 bug 不是指标波动）；过程健康线归主文档 §4 质量仪表做运行监控；商用判定只看本文 4 项。

---

## 1. 三道发布闸门（发布前必须全过）

### G1 零静默错误（凡错必标）——生死线

- **定义**：入库后 30 天内被发现、且当时无任何系统标注（needs_review / 孤证 / 低置信 / 更正记录）的错误条数。
- **门槛**：=0。事件型一票冻结线：用户先于系统发现一个无标注错数 → 商用资格冻结，复盘后恢复。
- **可行性审核**：✓ 可行。它不是"零错误"（真实网页数据必有错，做不到也不该追求），而是"凡错必标"——错误的合法出路是标注，不是拒收，**不会阻碍采集**。测量靠用户反馈 + 月度固定抽检 20 条兜底（样本小时防止"没人看=没错误"的假阳性）。
- **质量作用**：这一条逼出了整条防幻觉链——引句锚定与回验、双模型复核、冲突归因、孤证标记，全是为"每条数据的不确定性都可视"服务的。它是"看起来很全但暗藏错数"的库的终极防线。

### G2 溯源正确率 ≥90%——商用卖点的直接量化

- **定义**：抽样核验"产出的引用确实支持结论"的比例（不是"链接存在"，是"内容支撑"；防假溯源）。
- **门槛**：评测集人工判定 ≥90%；发布后季度抽检守线。
- **可行性审核**：✓ 可行。评测集 20-30 问的引用判定人工可完成；且它是**产出质量指标，不是采集过滤器**——运行时任何数据不因此被拒收。有引句锚定打底（锚不中的抽取在抽取时已拒收），90% 是可达的。
- **质量作用**：直接衡量"引句锚定 + 回验 + 快照"链路的端到端效果。它防的是最隐蔽的失败——引用了真实存在的源，但源并不支持结论。

### G3 评测不输基线、且溯源显著赢——价值证明（v3 修正）

- **定义**：同题同模型同预算，资料库辅助 vs 现搜现答。
- **门槛**：①答案准确率**不输基线**（容差 ±1 题，小样本噪声内）；②溯源正确率 ≥ 基线 **+15pt**（真赢点——现搜现答天然没有稳定溯源）；③无显著回退（任一子类容差内，取代原"零子类回退"）。任一不过不发布，如实登记差距回归设计。
- **可行性审核**：⚠ 原判据（准确率 +10pt、零子类回退）**不可行**，已修正——60-90 问的评测集上，+10pt 可能超出可达余量（飞轮教训：全上下文基线常打平专用系统），"零回退"会被单题噪声触发。修正后的判据承认"准确率打平 + 溯源碾压"就是赢，这正是资料库的价值主张。
- **质量作用**：强制模块回答"资料库值得养吗"，防止做成"每次其实还在现搜"的花架子；溯源项把质量建设的火力引向本模块真正的差异化。

## 2. 北极星（非闸门）：W2 回访率 ≥40%

- **定义**：首次使用后第 2 周内自发再次使用的新用户占比。
- **门槛**：用户数 <20 时**只记录不判线**（小样本是噪声）；≥20 后按月观察，连续两月破线触发复盘。
- **可行性审核**：✓ 作为观察项可行，✗ 作为发布闸门不可行（纯发布后指标、受产品整体混淆、早期无样本）。
- **质量作用**：唯一能证明"质量改进方向对不对"的外部行为信号；与 G1 组成发布后双看板。

## 3. 盲测验收（定性补 Numbers）

n≥3 名未参与设计的真实用户，自选主题、无文档、全流程：

1. **敢引用**：无提示引用产出数值比例 ≥80%，且发现的未标注错误 =0（对 G1/G2）；
2. **成本说得清**：仅凭实耗报告说出花费数量级（成本已退出闸门，此处验证报告可读性）；
3. **失败不骂人**：失败场景严重度评级无 critical/major 未缓解项；
4. **第二周回来**：W2 自发回访（对北极星）。

**可商用判定：G1-G3 全过 + 盲测四条过。发布后月度只盯 G1 与北极星。**

## 4. 可行性审核记录（v2 六项 → 终版去向）

| v2 指标 | 审核结论 | 去向 |
|---------|---------|------|
| 静默错误 =0 | ✓ 可行，保留 | **G1** |
| 溯源正确率 ≥90% | ✓ 可行，保留 | **G2** |
| 评测 +10pt / 零子类回退 | ✗ 小样本不可行：+10pt 可能超余量，零回退被单题噪声触发 | 修正判据 → **G3** |
| 预估偏差 ≤20% | ✗ 不可行：探索性采集方差天然大；绝对偏差判据激励系统高估预算"作弊" | 零未授权超支归**熔断器 CI 断言**（工程保证）；偏差改**仪表报警线**（>50% 提示校准预估器），不进验收 |
| TTFV P50 ≤10min | ⚠ 可测但受用户审蓝图时长与引擎延迟混淆 | 降为**设计目标**（驱动冷启动设计）+ 可用性测试观察项，不设门槛 |
| W2 回访 ≥40% | ⚠ 早期无样本 | 保留为**北极星**，n≥20 才判线 |

## 5. 执行流程

```
M0：评测集+基线跑通（G3 判据基线化）
M2：G3 全过 → 商用候选（3-5 人受限灰度）
M4+发布前：G1-G3 全过 + 盲测四条 → 商用发布
发布后：月度看板 = G1（静默错误）+ 北极星（W2 回访），破线即冻结复盘
G2/G3 门槛数值为初值，M0 基线后校准一次锁版，只升不降
```
