# 长文写作输出质量评估报告（真机实测）

- 日期：2026-09-09
- 方法：真机 Electron + 真实 LLM（应用当前配置的对话模型），采集脚本 `scripts/e2e-story-room-quality.cjs`；三轮研讨 → 提炼概要/人物卡 → 采纳 → 全量落盘 `output-quality-sample.json`
- 样本：`docs/design/output-quality-sample.json`

## 1. 主编对话输出：质量显著高于预期 ✅

轮 1（要求评判故事核）的回复表现出完整的主编人格纪律：

- **敢反驳**："骨架有了，但作为故事核不够硬"，直接指出**双动机互相稀释**（洗冤=事实回归 vs 复仇=情绪出口）与**玄天鉴是空的麦高芬**两个结构性问题；
- **先问后提**：收束在一个尖锐问题——"玄天鉴到底落在谁手里？这个答案直接决定你的故事层次"；
- **给选项给取舍**：A 复仇爽文（爽感强但俗、洗冤走过场）vs B 真相腐坏（慢热但弧光和格局）。

轮 3（世界观）同样给出判断标准（"每个势力都必须回答与失窃案的关系"）+ 两套势力方案 + 合成建议 + 收束提问。**对话层不需要优化，需要保护**：这套人格质量依赖强模型，账本提取等旁路任务切便宜档时不得反噬主编档位。

## 2. 实测发现并已修复的缺陷

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 1 | 整理器出**全空概要卡** | 整理器上下文**没有研讨实录**（圣经空/账本空/前情提要空），"宁缺毋滥"纪律下模型只能返回空模板 | 已修：注入最近 12 条研讨实录（`recentTranscript`）；单测覆盖注入路径 |
| 2 | 整理器偶发 "No output generated" | JSON-only 指令经 loop/streamText 偶发空输出 | 已修：整理器改直调 generateText（同静默提取路径），删除 kit 装配 |
| 3 | 静默提取被 "用户取消" 中断 | 轮后静默任务复用发送控制器的 signal，被轮内 abort 波及 | 已修：解耦 signal + 空输出重试一次 |
| 4 | distill 直调 400 "input.contents" | 脚本/宿主默认模型指向**嵌入端点**（阿里 MaaS 嵌入格式错误签名） | 部分修：UI 路径传参正确+正向评分已挡；宿主**默认模型治理**待平台级处理（见 O5） |
| 5 | 提取失败日志无法定位 | catch 记录 Error 对象序列化为 `{}` | 已修：日志带 name+message，直调带 url/status/responseBody |

## 3. 符合设计的"空账本"

三轮样本中账本为 0 条**并非缺陷**：讨论尚处"给选项未拍板"阶段，提取器按纪律不把未定方向灌进账本。这验证了"账本记结论"的设计——但引出 O3 优化：讨论期的 tentative 记录可以更进取（见下）。

## 4. 输出质量优化方案（按影响排序）

- **O1 整理器实录注入（已修待复验）**：重跑 `e2e-story-room-quality.cjs` 应产出有实质内容的概要/人物卡。
- **O2 模型分档落地**：主编=强模型；账本提取/滚动摘要/整理器=便宜档（接 `AGENT_MODEL_CHEAP`，直调路径已隔离，切换无风险）。长篇全程成本弹性主要来自这里。
- **O3 提取器进取度调参**：当前"只记已拍板"过于保守——讨论期出现的 A/B 方案、命名实体（幽篁谷/北冥府）值得以 tentative 记入账本（`op:add, status:tentative, points:[方案A…/方案B…]`），让"讨论成果"面板在讨论期就有内容感；prompt 一行改动。
- **O4 章节正文质量**：38 号已验证按勾选上下文生成可用；升级路径 = 圣经自动引用（holistic 方案 P2），并在生成后追加"章节自检"（一致性词表+前文复述）。
- **O5 默认模型治理**：宿主 `resolveModel` 无参兜底可能落到嵌入/多媒体端点（本轮 400 根因）；平台层应提供"chat-capable 默认模型"配置并在不可用时报错而非静默选错。
- **O6 观测**：直调路径（整理器/提取/摘要）不经 RunRegistry——如需工作台可见，加轻量 `run-registry` 直登记（可选）。

## 5. 残留与建议

- 实测采样为单一题材（玄幻）单会话；建议用都市/言情各跑一轮验证问题库分叉与提取稳健性。
- 伏笔/章节卡的真机全链路（含采纳）待一轮完整验证（单测已覆盖）。
- 章节提取管线的伏笔识别段未接（38 号链路，单独一轮）。
