## 4. 数据设计

### 4.1 数据结构

```typescript
// 搜索请求
interface SearchRequest {
  query: string                 // 搜索关键词
  engine?: 'bing' | 'baidu' | 'google'  // 搜索引擎
  count?: number                // 结果数量
}

// 搜索结果项
interface SearchResultItem {
  title: string                 // 标题
  url: string                   // 链接
  snippet: string               // 摘要
  favicon?: string              // 网站图标
}

// 搜索响应
interface SearchResponse {
  success: boolean
  results: SearchResultItem[]   // 搜索结果
  summary?: string              // AI总结
  error?: string                // 错误信息
}

// 搜索历史
interface SearchHistory {
  id: string                    // 记录ID
  query: string                 // 搜索关键词
  engine: string                // 使用的搜索引擎
  resultCount: number           // 结果数量
  createdAt: Date               // 搜索时间
}

// 搜索引擎配置
interface SearchEngine {
  id: string                    // 引擎ID
  name: string                  // 显示名称
  icon?: string                 // 图标
  enabled: boolean              // 是否启用
  requiresKey: boolean          // 是否需要API密钥
  configured: boolean           // 是否已配置
}
```

### 4.2 数据库表

```sql
-- 搜索历史表
CREATE TABLE search_history (
  id TEXT PRIMARY KEY,
  query TEXT NOT NULL,
  engine TEXT NOT NULL,
  result_count INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_search_created_at ON search_history(created_at DESC);
```

## 5. IPC接口设计

| 通道 | 方法 | 参数 | 返回值 | 描述 |
|-----|------|-----|-------|------|
| search:engines | GET | - | { success, engines } | 获取搜索引擎列表 |
| search:query | SEARCH | request: SearchRequest | { success, ...SearchResponse } | 执行搜索 |
| search:history | GET | page?, pageSize? | { success, history, total } | 获取搜索历史 |
| search:clear-history | DELETE | - | { success } | 清空历史 |

## 7. 核心流程

### 7.1 搜索流程

```
用户输入搜索词
    │
    ▼
选择搜索引擎
    │
    ▼
点击"搜索"按钮
    │
    ▼
调用 search:query IPC
    │
    ▼
主进程接收请求
    │
    ├── 调用搜索引擎API
    │
    ├── 解析搜索结果
    │
    ├── 调用AI进行总结
    │
    ├── 保存搜索历史
    │
    ▼
返回结果和总结
    │
    ▼
前端显示结果
```

### 7.2 AI总结流程

```
获取搜索结果
    │
    ▼
构建总结提示词
    │
    ├── 用户问题
    │
    ├── 搜索结果摘要
    │
    ▼
调用AI对话接口
    │
    ▼
获取AI总结
    │
    ▼
返回给前端显示
```

## 8. 错误处理

| 错误场景 | 错误码 | 错误信息 | 处理方式 |
|---------|-------|---------|---------|
| 搜索词为空 | E801 | 请输入搜索内容 | 前端提示 |
| 搜索引擎未配置 | E802 | 请先配置搜索引擎的API密钥 | 弹窗提示 |
| 搜索失败 | E803 | 搜索失败：{原因} | 弹窗提示 |
| 网络错误 | E804 | 网络连接失败 | 弹窗提示 |

## 9. 搜索引擎配置

### 9.1 必应搜索 (Bing)
- API: Bing Web Search API
- 需要配置: API Key
- 特点: 结果质量高，支持中文

### 9.2 百度搜索
- API: 百度搜索API
- 需要配置: API Key
- 特点: 中文搜索效果好

### 9.3 Google搜索 (可选)
- API: Google Custom Search API
- 需要配置: API Key + CX
- 特点: 结果全面，但需要代理
