# M03 - 视频生成模块设计

## 1. 模块概述

| 属性 | 值 |
|-----|-----|
| 模块编号 | M03 |
| 模块名称 | 视频生成 |
| 模块代码 | video |
| 优先级 | P2 |
| 描述 | 提供AI视频生成功能，支持文生视频和图生视频 |

## 4. 数据设计

### 4.1 数据结构

```typescript
// 视频记录
interface VideoRecord {
  id: string                    // 视频ID
  provider: string              // 提供商
  model: string                 // 使用的模型
  prompt: string                // 提示词
  sourceImage?: string          // 源图片（图生视频）
  videoUrl?: string             // 视频URL
  localPath?: string            // 本地存储路径
  duration: number              // 时长（秒）
  width: number                 // 宽度
  height: number                // 高度
  status: 'pending' | 'processing' | 'completed' | 'failed'  // 状态
  progress?: number             // 进度（0-100）
  error?: string                // 错误信息
  createdAt: Date               // 创建时间
}

// 视频生成请求
interface GenerateVideoRequest {
  provider: string              // 提供商
  prompt: string                // 提示词
  sourceImage?: string          // 源图片（图生视频）
  duration?: number             // 时长（秒）
  width?: number                // 宽度
  height?: number               // 高度
}

// 视频提供商
interface VideoProvider {
  id: string                    // 提供商ID
  name: string                  // 显示名称
  models: VideoModel[]          // 可用模型
  configured: boolean           // 是否已配置
}

// 视频模型
interface VideoModel {
  id: string                    // 模型ID
  name: string                  // 显示名称
  maxDuration: number           // 最大时长
  resolutions: string[]         // 支持的分辨率
  supportsImageToVideo: boolean // 是否支持图生视频
}
```

## 5. IPC接口设计

| 通道 | 方法 | 参数 | 返回值 | 描述 |
|-----|------|-----|-------|------|
| video:get-providers | GET | - | { success, providers } | 获取提供商列表 |
| video:generate | GENERATE | request | { success, taskId } | 开始生成视频 |
| video:status | GET | taskId | { success, status, progress } | 查询生成状态 |
| video:list | GET | page?, pageSize? | { success, videos, total } | 获取历史列表 |
| video:delete | DELETE | id: string | { success } | 删除视频 |

## 6. 核心流程

### 6.1 视频生成流程

```
用户输入提示词
    │
    ▼
设置视频参数
    │
    ▼
点击"生成"按钮
    │
    ▼
调用 video:generate IPC
    │
    ▼
主进程提交生成任务
    │
    ▼
返回任务ID
    │
    ▼
前端轮询 video:status
    │
    ├── 显示进度
    │
    ▼
生成完成
    │
    ├── 下载视频到本地
    │
    ├── 更新数据库状态
    │
    ▼
前端显示视频
```

## 7. 错误处理

| 错误场景 | 错误码 | 错误信息 | 处理方式 |
|---------|-------|---------|---------|
| 提示词为空 | E301 | 请输入提示词 | 前端提示 |
| API密钥未配置 | E302 | 请先配置视频生成服务的API密钥 | 弹窗提示 |
| 生成失败 | E303 | 视频生成失败：{原因} | 弹窗提示 |
| 超时 | E304 | 生成超时，请重试 | 弹窗提示 |
