# AI工具箱 - 模块设计总览

## 1. 系统概述

AI工具箱是一个基于 Electron + Vue3 + TypeScript 的桌面应用程序，集成多种AI能力，为用户提供统一的AI工具平台。

## 2. 模块划分

系统按功能划分为以下9个模块：

| 模块编号 | 模块名称 | 模块代码 | 功能描述 | 优先级 |
|---------|---------|---------|---------|-------|
| M01 | AI对话 | ai-dialog | 提供多模型AI对话功能 | P0 |
| M02 | 图像生成 | image | AI图像生成功能 | P1 |
| M03 | 视频生成 | video | AI视频生成功能 | P2 |
| M04 | OCR识别 | ocr | 图片文字识别功能 | P1 |
| M05 | 语音转换 | voice | 语音合成和识别功能 | P1 |
| M06 | 翻译 | translate | 多语言翻译功能 | P1 |
| M07 | 知识库 | knowledge | 知识管理和RAG功能 | P2 |
| M08 | 网络搜索 | search | 联网搜索功能 | P2 |
| M09 | 系统设置 | settings | 系统配置和API管理 | P0 |

## 4. 技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      渲染进程 (Vue3)                         │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐           │
│  │  Views  │ │Components│ │ Stores  │ │ Router  │           │
```

## 7. 数据库设计概览

### 核心表

| 表名 | 描述 | 所属模块 |
|-----|------|---------|
| settings | 系统设置 | M09 |
| api_keys | API密钥（加密） | M09 |
| dialogs | 对话列表 | M01 |
| dialog_messages | 对话消息 | M01 |
| roles | 角色模板 | M01 |
| images | 生成图像记录 | M02 |
| knowledge_bases | 知识库 | M07 |
| knowledge_documents | 知识文档 | M07 |

## 8. IPC通道命名规范

格式：`{模块}:{操作}`

示例：
- `dialog:list` - 获取对话列表
- `dialog:create` - 创建对话
- `image:generate` - 生成图像
- `settings:get` - 获取设置
