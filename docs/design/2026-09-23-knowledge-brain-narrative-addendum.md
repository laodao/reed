## 0. 结论摘要

1. 用户诉求的五类知识中，**三类已被 v2 完整覆盖**（套路→模式卡 plot-pattern §5.4；世界观体系→设定卡 setting-pattern + P-5；故事线→leads-to 事件链 + 情节卡），但**尚未实现**——设计完成、代码为零（全库无 kb_atoms/kb_notes/kb_entities/brainConfig 痕迹），总体处于 M0 未动工状态。
2. 两类诉求是 v2 的真实缺口：**人物角色设定**只有实体层（kb_entities 的「人物」实体），没有跨书原型归纳的卡片类型；**伏笔**只是视角卡的一句示例（「看伏笔与回收」），没有结构化表示。本文给出最小 diff 增订：一个 union 类型成员 + 一条边关系 + 两段 prompt + 两个配置开关，零新表、零新治理机制。

## 2. 增补 A：人物原型卡（character-pattern）

### 2.1 为什么需要

用户的例子直接给出了原型级知识的形态：「诛仙=木讷农村少年+奇遇」「凡人=同类起点但靠自己用心和剑走偏锋」——这是**同骨架、异参数**的观察，与 v2 §5.4「一张模式卡，N 个实例」完全同构。但落点既不是事件序列（情节卡）也不是规则集（设定卡），而是**人物的功能结构**：欲望×缺陷×能力来路×关系位×弧线。

现有设计里人物知识只有两层：具体人物实体（张小凡）+ 关于人物的论断（atom）。缺的正是向上归纳的那一跳——「木讷坚韧型底层主角」这个可复用的东西无处安放。

### 2.2 schema 变更（最小 diff）

```ts
// v2 §6.4 KbNoteType 增一个成员：
export type KbNoteType =
  | 'methodology' | 'insight' | 'synthesis'
  | 'plot-pattern' | 'setting-pattern'
  | 'character-pattern'        // ← 新增：人物原型卡
  | 'lens' | 'skill-seed'

// patternSkeleton 对 character-pattern 的语义约定（复用字段，不加列）：
// 五维骨架 { 欲望, 缺陷, 能力来路, 关系位, 弧线终点 }
// + 参数槽定义（出身/缺陷的社会化形态/情感绑定密度/金手指耦合度…）
// patternInstances 照旧：[{ documentId, 参数取值, 变形说明, evidenceAtomIds[] }]
```

其余全部复用：patternInstances / classicScore（浮现式经典性）/ proposed 治理 / version 演化 / 装配红线（注入骨架不注入血肉）。

### 2.3 提炼落点：P-7（P-5 同构变体）

```
P-7 CHARACTER-PATTERN（人物原型归纳）
输入：跨书的人物论断簇（P2 聚类的天然产物：subject 挂人物实体、
      type=fact/claim 的论断按功能位聚类——主角位/情感位/导师位/对手位…；
      Chi 1981 纪律：按功能结构聚类，不按词面「冷/木讷」聚类）
产出：patternSkeleton=五维骨架+参数槽；patternInstances=每本书该位角色的
      参数取值+变形说明+evidenceAtomIds；对照注记（同骨架异参数的书写差异）
开关：cfg.patterns.characterEnabled（缺省 false；随 M3 设定卡同批试点——
      人物归纳风险低于情节对齐、高于设定规则）
```

### 2.4 决策记录：为什么不加 character-archetype 实体类型

v2 哲学第 4 条：论断层稳定、解释层可重建。实体层承载**具体人物**（「能否拥有百科词条」判据）；原型是**解释层产物**（把多个具体人物读成同一个模式）——放卡片层才能被反复改写、提议、否决。若做成实体类型，原型会获得实体的稳定性表象，违背「理解是活文档」。样张 §4.3 即按此分层书写。

## 3. 增补 B：伏笔线（sets-up 边 + 伏笔扫描）

### 3.1 为什么需要

伏笔是叙事知识里唯一**跨距**的结构（埋设与回收可能相隔几十万字），leads-to 的句级因果表达不了它；视角卡能「看出」伏笔，但看到的产物没有家。用户把它与故事线并列表述（「故事线的设定，伏笔等等」），是把它当一等知识的信号。

### 3.2 schema 变更

```ts
// v2 §6.3 KbEdgeRelation 增一条（详细设计 §1.3 DDL 注释同步补词）：
export type KbEdgeRelation =
  | 'supports' | 'refutes' | 'refines' | 'exemplifies'
  | 'same-as' | 'depends-on' | 'applies-to'
  | 'leads-to'
  | 'instance-of'
  | 'sets-up'      // ← 新增：埋设。source=伏笔论断（承诺），target=回收论断（兑现）
```

- 方向语义：**埋设 -sets-up-> 回收**，一条边表达完整关系（回收端不需要反向边，邻接查询双向可达）。
- 与 leads-to 的分界：leads-to 是情节世界内的因果/转折（A 导致 B）；sets-up 是作者技法层的承诺-兑现（读者视角的呼应，与因果无关、甚至刻意反因果）。

### 3.3 检测落点：复用 open-question + distill 第 7 步

- **P1 不改**。基础遍的 `open-question` 类型论断（「文本未交代的悬置点」）天然就是伏笔候选池——该类型在 v2 已是一等公民，本次等于给它接上消费端。
- distill 流程（详细设计 §6.2）增**第 7 步：伏笔扫描**。输入=该书悬念型论断（按时序）+ 候选回收论断（内容与前文承诺吻合的 fact），P-8 一次调用输出 sets-up 边提案（带 evidence）；confidence 压低、`verified=0` 进人审，批准后置 1。
- 配置：`brainConfig.patterns` 增 `foreshadowEnabled`（缺省 false，按库开启——剧情类语料收益最大，工具书库开它纯属浪费）。
- 台账：并入 distill 台账行（stats_json 记 `{foreshadowEdges}`），不新增 pass_type。

### 3.4 查询与展示

- 「未回收伏笔」= 悬念型论断中**无出边 sets-up** 的集合——零图算法，一次 SQL。悬空伏笔对研究域是「作者挖了没填的坑」，对创作装配是现成的钩子素材。
- AtomListPanel 增「伏笔线」过滤视图（埋设端/回收端/悬空三态），不新增组件。
- 与视角卡咬合：伏笔视角卡（样张 §4.6）的视角遍产物（观感论断）可作 P-8 的**线索输入**——观感不进公共层裁决，但可以指路。

### 3.5 风险与预期管理

| 风险 | 缓解 |
|---|---|
| 跨距连边错误率高（比事件链对齐更难一个量级） | 只在人审流内产出（verified=0 起步）；样张 §4.4 作 prompt 金标准；验收按「候选生成器」口径——进前 5 候选即达标，不要求自动确认 |
| 与 leads-to 混淆 | P-8 与 P-1 事件链输出物理分离（不同调用、不同 schema）；判例写死：「因果相邻=leads-to；呼应不相邻=sets-up」 |
| 悬空伏笔误报（并非伏笔的 open-question） | 前置过滤：仅「具备承诺形态」（具体异物/异常行为/未解事件）的悬念论断进候选 |

## 4. 提炼样张：《诛仙》×《凡人修仙传》

### 4.0 使用说明

- 以下 13 张卡为**人工手写金标准**，三个用途：①P-4/P-5/P-7/P-8 prompt 的 few-shot 对照物（产出长这样）；②M0 评测库 A（同类型小说）综合型 20 问的出题母本；③评审两个增补 schema 能否接住真实知识。
- 格式对齐 v2 §5.4（骨架/参数槽/实例登记/风险注记），可直接填入 patternSkeleton / patternInstances 的 JSON 约定。
- 关键门派/人物名已对照公开资料复核（§6）；其余以原文为准。卡片不收录任何原文段落——「停在骨架+参数+反例」红线的自我执行。

### 4.1 情节模式卡

#### 卡 P-1 被动奇遇：至宝即诅咒

> - **骨架**：底层孤儿起点 → 无意卷入血案 → 获得来路不正的至宝（金手指与原罪同体）→ 至宝既是力量又是嫌疑/侵蚀 → 主角在「被宝物定义」的处境中挣扎 → 真相揭露时，宝物来历与开场血案同源
> - **参数槽**：至宝性质（凶器/魔物/诅咒物）｜获得方式（遗赠/拾得/强加）｜代价形态（身份嫌疑/心魔侵蚀/道德拖累）｜解除条件（真相大白/斩断因果/超脱宝物）
> - **实例**：《诛仙》——烧火棍（魔教至宝摄魂与噬血珠的合体）以伙房烧火棍的降格形态入手，来路系天音寺普智遗赠，而普智正是草庙村血案真凶：宝物来历与血案真相焊死为同一悬念，张小凡一生被这根棍子定义
> - **反例对照**：《凡人》掌天瓶来历清白、无人知晓，代价≈保密——同是「无名至宝开局」却不携带因果，故全书危机改由寿元焦虑与主角性格制造（联动卡 I-1）
> - **风险注记**：代价形态写得过轻（仅藏拙）则模式塌缩为普通金手指文；宿命感是该模式的全部张力来源

#### 卡 P-2 底层入场·体系边缘攀爬

> - **骨架**：主角以体系最低位入场（杂役/垫底脉/伪灵根）→ 依仗体系外的「错位资产」获得越位优势 → 在体系内逐步证明自己 → 错位资产的身份问题反复成为危机点
> - **参数槽**：入场位（垫底首座门下/杂役弟子）｜错位优势（他派功法/神秘至宝）｜攀爬驱动力（被动卷入/主动经营）｜体系态度（轻视→倚重/利用→忌惮）
> - **实例A**：《诛仙》张小凡——入七脉之末的大竹峰，身怀大梵般若（佛）+太极玄清道（道）+魔教凶器（魔），三教资产无处安放；攀爬是被动的（事件推着走）
> - **实例B**：《凡人》韩立——伪灵根资质入越国七派之一的黄枫谷，靠掌天瓶催熟灵草弥补资质；攀爬是主动的（目标阶梯+资源经营）——用户「不是一开始就进名门，靠自己用心和剑走偏锋」指的正是这组参数差异
> - **差异注记**：同骨架，「攀爬驱动力」参数一换，全书气质分野：被动型出宿命悲剧（诛仙），主动型出生存史诗（凡人）

#### 卡 P-3 挚爱之死→人格断裂

> - **骨架**：建立高浓度情感绑定 → 挚爱死于体制的「正义之手」→ 主角对体系的认同断裂 → 换身份转入对立面 → 后半部主线=复活/复仇/救赎
> - **实例**：《诛仙》——碧瑶以痴情咒挡诛仙剑（正道魁首青云门的镇派之宝）而死，「张小凡」死、「鬼厉」生；救活碧瑶的可能（天书一线）成为十年主线
> - **变体（反用）**：《凡人》全篇回避此模式——韩立的情感关系从不置于致命赌位，这是两书气质分野的第二根支柱（情感驱动 vs 生存驱动）
> - **风险注记**：断裂若过早可逆（复活太快），张力全消；诛仙把兑现悬置到近结局，是该模式的极限操作

### 4.2 设定模式卡

#### 卡 S-1 门派生态：正邪两极 vs 多极制衡

> - **规则集维度**：势力格局（两极正邪/多派联盟）× 主角入场位（名门核心/边缘小派）× 门派与主角关系（师门庇护兼枷锁/雇佣兼跳板）× 内奸位（必有，位置决定爆点）
> - **实例A**：《诛仙》=两极格局：青云门（七脉：通天、龙首、风回、朝阳、落霞、大竹、小竹）+天音寺+焚香谷 vs 魔教四派（鬼王宗、合欢派、万毒门、长生堂）；主角身在正道名门怀揣魔宝，两极格局把身份张力拉满；内奸位=青云内部（龙首峰首座苍松为魔教炼血堂旧部）
> - **实例B**：《凡人》=多极格局：越国七派（掩月宗最强，黄枫谷、灵兽山、清虚门、化刀坞、天阙堡、巨剑门）联盟对抗天罗国魔道六宗入侵；主角所在黄枫谷非最强派，门派对韩立近乎雇佣关系；内奸位=联盟内部（灵兽山暗通御灵宗，破金鼓原大阵）
> - **崩坏点**：两极格局正邪实力失衡 → 冲突退化成碾压；多极格局门派不做出个性区分 → 联盟戏码记不住人

#### 卡 S-2 境界阶梯：粗境界重奇物 vs 精细数值重积累

> - **规则集维度**：境界颗粒度（少数大境/每大境多层）× 战力决定项（奇物一锤定音/境界×功法×法宝×辅战体系乘法）× 时间刻度（模糊/寿元精确）× 越阶战斗（罕见苛刻/常态爽点）
> - **实例A**：《诛仙》太极玄清道玉清/上清/太清三境，数值模糊，胜负手常在法宝（诛仙剑阵）；升级感让位于宿命与情感节拍
> - **实例B**：《凡人》练气→筑基→结丹→元婴→化神→（灵界）炼虚→合体→大乘→渡劫，仙界再续金仙/太乙/大罗；寿元精确到年，战力是乘法——韩立赢在乘法项总比别人多攒一项（飞剑/傀儡/灵虫/遁术）
> - **思想关联**：联动卡 I-2——境界精度是爽点语法的总开关
> - **崩坏点**：精细体系后期数值膨胀（凡人仙界篇继续拉长致新鲜感稀释）；粗体系后期无升级感只能靠奇物加码

#### 卡 S-3 金手指形态：因果诅咒型 vs 资源杠杆型

> - **规则集维度**：来源因果（与血案/大能挂钩与否）× 功能（战力直供/资源加速）× 保密成本（身份嫌疑/仅藏拙）× 可成长性（随剧情解封/恒定）
> - **实例A**：《诛仙》烧火棍=战力直供+因果诅咒，宝物自己制造危机
> - **实例B**：《凡人》掌天瓶=资源加速（催熟灵药→丹药→资质补丁），本身不产战力，危机从别处来
> - **已知耦合点**：来源因果 × 情节引擎位置——带因果的金手指是内置冲突引擎，纯增益金手指要求作者外挂冲突源（性格/环境/寿元），见卡 I-1

### 4.3 人物原型卡（增补 A 演示）

#### 卡 C-1 木讷坚韧型底层主角

> - **骨架**：欲望（守护身边人/求长生）× 缺陷（木讷不通人情/多疑不轻信）× 能力来路（奇遇+苦修双轨，天资平庸）× 关系位（被低估者）× 弧线终点（入魔仍守本心/道心通明终成大能）
> - **参数槽**：缺陷的社会化形态（道德纯度型木讷=不会怀疑人/生存理性型多疑=不轻信任何人）｜情感绑定密度（高=悲剧燃料/低=理性美学）｜金手指耦合度（宝物与人格互相塑造/宝物外在于人格）
> - **实例A**：张小凡——木讷是赤子（道德纯度），情感浓度极高，弧线=被至宝与惨案推入魔道仍守本心
> - **实例B**：韩立——多疑是凡人（生存理性），不冒险不冲动不轻信，情感关系保持安全距离，弧线=一路经营到长生
> - **对照注记**：同骨架异参数的教科书案例——两位主角每次关键抉择都能沿「缺陷的社会化形态」预测：张小凡因不会怀疑而受骗入劫，韩立因不敢轻信而错失过机缘也躲过过死劫

#### 卡 C-2 冷傲仙子型情感位

> - **骨架**：天才光环（同辈第一）× 冷外壳（师门规矩/性格清冷）× 对主角的例外（唯一温柔）× 立场张力（与主角身份污点相对）× 长线守候（主角转变后不弃）
> - **实例A**：陆雪琪——小竹峰天才，与鬼厉隔着正魔大义，张力=悲剧
> - **实例B（变体）**：紫灵——冷艳神秘，与韩立隔着利益与不信任，张力=博弈；守候参数淡化，合作伙伴参数拉满
> - **对照注记**：情感位的「立场张力形态」参数决定情感线体裁（悲剧/博弈），与卡 P-2 的主线驱动参数联动

### 4.4 伏笔线实例（增补 B 演示）

#### 卡 F-1 异物来历长线悬念

> - **埋设（sets-up 源）**：开局至宝以降格形态无名入手（烧火棍/小绿瓶）
> - **回收（sets-up 目标）**：中后期揭示真名与渊源（摄魂+噬血珠的魔教凶名与血案渊源 / 掌天瓶来历揭晓）
> - **手法注记**：降格呈现延迟读者估值，揭示时产生倍增爽感；《诛仙》进一步把至宝来历与血案真相焊成同一悬念——埋设成本一次、回收收益两次

#### 卡 F-2 体制内鬼悬念

> - **埋设**：名门/联盟内部成员行为微异（回避某类话题/大战关头迟疑）
> - **回收**：最大规模团战中内奸现形（青云龙首峰首座苍松=炼血堂旧部 / 灵兽山暗通御灵宗破金鼓原大阵）
> - **手法注记**：内鬼位是卡 S-1 两种格局的标配张力源；回收时机绑最大团战让背叛伤害最大化——两书彼此独立却给出结构对称的解，说明该模式接近「类型语法」而非巧合

### 4.5 思想卡

#### 卡 I-1 金手指的性质决定冲突引擎的位置

> - **title**：金手指带因果则冲突内生，纯增益则冲突必须外挂于主角性格与资源环境
> - **description**：设计主角金手指时用。判断你的故事靠什么制造危机：宝物自己制造（宿命剧），还是寿元、稀缺、性格制造（生存剧）。
> - **body**：《诛仙》烧火棍自带血案因果，情节被宝物推着走；《凡人》掌天瓶只省时间，忘语用寿元焦虑+资源稀缺+韩立的多疑制造全部危机。两种都成立，混用会拧：给纯增益金手指强加道德负担（读者觉得矫情），给因果金手指安安稳稳的日常（宝物的戏剧能量被浪费）。
> - **evidence**：卡 S-3、卡 P-1 的实例论断群

#### 卡 I-2 境界体系精度决定爽点形态

> - **title**：境界数值越精确，爽点越偏向积累与算计；境界越模糊，爽点越依赖奇物与一战定鼎
> - **description**：搭建力量体系时用。先选精度再选爽点语法，二者不匹配则两头落空。
> - **body**：写精细数值体系（凡人式）却让主角靠爆发翻盘，读者的积累预期落空；写粗境界（诛仙式）却强调数值压制，奇物的宿命感荡然无存。卡 S-2 的实例对照即证据。
> - **evidence**：卡 S-2

### 4.6 视角卡

#### 卡 L-1 伏笔与回收视角（v2 视角卡示例的具体化）

> - **attendTo**：反复出现却未解释的异物；人物的微异常行为；提前出场的高规格威胁；章末悬置句
> - **questions**：这个承诺在第几章兑现？埋设-回收间隔拉出了多大张力？哪些承诺从未兑现（悬空伏笔）？
