# 角色管理系统

## 1. 功能概述

角色管理系统允许用户创建和管理不同的 AI 助手角色，每个角色有独立的系统提示词和默认配置，适用于不同场景的对话需求。

## 2. 功能需求

#### FR-ROLE-003 编辑自定义角色

**需求描述**：用户可以修改已创建的自定义角色

**操作流程**：
1. 在自定义角色卡片上，点击"编辑"按钮
2. 显示编辑对话框，预填充当前信息
3. 修改角色信息
4. 点击"保存"更新

**可编辑内容**：
- 头像
- 名称
- 描述
- 系统提示词
- 默认模型
- 生成参数

---

#### FR-ROLE-004 删除自定义角色

**需求描述**：用户可以删除不再需要的自定义角色

**操作流程**：
1. 在自定义角色卡片上，点击"删除"按钮
2. 系统检查是否有关联的对话
3. 如果有关联对话：
   - 显示："此助手关联了 X 个对话，删除后对话将转移到默认助手，是否继续？"
4. 用户确认后删除

**业务规则**：
- 关联对话不会被删除
- 关联对话的 roleId 置空（变为默认助手的对话）

---

### 2.3 角色使用

#### FR-ROLE-006 使用角色创建对话

**需求描述**：用户可以选择角色后创建对话

**操作流程**：
1. 在对话页面侧边栏，选择一个助手角色
2. 点击"新建对话"按钮
3. 新对话自动关联该角色
4. 使用角色的系统提示词和默认配置

**业务规则**：
- 选择角色后新建的对话自动关联该角色
- 角色的系统提示词会作为对话的系统提示词
- 角色的默认模型作为对话的默认模型

---

#### FR-ROLE-007 按角色筛选对话

**需求描述**：用户可以按角色筛选对话列表

**操作流程**：
1. 在侧边栏选择一个助手
2. 话题列表自动切换，只显示该角色的对话
3. 选择"默认助手"显示未关联角色的对话

## 4. 业务规则

### 4.1 角色创建规则

| 字段 | 验证规则 |
|------|----------|
| 名称 | 必填，1-30 字符，不能与内置角色重名 |
| 描述 | 选填，最多 100 字符 |
| 系统提示词 | 选填，最多 4000 字符 |

### 4.2 角色使用规则

- 每个对话只能关联一个角色
- 角色删除后，关联对话的 roleId 置空
- 内置角色不能修改和删除

### 4.3 默认配置继承

使用角色创建对话时：
1. 对话的 systemPrompt 使用角色的 systemPrompt
2. 对话的 modelId 使用角色的 defaultModelId（如有）或全局默认
3. 对话的 providerConfigId 使用角色的 defaultProviderConfigId（如有）或全局默认

## 5. 边界情况

### 5.1 角色的默认模型被删除

**场景**：角色配置的默认模型被从提供商中删除

**处理**：
- 使用全局默认提供商和模型
- 提示用户："该助手的默认模型不可用，已切换为默认模型"

### 5.2 系统提示词过长

**场景**：系统提示词超过模型的输入限制

**处理**：
- 显示警告："系统提示词较长，可能影响对话上下文"
- 仍然允许保存

### 5.3 角色关联大量对话

**场景**：删除关联了大量对话的角色

**处理**：
- 显示关联对话数量
- 提示用户对话将转移到默认助手
- 用户确认后执行删除
