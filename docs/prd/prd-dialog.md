# AI对话模块 PRD

**模块名称：** AI对话
**优先级：** Must Have
**所属Epic：** EPIC-001 AI对话核心系统
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

AI对话模块是AI工具箱的核心功能，为用户提供智能对话体验。支持多模型切换、角色预设、对话历史管理等能力。

### 1.1 功能目标

- 提供统一的AI对话界面
- 支持多个AI模型提供商
- 支持角色预设和自定义角色
- 支持对话历史管理

### 1.2 目标用户

- 所有用户（普通用户、开发者、内容创作者）

## 3. 详细功能说明

### 3.1 多模型支持 (D-001)

#### 功能描述

支持用户配置和切换多个AI模型提供商，包括主流云端模型和本地模型。

#### 支持的模型提供商

**Must Have（必须支持）：**
| 提供商 | 模型示例 | API端点 |
|--------|----------|---------|
| 通义千问 | qwen-turbo, qwen-plus, qwen-max | dashscope.aliyuncs.com |
| 豆包 | doubao-pro, doubao-lite | ark.cn-beijing.volces.com |
| GLM | glm-4, glm-3-turbo | open.bigmodel.cn |
| DeepSeek | deepseek-chat, deepseek-coder | api.deepseek.com |

**Should Have（应该支持）：**
| 提供商 | 模型示例 | API端点 |
|--------|----------|---------|
| OpenAI | gpt-4, gpt-3.5-turbo | api.openai.com |
| Claude | claude-3-opus, claude-3-sonnet | api.anthropic.com |
| Gemini | gemini-pro | generativelanguage.googleapis.com |
| Kimi | moonshot-v1 | api.moonshot.cn |
| Ollama | 本地模型 | localhost:11434 |

#### 操作流程

```
1. 用户点击顶部模型选择器
2. 显示已配置的模型列表
3. 用户选择目标模型
4. 系统切换模型并更新状态指示
5. 后续对话使用新选择的模型
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 模型提供商 | string | 是 | 如 "qwen", "doubao" |
| 模型名称 | string | 是 | 如 "qwen-turbo" |
| API密钥 | string | 是 | 在设置中配置 |
| API端点 | string | 否 | 自定义端点URL |

#### 输出

- 模型切换成功/失败状态
- 当前模型状态指示（可用/不可用/配置中）

#### 界面布局

```
┌─────────────────────────────────────────┐
│  [🤖 通义千问 qwen-turbo ▼]  ● 已连接   │
└─────────────────────────────────────────┘
         ↓ 点击展开
┌─────────────────────────────────────────┐
│  🔍 搜索模型...                          │
├─────────────────────────────────────────┤
│  ✅ 通义千问 - qwen-turbo     ● 已连接   │
│  ⚪ 豆包 - doubao-pro         ○ 未配置   │
│  ⚪ GLM - glm-4               ○ 未配置   │
│  ⚪ DeepSeek - deepseek-chat  ○ 未配置   │
├─────────────────────────────────────────┤
│  ⚙️ 配置模型...                          │
└─────────────────────────────────────────┘
```

#### 边界检查

| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| API密钥为空 | 密钥不能为空 | "请先配置API密钥" |
| API密钥格式 | 根据提供商验证格式 | "API密钥格式不正确" |
| 网络连接 | 检查API端点可达性 | "无法连接到API服务" |
| 模型可用性 | 调用API验证 | "模型暂时不可用" |
| 余额检查 | 检查账户余额 | "账户余额不足" |

### 3.2 对话界面 (D-002)

#### 功能描述

提供用户友好的对话界面，支持多轮对话、上下文保持、流式输出。

#### 操作流程

```
1. 用户在输入框输入消息
2. 可选择附加选项（角色、知识库等）
3. 点击发送或按Enter键
4. 系统显示用户消息
5. 系统调用AI模型API
6. 流式显示AI响应
7. 对话历史自动保存
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用户消息 | string | 是 | 用户输入的文本 |
| 角色ID | string | 否 | 选择的预设角色 |
| 知识库ID | string | 否 | 关联的知识库 |
| 温度 | number | 否 | 生成温度 0-2 |
| 最大Token | number | 否 | 最大生成Token数 |

#### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| AI响应 | string | AI生成的回复文本 |
| 响应时间 | number | API响应耗时(ms) |
| Token使用 | object | 输入/输出Token统计 |

### 3.3 角色预设系统 (D-003)

#### 功能描述

支持预设定和自定义AI角色，为不同场景提供专门的对话助手。

#### 预设角色列表

| 角色ID | 角色名称 | 适用场景 | 系统提示词要点 |
|--------|----------|----------|----------------|
| assistant | 通用助手 | 日常对话 | 通用AI助手 |
| programmer | 编程专家 | 开发调试 | 精通编程语言和最佳实践 |
| designer | 设计顾问 | UI/UX设计 | 专业设计建议 |
| writer | 文案策划 | 内容创作 | 文案写作专家 |
| translator | 翻译专家 | 多语言翻译 | 专业翻译能力 |
| data_analyst | 数据分析师 | 数据分析 | 数据分析和可视化 |
| teacher | 教学助手 | 学习辅导 | 耐心讲解知识点 |
| video_creator | 视频创作者 | 视频脚本 | 视频创作指导 |
| image_creator | 图像创作者 | 提示词生成 | 图像生成提示词专家 |
| project_manager | 项目经理 | 项目管理 | 项目管理最佳实践 |

#### 操作流程

**选择预设角色：**
```
1. 用户点击"选择角色"下拉框
2. 显示预设角色列表
3. 用户选择角色
4. 系统应用角色系统提示词
5. 后续对话使用该角色
```

**创建自定义角色：**
```
1. 用户进入角色管理界面
2. 点击"新建角色"
3. 填写角色信息（名称、描述、系统提示词）
4. 可选上传头像
5. 保存角色
6. 在对话中可选择使用
```

#### 输入

**创建角色：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色名称 | string | 是 | 2-20字符 |
| 角色描述 | string | 否 | 角色简介 |
| 系统提示词 | string | 是 | 最多4000字符 |
| 头像 | file | 否 | 图片文件 |

#### 输出

- 角色创建成功/失败状态
- 角色列表

## 4. 数据模型

### 4.1 对话会话 (Conversation)

```typescript
interface Conversation {
  id: string;              // UUID
  title: string;           // 对话标题
  model: string;           // 使用的模型
  roleId?: string;         // 角色ID
  knowledgeBaseId?: string;// 知识库ID
  messages: Message[];     // 消息列表
  createdAt: Date;         // 创建时间
  updatedAt: Date;         // 更新时间
}
```

### 4.2 消息 (Message)

```typescript
interface Message {
  id: string;              // UUID
  role: 'user' | 'assistant' | 'system';
  content: string;         // 消息内容
  tokens?: {               // Token统计
    input: number;
    output: number;
  };
  timestamp: Date;         // 时间戳
}
```

### 4.3 角色 (Role)

```typescript
interface Role {
  id: string;              // UUID
  name: string;            // 角色名称
  description?: string;    // 角色描述
  systemPrompt: string;    // 系统提示词
  avatar?: string;         // 头像路径
  isPreset: boolean;       // 是否预设
  createdAt: Date;         // 创建时间
}
```

## 5. API接口

### 5.1 发送对话消息

```
POST /api/dialog/send
```

**请求体：**
```json
{
  "conversationId": "uuid",
  "message": "用户消息内容",
  "model": "qwen-turbo",
  "roleId": "uuid",
  "options": {
    "temperature": 0.7,
    "maxTokens": 2048
  }
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "messageId": "uuid",
    "content": "AI响应内容",
    "tokens": {
      "input": 150,
      "output": 280
    }
  }
}
```

### 5.2 流式对话

```
POST /api/dialog/stream
```

使用SSE返回流式数据。

## 6. 错误处理

### 6.1 错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| D001 | API密钥无效 | 引导用户检查API配置 |
| D002 | 模型不可用 | 建议切换其他模型 |
| D003 | 请求超时 | 提供重试选项 |
| D004 | 余额不足 | 提示充值或切换模型 |
| D005 | 内容违规 | 提示修改内容 |
| D006 | 网络错误 | 检查网络连接 |
| D007 | 上下文过长 | 自动截断或提示 |
