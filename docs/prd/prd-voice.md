# 语音转换模块 PRD

**模块名称：** 语音转换（TTS/STT）
**优先级：** Must Have
**所属Epic：** EPIC-003 文档处理与转换工具
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

语音转换模块提供文本转语音（TTS）和语音转文本（STT）能力，帮助用户进行语音和文本的互相转换。

### 1.1 功能目标

- 提供高质量TTS服务
- 提供准确STT服务
- 支持多种语音角色
- 支持实时录音转文字

### 1.2 目标用户

- 所有用户
- 内容创作者（配音、字幕）
- 会议记录人员

## 3. 详细功能说明

### 3.1 文本转语音 (TTS) (VC-001)

#### 功能描述

将输入的文本转换为自然流畅的语音输出。

#### 操作流程

```
1. 用户进入语音转换模块
2. 选择TTS标签页
3. 输入或粘贴要转换的文本
4. 选择语音角色
5. 调节语速、音调等参数
6. 点击"生成语音"
7. 系统调用TTS API
8. 播放生成的语音
9. 用户可下载音频文件
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 文本内容 | string | 是 | 要转换的文本，最多10000字符 |
| 语音角色 | string | 是 | 选择语音角色 |
| 语速 | number | 否 | 语速倍率 0.5-2.0，默认1.0 |
| 音调 | number | 否 | 音调 -10到+10，默认0 |
| 音量 | number | 否 | 音量 0-100，默认100 |
| 输出格式 | string | 否 | MP3/WAV，默认MP3 |

#### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| 音频文件 | file | 生成的音频文件 |
| 时长 | number | 音频时长(秒) |
| 文件大小 | number | 文件大小(KB) |

### 3.3 语音转文本 (STT) (VC-005)

#### 功能描述

将音频文件或实时录音转换为文本。

#### 支持的音频格式

| 格式 | 扩展名 | 最大文件大小 | 最大时长 |
|------|--------|--------------|----------|
| MP3 | .mp3 | 100MB | 60分钟 |
| WAV | .wav | 500MB | 60分钟 |
| M4A | .m4a | 100MB | 60分钟 |
| FLAC | .flac | 200MB | 60分钟 |
| OGG | .ogg | 100MB | 60分钟 |

#### 操作流程

**文件上传识别：**
```
1. 用户选择STT标签页
2. 点击上传音频文件
3. 或拖拽音频文件到界面
4. 选择识别语言
5. 点击"开始识别"
6. 系统调用STT API
7. 显示识别结果
8. 用户可编辑和导出
```

**实时录音识别：**
```
1. 用户点击"开始录音"
2. 系统请求麦克风权限
3. 开始录音并实时转写
4. 实时显示转写文本
5. 点击"停止录音"
6. 显示完整转写结果
7. 用户可编辑和导出
```

### 3.5 长文本处理 (VC-009)

#### 功能描述

自动将长文本分段处理，避免API限制和超时。

#### 处理策略

```
1. 检测文本长度
2. 如超过限制，按段落/句号分段
3. 每段单独调用API
4. 合并所有音频片段
5. 生成完整音频文件
```

#### 分段设置

```
┌─────────────────────────────────────────┐
│  长文本设置                              │

│  分段间隔: [0.5] 秒静音                  │
│  ☑ 显示处理进度                          │
└─────────────────────────────────────────┘
```

## 4. 数据模型

### 4.1 TTS记录 (TTSRecord)

```typescript
interface TTSRecord {
  id: string;
  text: string;            // 原始文本
  voice: string;           // 语音角色
  speed: number;           // 语速
  pitch: number;           // 音调
  volume: number;          // 音量
  format: string;          // 输出格式
  audioPath: string;       // 音频文件路径
  duration: number;        // 时长(秒)
  fileSize: number;        // 文件大小
  createdAt: Date;
}
```

### 4.2 STT记录 (STTRecord)

```typescript
interface STTRecord {
  id: string;
  audioPath?: string;      // 音频文件路径
  isRecording: boolean;    // 是否实时录音
  language: string;        // 识别语言
  text: string;            // 识别结果
  confidence: number;      // 置信度
  duration: number;        // 音频时长
  createdAt: Date;
}
```

## 5. API接口

### 5.1 文本转语音

```
POST /api/voice/tts
```

**请求体：**
```json
{
  "text": "要转换的文本内容",
  "voice": "female_lively",
  "speed": 1.0,
  "pitch": 0,
  "volume": 100,
  "format": "mp3"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "recordId": "uuid",
    "audioUrl": "file://path/to/audio.mp3",
    "duration": 90,
    "fileSize": 256
  }
}
```

### 5.2 语音转文本

```
POST /api/voice/stt
```

**请求体：**
```json
{
  "audioPath": "/path/to/audio.mp3",
  "language": "auto"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "recordId": "uuid",
    "text": "识别出的文本内容",
    "confidence": 92,
    "duration": 60
  }
}
```

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| VC001 | API密钥无效 | 检查API配置 |
| VC002 | 语音角色不可用 | 选择其他角色 |
| VC003 | 音频格式不支持 | 转换音频格式 |

| VC006 | 识别失败 | 检查音频质量 |
| VC007 | 网络超时 | 重试请求 |
