# 视频生成模块 PRD

**模块名称：** 视频生成
**优先级：** Must Have
**所属Epic：** EPIC-002 多媒体内容生成
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

视频生成模块提供AI文生视频能力，支持通过文本描述生成视频，并提供流程化创作功能。

### 1.1 功能目标

- 支持视频生成API
- 提供灵活的参数配置
- 支持流程化创作（大纲→角色→分镜→视频）
- 支持生成历史管理

### 1.2 目标用户

- 内容创作者（主要）
- 视频制作者
- 营销人员

## 3. 详细功能说明

### 3.1 视频生成 (V-001)

#### 功能描述

用户通过输入文本描述生成视频，可选择不同的生成模型和参数。

#### 操作流程

```
1. 用户进入视频生成模块
2. 选择生成模型
3. 输入视频描述（提示词）
4. 配置生成参数（时长、分辨率等）
5. 点击"生成"按钮
6. 系统提交任务到API
7. 显示生成进度（视频生成时间较长）
8. 生成完成后展示视频
9. 用户可预览、保存或重新生成
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 视频描述 | string | 是 | 描述想要生成的视频内容，最多2000字符 |
| 模型 | string | 是 | 选择生成模型 |
| 时长 | number | 否 | 视频时长（秒），默认4秒 |
| 分辨率 | string | 否 | 视频分辨率，默认720p |
| 帧率 | number | 否 | 帧率，默认24fps |
| 风格 | string | 否 | 视频风格预设 |
| 种子 | number | 否 | 随机种子 |

#### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| 视频URL | string | 生成的视频文件路径 |
| 生成时间 | number | 生成耗时(ms) |
| 时长 | number | 实际视频时长 |
| 分辨率 | string | 实际分辨率 |
| 种子值 | number | 实际使用的种子 |

#### 边界检查

| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 描述长度 | 最多2000字符 | "描述过长，请精简" |
| 空描述 | 不允许为空 | "请输入视频描述" |

| 并发任务 | 最多3个任务 | "任务队列已满，请等待" |

### 3.2 多模型支持 (V-002)

#### 功能描述

支持多个视频生成API提供商。

#### 支持的模型

| 提供商 | 模型名称 | 特点 | 时长限制 | 优先级 |
|--------|----------|------|----------|--------|
| 火山引擎 | video-01 | 字节跳动，高质量 | 4-10秒 | Must Have |
| Runway | Gen-2 | 高质量（预留） | 4-18秒 | Could Have |
| Pika | pika-1.0 | 创意风格（预留） | 3-4秒 | Could Have |

#### 模型配置

```typescript
interface VideoModel {
  id: string;              // 模型ID
  name: string;            // 显示名称
  provider: string;        // 提供商
  maxDuration: number;     // 最大时长(秒)
  minDuration: number;     // 最小时长(秒)
  resolutions: string[];   // 支持的分辨率
  frameRates: number[];    // 支持的帧率
  avgGenerationTime: number; // 平均生成时间(秒)
}
```

### 3.3 参数配置 (V-003)

#### 可配置参数

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 时长 | number | 2-10秒 | 4秒 | 视频时长 |

| 分辨率 | 尺寸 | 适用场景 |
|--------|------|----------|
| 480p | 854x480 | 快速预览 |
| 720p | 1280x720 | 通用场景 |
| 1080p | 1920x1080 | 高清输出 |

#### 支持的风格

| 风格 | 说明 |
|------|------|
| 写实 | 真实影像风格 |
| 动漫 | 二次元动画风格 |
| 3D动画 | 3D动画电影风格 |
| 电影感 | 电影画面风格 |

### 3.5 流程化创作 (V-006)

#### 功能描述

支持完整的视频创作流程：大纲→角色→分镜→视频。

#### 创作流程

```
┌─────────────────────────────────────────┐
│  创作流程                                │
├─────────────────────────────────────────┤
│  ① 大纲 → ② 角色 → ③ 分镜 → ④ 生成 → ⑤ 导出 │
├─────────────────────────────────────────┤
│  当前步骤: ③ 分镜                        │
└─────────────────────────────────────────┘
```

#### 各阶段说明

**① 大纲阶段：**
- 使用AI对话生成故事大纲
- 定义故事主题和情节
- 保存大纲到项目

**② 角色阶段：**
- 定义主要角色特征
- 生成角色基准图像
- 保存角色设定

**③ 分镜阶段：**
- 将故事拆分为分镜
- 每个分镜包含场景描述
- 关联角色和场景

**④ 生成阶段：**
- 基于分镜生成视频片段
- 审阅和调整
- 重新生成不满意的部分

**⑤ 导出阶段：**
- 导出所有视频片段
- 生成项目报告
- 备份项目文件

## 4. 数据模型

### 4.1 视频记录 (VideoRecord)

```typescript
interface VideoRecord {
  id: string;
  prompt: string;           // 视频描述
  model: string;            // 使用模型
  duration: number;         // 时长(秒)
  resolution: string;       // 分辨率
  frameRate: number;        // 帧率
  style?: string;           // 风格
  seed?: number;            // 种子
  videoPath: string;        // 视频文件路径
  thumbnailPath?: string;   // 缩略图路径
  projectId?: string;       // 所属项目ID
  sceneId?: string;         // 关联分镜ID
  status: 'pending' | 'generating' | 'completed' | 'failed';
  progress: number;         // 进度 0-100
  createdAt: Date;
}
```

### 4.2 创作项目 (VideoProject)

```typescript
interface VideoProject {
  id: string;
  name: string;
  description?: string;
  outline?: string;         // 故事大纲
  characters: Character[];  // 角色列表
  scenes: VideoScene[];     // 分镜列表
  videos: VideoRecord[];    // 生成的视频
  createdAt: Date;
  updatedAt: Date;
}
```

### 4.3 视频分镜 (VideoScene)

```typescript
interface VideoScene {
  id: string;
  order: number;            // 顺序
  name: string;             // 分镜名称
  sceneDescription: string; // 场景描述
  actionDescription: string;// 动作描述
  characterIds: string[];   // 关联角色
  duration: number;         // 时长(秒)
  status: 'pending' | 'generating' | 'completed' | 'failed';
  videoId?: string;         // 生成的视频ID
}
```

## 5. API接口

### 5.1 生成视频

```
POST /api/video/generate
```

**请求体：**
```json
{
  "prompt": "一只橘猫在阳光下打盹",
  "model": "video-01",
  "duration": 4,
  "resolution": "720p",
  "frameRate": 24,
  "style": "realistic",
  "seed": null
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "taskId": "uuid",
    "status": "pending",
    "estimatedTime": 180
  }
}
```

### 5.2 查询生成状态

```
GET /api/video/status/:taskId
```

**响应：**
```json
{
  "success": true,
  "data": {
    "taskId": "uuid",
    "status": "generating",
    "progress": 60,
    "remainingTime": 72
  }
}
```

## 6. 错误处理

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| V001 | API密钥无效 | 检查API配置 |
| V002 | 模型不可用 | 切换其他模型 |
| V003 | 描述违规 | 修改描述内容 |
| V004 | 生成超时 | 重试或减少时长 |
| V005 | 存储空间不足 | 清理磁盘空间 |
| V006 | 时长超限 | 减少视频时长 |
| V007 | 并发限制 | 等待任务完成 |
