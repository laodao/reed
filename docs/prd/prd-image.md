# 图像生成模块 PRD

**模块名称：** 图像生成
**优先级：** Must Have
**所属Epic：** EPIC-002 多媒体内容生成
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

图像生成模块提供AI文生图能力，支持多种图像生成模型，并提供流程化创作功能帮助用户维护角色一致性。

### 1.1 功能目标

- 支持多种图像生成API
- 提供灵活的参数配置
- 支持流程化创作（角色一致性）
- 支持生成历史管理

### 1.2 目标用户

- 内容创作者（主要）
- 设计师
- 普通用户

## 3. 详细功能说明

### 3.1 图像生成 (I-001)

#### 功能描述

用户通过输入提示词（Prompt）生成图像，支持正向和负向提示词。

#### 操作流程

```
1. 用户进入图像生成模块
2. 选择生成模型
3. 输入正向提示词（描述想要的内容）
4. 可选输入负向提示词（描述不想要的内容）
5. 配置生成参数（尺寸、数量等）
6. 点击"生成"按钮
7. 系统调用API生成图像
8. 显示生成进度
9. 展示生成结果
10. 用户可保存或重新生成
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 正向提示词 | string | 是 | 描述想要生成的内容，最多1000字符 |
| 负向提示词 | string | 否 | 描述不想要的元素，最多500字符 |
| 模型 | string | 是 | 选择生成模型 |
| 尺寸 | string | 否 | 图像尺寸，默认1024x1024 |
| 数量 | number | 否 | 生成数量，1-4张，默认1 |
| 风格 | string | 否 | 图像风格预设 |
| 种子 | number | 否 | 随机种子，用于复现 |

#### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| 图像列表 | array | 生成的图像URL或Base64 |
| 生成时间 | number | 生成耗时(ms) |
| 种子值 | number | 实际使用的种子 |
| 提示词ID | string | 用于复现的ID |

#### 界面布局

#### 边界检查

| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 提示词长度 | 正向最多1000字符 | "提示词过长，请精简" |
| 负向提示词长度 | 最多500字符 | "负向提示词过长" |
| 空提示词 | 不允许为空 | "请输入提示词" |
| 敏感词检测 | 检测违规内容 | "提示词包含敏感内容" |
| 生成数量 | 1-4张 | "生成数量需在1-4之间" |
| API额度 | 检查余额 | "API额度不足" |

### 3.2 多模型支持 (I-002)

#### 功能描述

支持多个图像生成API提供商，用户可自由切换。

#### 支持的模型

| 提供商 | 模型名称 | 特点 | 优先级 |
|--------|----------|------|--------|
| 通义万项 | wanx-v1 | 阿里云，中文友好 | Must Have |
| 火山引擎 | stable-diffusion | 字节跳动，多样风格 | Must Have |
| 智谱 | cogview-3 | 智谱AI，高质量 | Must Have |
| Midjourney | mj-v6 | 高质量（预留） | Could Have |
| Stable Diffusion | sd-xl | 开源模型（预留） | Could Have |

#### 模型配置

```typescript
interface ImageModel {
  id: string;           // 模型ID
  name: string;         // 显示名称
  provider: string;     // 提供商
  maxSize: string;      // 最大尺寸
  supportedSizes: string[]; // 支持的尺寸列表
  maxBatch: number;     // 最大批量数
  styles: string[];     // 支持的风格
}
```

### 3.3 参数配置 (I-003)

#### 功能描述

提供丰富的参数配置选项，控制生成效果。

#### 可配置参数

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 尺寸 | enum | 见下表 | 1024x1024 | 图像尺寸 |
| 数量 | number | 1-4 | 1 | 生成数量 |
| 风格 | enum | 模型相关 | 自动 | 图像风格 |
| 种子 | number | 0-999999 | 随机 | 随机种子 |
| 步数 | number | 20-50 | 30 | 生成步数 |
| CFG Scale | number | 1-20 | 7 | 提示词相关性 |

#### 支持的尺寸

| 尺寸 | 宽高比 | 适用场景 |
|------|--------|----------|
| 1024x1024 | 1:1 | 正方形，通用 |
| 1024x1792 | 9:16 | 竖版，手机壁纸 |
| 1792x1024 | 16:9 | 横版，封面图 |
| 768x768 | 1:1 | 小尺寸，快速预览 |
| 512x512 | 1:1 | 缩略图 |

#### 支持的风格

| 风格 | 说明 |
|------|------|
| 自动 | 模型自动判断 |
| 写实 | 真实照片风格 |
| 动漫 | 二次元动漫风格 |
| 油画 | 油画艺术风格 |
| 水彩 | 水彩画风格 |
| 3D渲染 | 3D建模渲染风格 |
| 像素风 | 像素游戏风格 |
| 素描 | 铅笔素描风格 |

### 3.4 图像保存 (I-004)

#### 功能描述

将生成的图像保存到本地文件系统。

#### 操作流程

```
1. 用户点击图像上的"保存"按钮
2. 选择保存位置（默认下载目录）
3. 选择保存格式（PNG/JPG/WEBP）
4. 系统保存图像
5. 显示保存成功提示
6. 可选打开文件位置
```

#### 保存选项

| 选项 | 说明 |
|------|------|
| 保存位置 | 默认为用户下载目录 |
| 文件名 | 自动生成或自定义 |
| 格式 | PNG（无损）/ JPG（压缩）/ WEBP |
| 质量 | JPG/WEBP质量设置 |

### 3.6 角色一致性 (I-006)

#### 功能描述

支持流程化创作，维护生成图像中角色的视觉一致性。

#### 操作流程

```
1. 用户创建"创作项目"
2. 定义角色特征（文字描述）
3. 生成角色基准图像
4. 基于角色创建多个场景图像
5. 系统自动维护角色一致性
```

#### 角色定义

```typescript
interface Character {
  id: string;
  name: string;           // 角色名称
  description: string;    // 详细描述
  features: string[];     // 关键特征
  baseImage?: string;     // 基准图像
  styleGuide?: string;    // 风格指南
  createdAt: Date;
}
```

## 4. 数据模型

### 4.1 生成记录 (ImageRecord)

```typescript
interface ImageRecord {
  id: string;
  prompt: string;           // 正向提示词
  negativePrompt?: string;  // 负向提示词
  model: string;            // 使用模型
  size: string;             // 尺寸
  style?: string;           // 风格
  seed?: number;            // 种子
  images: string[];         // 图像路径列表
  projectId?: string;       // 所属项目ID
  characterId?: string;     // 关联角色ID
  createdAt: Date;
}
```

### 4.2 创作项目 (ImageProject)

```typescript
interface ImageProject {
  id: string;
  name: string;
  description?: string;
  characters: Character[];  // 角色列表
  scenes: Scene[];          // 场景列表
  images: ImageRecord[];    // 生成的图像
  createdAt: Date;
  updatedAt: Date;
}
```

## 5. API接口

### 5.1 生成图像

```
POST /api/image/generate
```

**请求体：**
```json
{
  "prompt": "一只可爱的橘猫",
  "negativePrompt": "模糊, 低质量",
  "model": "wanx-v1",
  "size": "1024x1024",
  "count": 1,
  "style": "auto",
  "seed": null
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "recordId": "uuid",
    "images": [
      {
        "url": "file://path/to/image.png",
        "seed": 123456
      }
    ],
    "duration": 5200
  }
}
```

### 5.2 获取生成历史

```
GET /api/image/history?page=1&size=20&model=wanx-v1
```

## 6. 错误处理

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| I001 | API密钥无效 | 检查API配置 |
| I002 | 模型不可用 | 切换其他模型 |
| I003 | 提示词违规 | 修改提示词 |
| I004 | 生成超时 | 重试或切换模型 |
| I005 | 存储空间不足 | 清理磁盘空间 |
| I006 | 尺寸不支持 | 选择支持的尺寸 |
