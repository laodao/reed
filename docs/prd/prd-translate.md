# 翻译模块 PRD

**模块名称：** 翻译
**优先级：** Must Have
**所属Epic：** EPIC-003 文档处理与转换工具
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

翻译模块提供多语言文本翻译能力，支持多种翻译API，帮助用户快速进行语言转换。

### 1.1 功能目标

- 支持多种翻译API
- 支持多语言互译
- 提供原文/译文对照
- 支持批量翻译

### 1.2 目标用户

- 所有用户
- 跨语言工作者
- 学习者

## 3. 详细功能说明

### 3.1 文本翻译 (T-001)

#### 功能描述

将输入的文本从一种语言翻译为另一种语言。

#### 操作流程

```
1. 用户进入翻译模块
2. 输入或粘贴要翻译的文本
3. 选择源语言（或自动检测）
4. 选择目标语言
5. 点击"翻译"或自动翻译
6. 系统调用翻译API
7. 显示翻译结果
8. 用户可复制或导出
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 原文文本 | string | 是 | 要翻译的文本，最多5000字符 |
| 源语言 | string | 是 | 源语言代码，"auto"为自动检测 |
| 目标语言 | string | 是 | 目标语言代码 |
| 翻译API | string | 否 | 使用的翻译服务 |

#### 输出

| 字段 | 类型 | 说明 |
|------|------|------|
| 译文文本 | string | 翻译结果 |
| 检测语言 | string | 检测到的源语言 |
| 置信度 | number | 语言检测置信度 |

#### 界面布局

```

├─────────────────────────────────────────┤
│  翻译服务: [火山翻译 ▼]                  │
├─────────────────────────────────────────┤
│  ┌─────────────────┬───────────────────┐│
│  │ 源语言: [自动 ▼]│ 目标语言: [英文 ▼]││
│  ├─────────────────┼───────────────────┤│
│  │                 │                    ││
│  │ 请输入要翻译的  │ Here is the        ││
│  │ 文本内容...     │ translated text... ││
│  │                 │                    ││
│  │                 │                    ││
│  │                 │                    ││
│  │ 字数: 0/5000    │ [📋 复制]          ││
│  │ [🔄 清空]       │ [🔊 朗读]          ││
│  └─────────────────┴───────────────────┘│
├─────────────────────────────────────────┤
│  [🔄 互换语言] [➡️ 翻译]                 │
└─────────────────────────────────────────┘
```

#### 边界检查

| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 文本长度 | 最多5000字符 | "文本过长，请分段翻译" |
| 空文本 | 不允许为空 | "请输入要翻译的文本" |
| 相同语言 | 源/目标不能相同 | "源语言和目标语言相同" |
| 网络连接 | 需要网络 | "网络连接失败" |

### 3.6 批量翻译 (T-007)

#### 功能描述

支持批量翻译多段文本，提高效率。

#### 操作流程

```
1. 用户点击"批量翻译"
2. 输入或粘贴多段文本（每行一段）
3. 选择源语言和目标语言
4. 点击"开始翻译"
5. 系统依次翻译每段
6. 显示翻译进度
7. 完成后可批量导出
```

## 4. 数据模型

### 4.1 翻译记录 (TranslateRecord)

```typescript
interface TranslateRecord {
  id: string;
  sourceText: string;      // 原文
  targetText: string;      // 译文
  sourceLanguage: string;  // 源语言
  targetLanguage: string;  // 目标语言
  detectedLanguage?: string; // 检测到的语言
  service: string;         // 翻译服务
  confidence?: number;     // 置信度
  createdAt: Date;
}
```

## 5. API接口

### 5.1 翻译文本

```
POST /api/translate
```

**请求体：**
```json
{
  "text": "要翻译的文本",
  "sourceLanguage": "auto",
  "targetLanguage": "en",
  "service": "volcengine"
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "translatedText": "Translated text",
    "detectedLanguage": "zh-CN",
    "confidence": 0.98
  }
}
```

### 5.2 批量翻译

```
POST /api/translate/batch
```

**请求体：**
```json
{
  "texts": ["文本1", "文本2", "文本3"],
  "sourceLanguage": "zh-CN",
  "targetLanguage": "en"
}
```

## 6. 错误处理

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| T001 | API密钥无效 | 检查API配置 |
| T002 | 服务不可用 | 切换其他服务 |
| T003 | 语言不支持 | 选择支持的语言 |
| T004 | 文本过长 | 分段翻译 |
| T005 | 额度不足 | 检查API额度 |
| T006 | 网络超时 | 重试请求 |
