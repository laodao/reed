# OCR识别模块 PRD

**模块名称：** OCR识别
**优先级：** Must Have
**所属Epic：** EPIC-003 文档处理与转换工具
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

OCR识别模块提供图片文字识别能力，支持多种OCR引擎，帮助用户从图片中提取文字内容。

### 1.1 功能目标

- 支持多种OCR引擎
- 支持多语言识别
- 支持批量处理
- 提供识别结果编辑

### 1.2 目标用户

- 所有用户
- 文档处理人员
- 学生和研究人员

## 3. 详细功能说明

### 3.1 图片上传 (O-001, O-002)

#### 功能描述

用户可以通过点击上传或拖拽方式导入图片进行OCR识别。

#### 支持的图片格式

| 格式 | 扩展名 | 最大文件大小 |
|------|--------|--------------|
| JPEG | .jpg, .jpeg | 20MB |
| PNG | .png | 20MB |
| BMP | .bmp | 20MB |
| WEBP | .webp | 20MB |
| TIFF | .tiff, .tif | 20MB |
| PDF | .pdf | 50MB |

#### 操作流程

**点击上传：**
```
1. 用户点击"上传图片"按钮
2. 打开文件选择对话框
3. 选择图片文件
4. 系统加载并显示图片预览
5. 自动开始识别或手动点击识别
```

**拖拽上传：**
```
1. 用户拖拽图片文件到识别区域
2. 系统检测到拖拽操作
3. 高亮显示放置区域
4. 用户释放鼠标
5. 系统加载并显示图片预览
6. 自动开始识别或手动点击识别
```

### 3.2 多引擎支持 (O-003)

#### 功能描述

支持多种OCR引擎，用户可根据需求选择。

#### 支持的引擎

| 引擎 | 类型 | 特点 | 优先级 |
|------|------|------|--------|
| Tesseract-OCR | 本地 | 开源免费，支持多语言 | Must Have |
| 系统OCR | 本地 | Windows/macOS内置 | Should Have |
| PaddleOCR | 本地 | 百度开源，中文效果好 | Should Have |

#### 引擎配置

```typescript
interface OCREngine {
  id: string;              // 引擎ID
  name: string;            // 显示名称
  type: 'local' | 'cloud'; // 类型
  languages: string[];     // 支持的语言
  installed: boolean;      // 是否已安装
  version?: string;        // 版本号
}
```

### 3.4 结果显示与编辑 (O-005, O-006)

#### 功能描述

显示识别结果，支持用户编辑修改。

#### 识别结果

```typescript
interface OCRResult {
  id: string;
  text: string;            // 识别文本
  confidence: number;      // 置信度 0-100
  blocks: TextBlock[];     // 文本块
  language: string;        // 检测到的语言
  processingTime: number;  // 处理时间(ms)
}

interface TextBlock {
  text: string;
  boundingBox: {           // 边界框
    x: number;
    y: number;
    width: number;
    height: number;
  };
  confidence: number;
}
```

#### 编辑功能

| 功能 | 说明 |
|------|------|
| 文本编辑 | 直接修改识别文本 |
| 格式保留 | 保留段落格式 |
| 撤销/重做 | 支持编辑撤销 |
| 查找替换 | 查找和替换文本 |

## 4. 数据模型

### 4.1 OCR记录 (OCRRecord)

```typescript
interface OCRRecord {
  id: string;
  imagePath: string;       // 原图路径
  engine: string;          // 使用的引擎
  language: string;        // 识别语言
  result: OCRResult;       // 识别结果
  editedText?: string;     // 编辑后的文本
  status: 'pending' | 'processing' | 'completed' | 'failed';
  createdAt: Date;
}
```

## 5. API接口

### 5.1 识别图片

```
POST /api/ocr/recognize
```

**请求体：**
```json
{
  "imagePath": "/path/to/image.png",
  "engine": "tesseract",
  "language": "chi_sim+eng",
  "options": {
    "psm": 3,
    "oem": 3
  }
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "recordId": "uuid",
    "text": "识别出的文字内容",
    "confidence": 95,
    "language": "chi_sim",
    "processingTime": 1200
  }
}
```

### 5.2 批量识别

```
POST /api/ocr/batch
```

**请求体：**
```json
{
  "imagePaths": ["/path/to/image1.png", "/path/to/image2.png"],
  "engine": "tesseract",
  "language": "auto"
}
```

## 6. 错误处理

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| O001 | 引擎未安装 | 引导安装OCR引擎 |
| O002 | 语言包缺失 | 下载对应语言包 |
| O003 | 图片格式不支持 | 转换图片格式 |
| O004 | 图片损坏 | 检查图片文件 |
| O005 | 识别失败 | 调整图片或更换引擎 |
| O006 | 内存不足 | 关闭其他应用 |
