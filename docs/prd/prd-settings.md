# 系统设置模块 PRD

**模块名称：** 系统设置
**优先级：** Must Have
**所属Epic：** EPIC-005 系统基础设施
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

系统设置模块提供应用程序的配置管理功能，包括API密钥管理、界面设置、数据管理等功能。

### 1.1 功能目标

- 提供统一的设置入口
- 安全管理API密钥
- 支持界面个性化
- 提供数据导入导出

### 1.2 目标用户

- 所有用户

## 3. 详细功能说明

### 3.1 API密钥管理 (ST-001)

#### 功能描述

安全管理各服务的API密钥，支持添加、编辑、删除和测试。

#### 支持的服务

| 服务类型 | 服务名称 | 配置项 |
|----------|----------|--------|
| AI对话 | 通义千问 | API Key |
| AI对话 | 豆包 | API Key, Endpoint |
| AI对话 | GLM | API Key |
| AI对话 | DeepSeek | API Key |
| AI对话 | OpenAI | API Key, Base URL |
| AI对话 | Claude | API Key |
| 图像生成 | 通义万项 | API Key |
| 图像生成 | 火山引擎 | API Key, Access Key |
| 视频生成 | 火山引擎 | API Key, Access Key |
| 语音服务 | 火山引擎豆包语音 | App ID, Access Token |
| 翻译 | 火山翻译 | API Key |
| 翻译 | 百度翻译 | App ID, Secret Key |
| 搜索 | Bing Search | API Key |

## 4. 数据模型

### 4.1 应用设置 (AppSettings)

```typescript
interface AppSettings {
  theme: 'light' | 'dark' | 'system';
  language: 'zh-CN' | 'en-US';
  fontSize: 'small' | 'medium' | 'large';
  accentColor: string;

  defaultModel: {
    dialog: string;
    image: string;
    video: string;
    tts: string;
    translate: string;
  };

  autoSearch: boolean;
  searchConfirm: boolean;

  shortcuts: Record<string, string>;

  storage: {
    dataPath: string;
    maxCacheSize: number;
  };
}
```

## 5. API接口

### 5.1 获取设置

```
GET /api/settings
```

### 5.2 更新设置

```
PUT /api/settings
```

**请求体：**
```json
{
  "theme": "dark",
  "language": "zh-CN"
}
```

### 5.3 导出数据

```
POST /api/settings/export
```

### 5.4 导入数据

```
POST /api/settings/import
```
