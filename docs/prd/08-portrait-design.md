# 人像设计功能 PRD

## 1. 功能概述

人像设计功能是一个基于 AI 的角色形象生成系统，用户可以通过提示词和参考图片创建人物形象，并生成包含多个角度、多种服装、多种背景的人物系列图。

### 1.1 核心价值

- **角色一致性**：生成的人物形象在不同场景下保持高度一致性
- **多角度展示**：支持正面、左侧、右侧、背面四个视角
- **灵活变换**：支持换衣、换背景等二次创作
- **批量生成**：一次操作生成系列图，提高创作效率

### 1.2 目标用户

- 游戏开发者：需要快速生成角色原型
- 漫画/插画师：需要角色参考图
- 内容创作者：需要虚拟形象
- AI 艺术爱好者：探索 AI 创作可能性

**优先级**：Must Have

**需求描述**：用户可以通过提示词和参考图片生成人物形象

**操作流程**：
1. 选择图像提供商和模型
2. 输入人物描述提示词
3. （可选）上传参考图片作为风格参考
4. 选择生成角度（默认四角度全选）
5. 点击生成按钮
6. 等待生成完成，展示四角度人物图

- [ ] 支持输入人物描述提示词（1-2000 字符）

- [ ] 生成的人物形象在四个角度保持面部和体型一致性
- [ ] 默认使用纯色背景（白色或灰色）
- [ ] 生成结果可在结果区域展示

#### FR-PORTRAIT-002 四角度同步生成

**优先级**：Must Have

**需求描述**：一次生成操作可同时生成正面、左侧、右侧、背面四个角度的人物图

**业务规则**：
- 四个角度使用相同的人物特征描述
- 通过 AI 提示词工程技术确保一致性
- 生成时保持相同的随机种子或使用 IP-Adapter 等技术
- 单次生成最多 4 张图（四角度）

**验收标准**：
- [ ] 四张图片分别标注视角（正面/左侧/右侧/背面）
- [ ] 人物面部特征、体型、服装在各角度保持一致
- [ ] 支持单独重新生成某一角度
- [ ] 显示整体生成进度

## 5. 数据模型设计

### 5.1 人物项目（PortraitProject）

项目作为容器，包含多个人物角色。

```typescript
interface PortraitProject {
  id: string                    // 项目 ID
  name: string                  // 项目名称
  description?: string          // 项目描述
  createdAt: number            // 创建时间
  updatedAt: number            // 更新时间
}
```

### 5.2 人物角色（PortraitCharacter）

每个角色有独立的基本信息和生成配置。

```typescript
interface PortraitCharacter {
  id: string                    // 角色 ID
  projectId: string             // 所属项目 ID
  name: string                  // 人物姓名
  gender: 'male' | 'female'     // 性别
  age: number                   // 年龄
  height: number                // 身高(cm)
  weight: number                // 体重(kg)
  race: 'asian' | 'european'    // 人种
  description?: string          // 人物简介

  // 生成配置
  prompt: string                // 人物描述提示词（可自动生成或手动修改）
  referenceImages: string[]     // 参考图片路径
  providerId: string            // 提供商 ID
  modelId: string               // 模型 ID
  config: PortraitGenerateConfig  // 生成配置

  createdAt: number             // 创建时间
  updatedAt: number             // 更新时间
}

interface PortraitGenerateConfig {
  angles: ('front' | 'left' | 'right' | 'back')[]  // 生成角度
  backgroundType: 'solid' | 'transparent'           // 背景类型
  backgroundColor?: string                          // 背景颜色
}
```

### 5.3 人物变体（PortraitVariant）

每个角色可以有多个变体（基础形象、换衣、换背景）。

```typescript
interface PortraitVariant {
  id: string                    // 变体 ID
  characterId: string           // 所属角色 ID
  type: 'base' | 'clothes' | 'background'  // 变体类型
  parentId?: string             // 父变体 ID（用于追溯）

  // 生成信息
  angle: 'front' | 'left' | 'right' | 'back'  // 视角
  imagePath: string             // 图片路径
  prompt: string                // 使用的提示词
  config: Record<string, any>   // 生成配置

  // 变体特有信息
  variantInfo?: {
    clothesDescription?: string      // 换衣描述
    backgroundDescription?: string   // 背景描述
    backgroundType?: string          // 背景类型
    backgroundColor?: string         // 背景颜色
  }

  createdAt: number             // 创建时间
}
```

### 5.4 数据库表设计

```sql
-- 人物项目表
CREATE TABLE portrait_projects (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

-- 人物角色表
CREATE TABLE portrait_characters (
  id TEXT PRIMARY KEY,
  project_id TEXT NOT NULL,
  name TEXT NOT NULL,
  gender TEXT NOT NULL,
  age INTEGER NOT NULL,
  height INTEGER NOT NULL,
  weight INTEGER NOT NULL,
  race TEXT NOT NULL,
  description TEXT,
  prompt TEXT NOT NULL,
  reference_images TEXT,        -- JSON 数组
  provider_id TEXT NOT NULL,
  model_id TEXT NOT NULL,
  config TEXT,                  -- JSON 对象
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  FOREIGN KEY (project_id) REFERENCES portrait_projects(id) ON DELETE CASCADE
);

-- 人物变体表
CREATE TABLE portrait_variants (
  id TEXT PRIMARY KEY,
  character_id TEXT NOT NULL,
  type TEXT NOT NULL,           -- base/clothes/background
  parent_id TEXT,
  angle TEXT NOT NULL,          -- front/left/right/back
  image_path TEXT NOT NULL,
  prompt TEXT NOT NULL,
  config TEXT,                  -- JSON 对象
  variant_info TEXT,            -- JSON 对象
  created_at INTEGER NOT NULL,
  FOREIGN KEY (character_id) REFERENCES portrait_characters(id) ON DELETE CASCADE
);

-- 索引
CREATE INDEX idx_characters_project ON portrait_characters(project_id);
CREATE INDEX idx_variants_character ON portrait_variants(character_id);
CREATE INDEX idx_variants_type ON portrait_variants(type);
```

## 6. 技术方案要点

### 6.1 角色一致性保障

推荐使用以下技术方案确保多角度一致性：

1. **Seed 控制**：四个角度使用相同种子
2. **IP-Adapter**：使用参考图作为风格引导
3. **LoRA/Character Reference**：角色特征学习
4. **Prompt 工程**：固定人物特征描述，仅改变视角描述

### 6.2 换衣/换背景实现

1. **Inpainting**：局部重绘技术
2. **ControlNet**：姿态控制保持一致
3. **Segmentation**：人物分割提取

### 6.3 提供商适配

需要提供商支持以下能力：
- 图生图（Image-to-Image）
- 局部重绘（Inpainting）
- ControlNet 或类似能力

## 7. 用户流程

### 7.1 基础生成流程

```
开始 → 选择 Tab "人像设计" → 选择提供商/模型
     → 输入人物描述 → 上传参考图（可选）
     → 选择角度 → 设置背景 → 点击生成
     → 等待生成完成 → 查看结果
     → 满意则保存项目 / 不满意则调整重试
     → 结束
```

### 7.2 换衣流程

```
开始 → 打开人物项目 → 选择要换衣的图片
     → 点击"换衣" → 输入新服装描述
     → 选择应用角度 → 点击生成
     → 查看结果 → 满意保存 / 不满意重试
     → 结束
```

### 7.3 换背景流程

```
开始 → 打开人物项目 → 选择要换背景的图片
     → 点击"换背景" → 选择背景类型
     → 设置背景参数 → 选择应用角度
     → 点击生成 → 查看结果 → 满意保存 / 不满意重试
     → 结束
```

### 8.1 无支持 Inpainting 的提供商

**场景**：用户配置的提供商不支持局部重绘

**处理**：
- 换衣/换背景功能禁用
- 显示提示："当前提供商不支持换衣/换背景功能，请使用其他提供商"

### 8.2 生成失败

**场景**：部分角度生成失败

**处理**：
- 成功的角度正常展示
- 失败的角度显示错误状态
- 提供"重新生成失败角度"按钮

### 8.3 存储空间不足

**场景**：用户磁盘空间不足

**处理**：
- 生成前检查存储空间
- 空间不足时提示用户清理
- 提供清理建议（删除旧项目）
