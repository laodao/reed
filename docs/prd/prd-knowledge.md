# 知识库模块 PRD

**模块名称：** 知识库
**优先级：** Should Have
**所属Epic：** EPIC-004 知识管理与智能搜索
**日期：** 2026-03-01
**版本：** 2.0

---

## 1. 模块概述

知识库模块提供知识管理能力，支持创建、管理和检索知识库，并与AI对话集成，实现基于知识库的智能问答。

### 1.1 功能目标

- 支持创建多个知识库
- 支持多种文档格式导入
- 提供知识库检索功能
- 支持与AI对话集成（RAG）

### 1.2 目标用户

- 开发者
- 内容创作者
- 研究人员

## 3. 详细功能说明

### 3.1 创建知识库 (K-001)

#### 功能描述

用户可以创建新的知识库，用于存储和管理特定领域的知识。

#### 操作流程

```
1. 用户点击"新建知识库"
2. 填写知识库信息（名称、描述）
3. 选择嵌入模型
4. 点击"创建"
5. 系统创建知识库
6. 进入知识库管理界面
```

#### 输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 知识库名称 | string | 是 | 2-50字符 |
| 描述 | string | 否 | 知识库描述，最多500字符 |
| 嵌入模型 | string | 是 | 用于向量化的模型 |
| 图标 | file | 否 | 知识库图标 |

#### 界面布局

```

├─────────────────────────────────────────┤
│  知识库名称: *                           │

│  └─────────────────────────────────────┘│
│                                          │
│  描述:                                   │
│  ┌─────────────────────────────────────┐│
│  │ 存储我的技术学习笔记和文档...        ││
│  └─────────────────────────────────────┘│
│                                          │
│  嵌入模型: *                             │
│  [通义千问-Embedding ▼]                  │
│                                          │
│  图标: (可选)                            │
│  [📁 选择图片]                           │
├─────────────────────────────────────────┤
│  [取消]  [创建]                          │
└─────────────────────────────────────────┘
```

#### 边界检查

| 检查项 | 规则 | 错误提示 |
|--------|------|----------|
| 名称长度 | 2-50字符 | "名称长度需在2-50字符之间" |

| 数量限制 | 最多20个知识库 | "知识库数量已达上限" |

### 3.2 文档导入 (K-002)

#### 功能描述

将文档导入知识库，系统自动进行解析和向量化处理。

#### 支持的文档格式

| 格式 | 扩展名 | 最大文件大小 | 说明 |
|------|--------|--------------|------|
| PDF | .pdf | 50MB | PDF文档 |
| Word | .docx, .doc | 50MB | Word文档 |
| 文本 | .txt | 10MB | 纯文本 |
| Markdown | .md | 10MB | Markdown文档 |
| HTML | .html, .htm | 10MB | 网页文件 |
| CSV | .csv | 10MB | 表格数据 |
| JSON | .json | 10MB | JSON数据 |

#### 操作流程

```
1. 用户进入知识库
2. 点击"导入文档"
3. 选择或拖拽文件
4. 系统解析文档内容
5. 进行文本分块
6. 调用嵌入模型向量化
7. 存储到向量数据库
8. 显示导入结果
```

## 4. 数据模型

### 4.1 知识库 (KnowledgeBase)

```typescript
interface KnowledgeBase {
  id: string;
  name: string;            // 知识库名称
  description?: string;    // 描述
  embeddingModel: string;  // 嵌入模型
  icon?: string;           // 图标
  documentCount: number;   // 文档数量
  chunkCount: number;      // 片段数量
  createdAt: Date;
  updatedAt: Date;
}
```

### 4.2 文档 (Document)

```typescript
interface Document {
  id: string;
  knowledgeBaseId: string; // 所属知识库
  name: string;            // 文档名称
  type: string;            // 文档类型
  size: number;            // 文件大小
  content: string;         // 文本内容
  chunkCount: number;      // 分块数量
  status: 'pending' | 'processing' | 'completed' | 'failed';
  createdAt: Date;
}
```

### 4.3 文本片段 (Chunk)

```typescript
interface Chunk {
  id: string;
  documentId: string;      // 所属文档
  content: string;         // 文本内容
  embedding: number[];     // 向量
  metadata: {              // 元数据
    source: string;
    page?: number;
    position?: number;
  };
  createdAt: Date;
}
```

## 5. API接口

### 5.1 创建知识库

```
POST /api/knowledge/create
```

**请求体：**
```json
{
  "name": "我的技术文档库",
  "description": "存储技术学习笔记",
  "embeddingModel": "qwen-embedding"
}
```

### 5.2 导入文档

```
POST /api/knowledge/import
```

**请求体：**
```json
{
  "knowledgeBaseId": "uuid",
  "filePath": "/path/to/document.pdf",
  "options": {
    "chunkSize": 500,
    "overlap": 50
  }
}
```

### 5.3 检索知识

```
POST /api/knowledge/search
```

**请求体：**
```json
{
  "knowledgeBaseId": "uuid",
  "query": "如何使用Electron",
  "topK": 5
}
```

## 6. 错误处理

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| K001 | 嵌入模型不可用 | 检查模型配置 |
| K002 | 文档解析失败 | 检查文档格式 |
| K003 | 向量化失败 | 重试或检查内容 |
| K004 | 存储空间不足 | 清理知识库 |
| K005 | 知识库不存在 | 检查知识库ID |
| K006 | 文件过大 | 压缩或分割文件 |
