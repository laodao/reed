# 当前实现 vs 业务标准 · gap 映射

> 日期：2026-05-10
> 配套文档：[业务流程文档](./2026-05-10-ai-video-production-business-flow.md)（业务对照表）
> 目的：把当前 6 stage 实现映射到 8 业务环节，标差距，定优先级

---

## 0. 总映射表

```
业务 8 环节                         当前 6 stage                    状态
───────────────────────────────────────────────────────────────────────
1 创意立项     ──────────►  EpisodeProjectListV2 (项目列表 + 创建)    △ 字段不全
2 故事剧本     ──────────►  ① 内容 + ③ 剧本（合并 V3）                ✓ 已实现
3 资产建立     ──────────►  ② 资产                                    ✓ 已实现
4 分镜设计     ──────────►  ④ 分镜                                    △ 字段错位
5 画面生成     ─┐
                ├──────►   ⑤ 制作                                     △ 字段堆叠
6 运动生成     ─┘
7 声音        ──────────►  ⑤ 制作 AudioPanel（位置错）                △ 错位
8 合成剪辑     ──────────►  ⑥ 合成                                    ✓ 已实现
```

**关键观察**：
- 当前架构 ⑤ 制作 stage **同时**承担"画面生成 + 运动生成 + 声音"三个业务环节 → 字段过载
- ④ 分镜 stage 含转场字段（属于 ⑧ 合成业务） → 错位
- 创意立项缺关键业务元信息（题材 / 平台 / 受众 / 美术风格）

## 1. 环节 1 · 创意立项

### 业务标准要素

| 要素 | 业务作用 |
|---|---|
| 题材类型 | 短剧 / 广告 / 解说 / 教程 / MV |
| 目标平台 | 抖音 / B 站 / YouTube / 朋友圈 |
| 目标受众 | 年龄段 / 兴趣群体 |
| 整体时长 | 15s / 60s / 3min |
| 画幅 | 9:16 / 16:9 / 1:1 |
| 美术风格 | 写实 / 动漫 / 国风 / 赛博朋克 |
| 故事世界 | 年代 / 地域 / 整体调性 |
| 参考素材 | 参考视频 / 画风图 / 剧本 |

### 当前实现

`video_projects` 表字段：
```
id / name / longWritingProjectId / status / config{ aspectRatio, resolution, fps, 5 个 AI model } / createdAt / updatedAt
```

`video_episodes` 表（剧集级）有：
```
storyEra / storyRegion / storyBackgroundExtra
```

**AI 一键模式**：`AIQuickModeWizard` 已实现，含 一句话主题 + 时长 + 风格 输入。

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| G1.1 | **题材类型缺失** — 没有"短剧/广告/解说/MV"分类，所有项目同质化 | 🟡 中 |
| G1.2 | **目标平台缺失** — 影响时长、画幅、字幕样式的预设决策 | 🟡 中 |
| G1.3 | **目标受众缺失** — 影响语言风格、节奏、画面美术 | 🟢 低 |
| G1.4 | **美术风格在项目级缺失** — 实际散在 binding.styleAnchors / styleHint 各处，没有项目级"全剧风格锚定" | 🔴 高 |
| G1.5 | **故事世界放错层级** — `storyEra/storyRegion` 在 episode 级而非 project 级；多剧集项目共用一个世界观时无法复用 | 🟡 中 |
| G1.6 | **参考素材入口缺失** — 业务文档环节 1 提到"从参考视频起步"，当前虽然有 ReferenceVideoAnalysisService 表但 UI 入口不明显 | 🟡 中 |
| G1.7 | **AI 一键模式没用项目元信息** — 一键 wizard 只问 主题/时长/风格 三项，没用到 平台/受众/题材 | 🟢 低 |

### 改进建议

- **R1.A**（必做）项目级加 `genre`（题材）/ `aspectRatio` 已有 / `targetDurationHint` / `artStyle`（美术风格）/ `targetPlatform` 5 个字段
- **R1.B**（必做）美术风格升为**项目级锚定**字段 — 后续每个画面生成都自动套用，UI 上明显展示当前风格
- **R1.C**（建议）`storyEra/storyRegion` 升到 project 级，episode 级保留 override（少数剧集需要不同年代时）
- **R1.D**（建议）"从参考视频起步"做成项目创建时的 第三个 tab（标准 / AI 一键 / 参考视频）

## 3. 环节 3 · 资产建立

### 业务标准要素

| 类别 | 要素 |
|---|---|
| 角色身份 | 姓名 / 别名 / 定位 / 性别 / 年龄 / 人种 |
| 角色视觉 | 体型 / 肤色 / 发型 / 服装 / 标志特征 |
| 角色表演 | 性格 / 情感倾向 / 招牌动作 |
| 角色配音 | 音色 / 语速 / 语调 / 情感 |
| **角色形象库** | 多角度图（正/侧/背）+ 表情图 + 服装图 |
| 地点 | 名称 / 描述 / 形象库（不同时间/天气/视角）|
| 物品 | 名称 / 形状 / 材质 / 标志特征 |
| **项目级风格锚定** | 美术风格代表图 + 调色板 |

### 当前实现

`AssetStageViewV2` + `CharacterAssetCardV2` / `LocationAssetCardV2` / `ItemAssetCardV2`：
- 完整 CRUD
- 主图生成（主图 isMain=1）
- 多角度参考图（character view 类）
- 多张主图（仅 location）
- 派生（expression / outfit / pose / variant）
- ⭐ 角色形象组（reference_set_image_ids，已实现）
- 跨项目库（user_assets，已实现）
- 数字人池（preset_digital_humans，已实现）
- 透明度面板（GenerationDetailDialog，已实现）

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| G3.1 | **角色配音字段散乱** — voice_id / voice_speed / voice_pitch / voice_emotion 分散在 binding 表，没有"音色试听 + 一致性管理"统一面板 | 🟡 中 |
| G3.2 | **角色性格 / 表演倾向不进生成 prompt** — 业务上是有用的（影响 AI 拆分镜时的角色动作），当前完全不参与 | 🟢 低 |
| G3.3 | **项目级美术风格锚定** — 当前只有 binding.styleAnchors（每个角色单独一份），项目级缺独立风格资产 | 🔴 高（重复 G1.4） |
| G3.4 | **形象组的 UI 透明度不足** — 用户不知道"这一组图会被自动喂给 AI"（业务文档 §3.1 D1 强调） | 🟡 中（已在重设计文档 D1-D3 提及） |
| G3.5 | 视频提取主体（业务文档"参考素材 → 角色"路径）未实现 | 🟢 低 |

### 改进建议

- **R3.A**（必做）建项目级"美术风格"独立资产（不是每个角色重复填）
- **R3.B**（建议）角色配音管理面板（音色试听 + 全剧角色音色列表）
- **R3.C**（建议）形象组 UI 透明度提升（前面重设计文档已规划 Phase D）

## 4. 环节 4 · 分镜设计

### 业务标准要素

| 类别 | 业务要素 |
|---|---|
| 画面内容 | 画面描述 / 主体 / 构图 |
| 镜头语言 | 景别 / 角度 / 运镜 / 摄影参数 |
| 光照氛围 | 打光风格 / 时间 / 天气 |
| 角色配置 | 出场角色 / 位置 / 表情 / 动作 / 朝向 |
| 物品引用 | 出场物品 |
| 音频引用 | 旁白片段 / 对白片段 / 音效提示 |
| 时序 | 时长 |
| **不属于本环节** | 转场（是合成阶段事） |

### 当前实现

`StageStoryboardViewV2`：
- 镜头工具栏：景别 / 角度 / 运镜（25 预设）/ 时长 / 焦距 / 光圈 / 相机风格
- 打光预设（metadata.lighting）
- **转场工具栏**：类型 / 时长 / 方向 / 缓动 / 颜色 ← **错位**
- 画面描述（自由 textarea）
- 镜头内角色配置（位置 / 表情 / 动作 / 朝向）
- 关键帧数 + 生成模式（useKeyframes）
- 资产引用挑图（storyboard.referenceImageIds）
- 3D 摆位（高级）+ backgroundRefImageId

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| **G4.1** | **🚨 转场字段放在分镜阶段** — 转场是相邻分镜之间的事，属于 ⑥ 合成业务；放 ④ 分镜让用户在错地方决策，且这些字段不影响画面/视频生成 | 🔴 **高** |
| G4.2 | **画面描述无引导** — 自由 textarea，新手不知道写什么；业务文档环节 4 提到"短剧 5 段 / 影视 5 字段"模板 | 🟡 中 |
| G4.3 | **音频引用 ID 字段裸露** — narrationId / dialogueIds[] / actionIds[] 字段对用户裸露，业务上只是引用关联，不该作为编辑字段 | 🟡 中 |
| G4.4 | **用户介入策略不分层** — 自媒体用户填不满 19 个字段，专业用户又觉得每镜头逐个配很慢；缺"按 AI 默认 / 按预设 / 全自定义"三层 | 🟡 中 |
| G4.5 | **3D 摆位字段平铺** — 高级功能 80% 用户用不到，应折叠 | 🟢 低 |
| G4.6 | **生成模式（useKeyframes）切换 UI 反馈不强** — 文生图模式下镜头语言/角色配置等字段无效，但 UI 没隐藏（前面重设计文档 Phase A） | 🟡 中（已规划） |

### 改进建议

- **R4.A**（必做）**转场字段移到 ⑥ 合成**（最重要的错位修复）
- **R4.B**（必做）画面描述加双模板引导（业务文档环节 4 的模板）
- **R4.C**（建议）音频引用 ID 折叠到"详情"区或自动维护
- **R4.D**（建议）3D 摆位移到高级折叠
- **R4.E**（必做）文生图模式下隐藏镜头语言（重设计文档 Phase A）

## 5. 环节 5 · 画面生成

### 业务标准要素

| 模式 | 输入 |
|---|---|
| 单帧 | 文本 prompt + 参考图 + 风格锚定 + 画幅 |
| 关键帧序列 | 同上 + 多帧之间的链式参考 |

| 用户介入点 | 业务含义 |
|---|---|
| 不满意时改哪一项 | 风格 / 角色 / 构图 / 表情 各自对应明确字段 |

### 当前实现

`StageProductionViewV2` 的关键帧部分：
- KeyframeGrid（9 宫格）
- 每帧卡：缩略图 + 重生成按钮 + 资产 chip + 「基于」参考图列表（5+ 张）
- 关键帧下「🎯 挑图」按钮（KeyframeReferencePicker）
- 底部「本分镜引用资产」挑图入口

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| **G5.1** | **🚨 双挑图入口冗余** — 关键帧下 per-frame + 底部 per-storyboard 两个，用户分不清 | 🔴 **高** |
| **G5.2** | **🚨 「最终提示词预览」装饰性** — 显示 7 段但不全进 prompt，误导用户调错地方 | 🔴 **高** |
| G5.3 | **不满意 → 改哪里"对应关系"不清** — 业务文档强调"风格不对改风格 / 角色不对改角色"，当前 UI 没体现这种 troubleshooting guide | 🟡 中 |
| G5.4 | 关键帧详情 dialog 缺失（透明度面板只在 ② 资产实现） — 看不到本帧完整 prompt / refImage / 模型 | 🟡 中 |
| G5.5 | **画面 vs 运动混在同一面板** — 业务上是两个独立环节（画面生成 → 运动生成），当前 UI 没分隔，让用户困惑 | 🟡 中 |

### 改进建议

- **R5.A**（必做）**删除关键帧下 per-frame 挑图**，保留底部 storyboard-level 挑图（重设计 Phase C）
- **R5.B**（必做）**改造「最终提示词预览」**为两段：keyframe prompt（完整）+ video prompt（仅 frameDescription，明确标注）
- **R5.C**（建议）关键帧卡加 ⓘ 详情按钮（透明度面板）
- **R5.D**（必做）**画面生成 panel 与运动生成 panel 视觉分隔**（不同 section + 标题）

## 6. 环节 6 · 运动生成

### 业务标准要素

| 模式 | 输入 |
|---|---|
| 文生视频 | 仅文本 |
| 图生视频 | 1 张图 + 运动描述 |
| 关键帧视频 | 多张图 + 运动描述 |

| 不进运动生成的字段 | 角色身份 / 地点 / 物品 / 镜头语言 / 光影 / 对白 / 旁白 / 转场 |

### 当前实现

`VideoSegmentPanel`：
- 只读分镜信息行
- 「最终提示词预览」（含 7 段，但实际只用 frameDescription）
- 「调整方向」textarea（实际只影响 keyframe，不影响 video）
- 「重新生成」按钮
- 视频预览

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| **G6.1** | **🚨 video prompt 只用 frameDescription** — 但 UI 显示一大堆字段假装都进了 | 🔴 **高**（已有 e2e 报告） |
| **G6.2** | **🚨 「调整方向」位置错误** — 在 video panel 下但只影响 keyframe；用户改了调整方向以为影响 video | 🔴 **高** |
| G6.3 | **缺运动描述字段** — 业务上"运动"应该是 video 的核心 prompt（"角色缓慢转身，目光由茶杯抬至窗外"），当前完全没有这个字段，靠用户在 frameDescription 里堆砌 | 🟡 中 |
| G6.4 | 缺"运动强度"参数（微动/普通/剧烈） | 🟢 低 |
| G6.5 | 三种生成模式（text2video / image2video / keyframes2video）由 capability matcher 自动决定，用户不知道走的哪个；部分专业用户希望强制指定 | 🟢 低 |

### 改进建议

- **R6.A**（必做）**重新定义 video prompt 业务含义** — 不是 frameDescription，而是"运动描述"（独立字段）
- **R6.B**（必做）**「调整方向」应同时影响 keyframe + video** 或明确标注只影响 keyframe（重设计 Phase B）
- **R6.C**（建议）加 storyboard.motionPrompt 字段（业务上的"动作描述"），与 frameDescription（业务上的"画面描述"）分开
- **R6.D**（建议）video 模式可选强制指定（专业用户）

## 7. 环节 7 · 声音

### 业务标准要素

| 类别 | 要素 |
|---|---|
| 旁白 | 文本 / 音色 / 语速 / 语调 / 情感 / 切分到分镜 |
| 对白 | 文本 / 角色音色 / 情感 / 时长 / **口型对齐** |
| BGM | 风格 / 段落规划 |
| 音效 | 关键音效列表 / 与分镜绑定 |

**业务时序对齐**：声音时长**反向决定**画面时长。

### 当前实现

`AudioPanel`（在 ⑤ 制作 stage 内）：
- 按 storyboard 过滤的旁白 / 对白
- 调用 ScriptAudioOrchestrator 生成音频
- 关联 narrationId / dialogueIds[]

⑥ 合成 stage 的 audio-mix.service.ts：
- 音频混合到 timeline

### 差距 / 反模式

| # | 差距 | 严重度 |
|---|---|---|
| **G7.1** | **🚨 AudioPanel 在 ⑤ 制作 stage 而非 ⑥ 合成** — 业务上声音是合成前的一道工序，与画面/运动生成同级，但 UI 上塞在制作 stage 让用户看不见 | 🔴 **高** |
| G7.2 | 缺统一**声音管理视图** — 全剧旁白/对白音频管理需要一个地方看 | 🟡 中 |
| G7.3 | **缺 BGM 管理** — 业务文档环节 7.3 提到的项目级 BGM 风格 + 段落规划，当前没看到入口 | 🟡 中 |
| G7.4 | **缺音效（SFX）管理** — 业务文档环节 7.3 提到的关键音效绑定到分镜，当前没看到 | 🟡 中 |
| G7.5 | **声音时长反向决定画面时长** — 业务上是核心一致性要求，当前声音生成完是否更新分镜时长？需确认 | 🟡 中 |
| G7.6 | **口型对齐** — 业务文档环节 7.2 提到的高级要求，当前完全没有 | 🟢 低 |

### 改进建议

- **R7.A**（必做）**AudioPanel 移到 ⑥ 合成 stage**（与转场移动一起做）
- **R7.B**（建议）声音管理统一视图（项目级看所有音频）
- **R7.C**（建议）加 BGM 管理 + 音效管理入口
- **R7.D**（建议）声音生成后同步更新分镜时长基线

## 8. 环节 8 · 合成剪辑

### 业务标准要素

- episode-mp4-exporter.service.ts（导出）

### 差距 / 反模式

| # | 差距 | 严重度 |

## 10. 三层决策模型 · 现状审视
