# 极睿科技电商功能清单 × 实现原理 × 本系统可行性评估

> 日期：2026-09-18 ｜ 前置调研：`docs/research/2026-09-18-ecommerce-infimind-benchmark.md`
> 评估基线：本系统 feat/story-room 当前能力面（workflow 引擎、provider 层、资产/知识库、agent harness）
> 结论速览：**内容生成侧功能约七成已具备或低成本可达（第一批 6 项已落地并实跑验证）；缺口集中在图像底层处理、排版/上架工程侧、垂直模型壁垒三类，前两类有清晰外挂路径，第三类建议不做。**

## 二、逐项：原理 / 技术路径 / 本系统可行性

### A. 已具备（0 新增，实跑验证过）

**#6 批量套图** — 原理：参数化批量（类型×姿势×场景矩阵展开，逐张带参考图编辑生成）。本系统 workflow `loop` + `image-gen`（multi-reference + promptExtend=false）已完整实现，且多了极睿没有的人工确认/重生成闭环（check1/condCheck/loop3）。

**#2 场景图/换背景** — 原理：参考图图像编辑（只改背景/环境，主体锁定）。本系统 scene 类型 + sceneHint 双通道已落地；底层 Seedream/wan image-edit 支持多参考图。

**#13+14 属性识别 + 文案生成** — 极睿原理：FashionCLIP 垂直识别 → ECGPT 文案。本系统用通用 VLM（vision llm-chat 的 analyze1 节点）达到"商用及格线"：商品认定/卖点 TOP3/人群/场景建议/广告语，图文同源注入全链。**垂直精度（99.2%）靠自训模型，不建议追**——属性体系用提示词结构化可覆盖长尾，精度差距主要体现在极端类目（服装版型/面料成分）。

### B. 可行、低成本（P1，1–2 天级）

**#10 商品短视频** — 极睿原理：图片素材 + 模板混剪（非文生视频）。本系统**架构已就位**：script-to-video-v3 的 asset 模式就是"素材池→分镜→i2v/合成"，且三家视频 provider 均支持图生视频（bailian wanx2.1-i2v-plus / 火山 / ComfyUI），TTS/ffmpeg 合成已有。做法 = 新增一条内置工作流：套图组（save-asset 的组）作为素材池输入 → LLM 排分镜与卖点口播 → i2v 动化 → 合成。代价主要是组装与提示词，不是基建。

**#4 抠图 / #5 超清放大** — 原理：显著性分割（BiRefNet/RMBG/SAM 族）与超分（RealESRGAN 或生成式 4K 重绘）。本系统无对应节点，但**不必自研**：两条路径都通——(a) 云端 API（DashScope/火山均有抠图/高清能力端点）；(b) ComfyUI 网关外挂（RMBG/BiRefNet/Ultimate SD Upscale 节点生态成熟）。做法 = 新增一个通用 `image-process` 工作流节点（操作类型：matting/upscale/…），路由到 provider。这也是"白底规范化预处理链"的地基（先抠图去杂背景，再进套图编辑，主体一致性更稳）。

**多色 SKU 套图**（极睿"颜色重排"的对应物）— 原理：图像编辑指令 change-color-keep-everything-else。posterTypes 加 colorway 类型 + 用户色号列表展开 loop 即可，纯模板改动。

### C. 可行、中高投入（P2，按需立项）

**#1 人台图→模特试穿** — 极睿原理：服装属性识别 + 姿态引导的可控生成（VTON，pose-guided inpainting）。本系统 0918 已落地的 model 类型（多参考图编辑"保持商品完全不变+真人上身"）可达约 80 分效果，已实跑验证（模特手持同款折扇、商品一致）。**精确 VTON**（版型/褶皱物理正确）需 ComfyUI 生态试穿工作流（IDM-VTON 类）或 dedicated API；若目标客户对版型还原挑剔再升级。品牌专属虚拟模特（极睿的高壁垒项）轻量版 = ComfyUI LoRA 训练工作流（同一张脸/身材 LoRA + 试穿编辑），可行但属独立立项。

**#7+#8 主图/详情页排版** — 极睿原理：**模板排版引擎而非生成**（结构化字段填充设计模板）。本系统缺排版层：需要设计模板库 + 渲染管线（服务端 sharp/node-canvas 合成，或前端 HTML 模板→printToPDF/PNG）。文案侧已图文同源就绪；卖点点位/卖点文案注入主图的"字"是排版问题不是生成问题（生成模型写中文字不可靠）。工作量在模板体系与渲染管线，属产品级投入；建议先做"详情页长图导出"单点验证。

**#11 直播切片** — 原理：ASR 转写 → 亮点检测（LLM 打分选段）→ ffmpeg 精切。本系统有 ASR/TTS/LLM/ffmpeg 全部零件，但**无直播实时链路**（拉流、弹幕、实时性）。录播文件切片版可行（video 文件→whisper→选段→切），实时版需流媒体基建，偏离桌面定位。

**#15 商品资产中台** — 极睿原理：DAM + 商品数据模型（SPU/SKU/类目属性）。本系统 asset-registry（组/标签）+ 知识库可承载"图与文档"，**缺商品维度数据模型**（商品档案、SKU、平台字段映射）。若电商场景要做深，这是绕不开的地基；当前定位下可先用"资产组 + 商品理解 JSON 存档"过渡。

### D. 可行但不建议做

**#3 换脸** — 原理：人脸检测 + 身份特征迁移（insightface/inswapper 类）。技术上 ComfyUI 生态现成，但**合规风险高**（《互联网深度合成规定》要求显著标识+被替换人授权，电商人像还叠加肖像权）。极睿拿它做"去侵权/原创化"有其法务体系，本系统作为桌面工具默认不做，最多在 ComfyUI 层留给高级用户自配。

**#9 一键上架 14 平台** — 原理：平台开放 API（淘宝 TOP/京东宙斯/拼多多开放平台）+ 字段映射引擎。技术可行但每平台一个适配器 + ISV 入驻/类目资质/授权链路，是**公司级商务工程**，且桌面单机形态拿不到多数平台的 ISV 资质。降级替代：按平台导出"适配包"（规格图 + 标准化字段 JSON/CSV），已有 specPreset 9 平台规格打底。

**#12 多渠道分发** — 同上，平台 API 授权问题；且与桌面创作工具定位偏差最大。

## 三、总体结论

1. **架构差异是评估前提**：极睿 = 云 SaaS + 自研垂直模型（ECGPT/FashionCLIP）+ 平台 API 闭环；本系统 = 本地桌面 agent/workflow + 通用大模型 API + ComfyUI 外挂。这个差异决定了：**生成类功能高度可行（通用多模态模型已够商用及格线），工程闭环类（上架/分发）可行但偏离定位，垂直模型壁垒类（自训识别/专属大模型）不值得追。**
2. **ComfyUI 网关是能力逃生舱**：抠图、放大、inpaint、精确试穿、LoRA 专属模特，全部可以以"ComfyUI 工作流 + 一个通用 image-process 节点"的方式外挂获得，不自研模型层——这是本系统对标极睿图像底层能力的最短路径。
3. **本系统已有的差异化优势**：人审确认/重生成闭环（极睿是纯自动批量）、图文同源的商品认知注入、agent harness（可把套图生成包成 agent 工具做对话式驱动）。
4. **已验证事实**：第一批对标优化（商品理解/模特图/场景提示/种草图/图文同源/平台规格）已于 2026-09-18 落地并真机实跑成功（火山 Seedream-5.0-lite 多参考编辑 + qwen-vl-max 商品理解，4 图 + 清单，主体一致性目检通过）。

## 四、建议路线

- **P1（低成本高收益）**：① 套图→主图视频（复用 V3 asset 模式组一条内置工作流）；② colorway 多色 SKU；③ `image-process` 节点（先接抠图+放大，云端 API 优先、ComfyUI 兜底），并把它插进套图链做白底预处理。
- **P2（按需立项）**：④ 详情页长图排版导出单点；⑤ ComfyUI 精确试穿工作流；⑥ 商品档案数据模型（若电商方向坐实）。
- **不做**：自训垂直识别模型、API 上架/分发对接、实时直播切片、换脸（合规）。
