# 前沿学习形态 + 中国市场调研

> 调研日期：2026-10-09 ｜ 方法：WebSearch+WebFetch 中英文交叉检索一手来源（官方产品页/GitHub/arXiv/官方博客/应用商店/权威媒体），结论标来源与时间。

## 0. 执行摘要

1. **"先对齐→确认→落库"的三阶段仪式已是落后形态**。Co-STORM 用"多智能体圆桌+动态思维导图"证明：规划可以是**持续生长、随时接管**的过程，而非前置审批流程；秘塔"今天学点啥"更是零仪式、一键成课。
2. **讲义形态正从"文字卡"走向"带溯源的可交互课程"**（Kimi Researcher 图表报告、秘塔视频课+PPT 导出、Gemini Guided Learning 的图示与视频）。
3. **修图不该靠手动**。讯飞"测-学-练"闭环与松鼠 AI"错因分析→知识漏洞回溯"证明：**测验数据本身就是修图信号**，图谱应随答题自动更新。
4. **单人对话的动力系统**有成熟解法：讯飞"少量题快速定位弱项"的减负感、粉笔刷题文化、Duolingo 角色+XP、AI 学生（费曼 teach-back）的社交替代。
5. **跨会话学习者画像**技术已商品化（Mem0/Zep/Letta/OpenAI Memory），可直接借其"事实抽取+决策更新+时序图谱"三件套。

## 一、全球前沿形态

### 1. STORM / Co-STORM（Stanford OVAL）：多视角圆桌产出知识结构

- **STORM**（[arXiv:2402.14207](https://arxiv.org/abs/2402.14207)，NAACL 2024）：聚焦"写前研究"——**视角发现**（调研同类已有文章，归纳该主题通常涉及的视角）→**模拟对话**（"带特定视角的维基作者"与"以互联网资料为据的领域专家"多轮问答，累积带引用的研究资料）。效果：多视角专家代理的研究比单 prompt 方式组织度约高 25%。四个可定制模块：知识策展/大纲生成/文章生成/打磨（各自独立开关）。来源：[官方项目页](https://storm-project.stanford.edu/research/storm)、[GitHub stanford-oval/storm](https://github.com/stanford-oval/storm)
- **Co-STORM**（[arXiv:2408.15232](https://arxiv.org/abs/2408.15232)，EMNLP 2024）=人机协作知识策展，三种角色轮转：
  - **多个 LLM 专家**：基于外部信源作答并互相追问；
  - **主持人**：从未被直接使用的检索材料里抛"启发式问题"防跑偏；
  - **人类用户**：可纯旁观（观察讨论建立理解）也可随时插话改向；
  - **动态思维导图**：持续更新的层级概念结构，作为人机共享概念空间，降低长对话认知负荷——**"规划过程可视化"的原型**。
  - API 三步：`warm_start()`（用户一句话起步，先生成初始共享空间）→ 反复 `step()`（旁观或注入话语）→ `generate_report()`（重组知识库产出带引用报告）。
- 现状：storm.genie.stanford.edu 为 research preview，7 万+人试用。查证："MindMapRex" 未检索到任何可证实同名产品。
- **启示**：Co-STORM 证明"多角色圆桌+共享导图"可**替代"AI 单体规划+用户审批"仪式**——规划不再是三步关卡，而是用户可随时旁观/插话的持续过程。

### 2. 深度研究智能体：报告形态与知识库联动

- **OpenAI Deep Research**（2025-02）：find→analyze→synthesize 数百来源，分析师级长报告带内联引用；一次性长文形态，无原生知识图谱/卡片化。来源：[官方](https://openai.com/index/introducing-deep-research)
- **Gemini Deep Research**：关键差异在**联动链路**——报告一键导出 Google Docs；可直接送入 NotebookLM；报告带内嵌可视化图表。**"研究报告→笔记本（可问答/生成导图/音频）"是最接近我们"研究轮→落库→学"的完整链路**。来源：[Google 帮助](https://support.google.com/gemini/answer/15719111)、[MakeUseOf](https://www.makeuseof.com/gemini-notebooklm-research-reports/)
- **Kimi Researcher**（2025-06）：国内首个端到端 Agentic RL 训练的深度研究智能体；HLE 8.6%→26.9%；产出**含丰富图表、可追溯引用的万字报告，多格式输出**。来源：[官方](https://www.kimi.com/deep-research)
- **秘塔深度研究**：国内免费，"证据链"式呈现+自动生成可视化对比表格。
- **启示**：研究产物已从"一篇长文"进化为"图表+引用+多格式"；我们的"研究轮"应把产物直接结构化落成**带溯源的素材卡**，而不是让 AI 裸奔自答。

### 3. AI 记忆框架→跨会话学习者画像

| 框架 | 抽取/更新机制 | 检索机制 | 对学习者画像的适配 |
|---|---|---|---|
| **Mem0** | 两阶段：LLM 从对话抽取候选事实→第二次 LLM 调用对既有记忆做 ADD/UPDATE/DELETE/NOOP 决策 | 向量语义相似度 | "用户说过什么"：目标、职业、薄弱点、偏好，随对话自动维护 |
| **Zep / Graphiti** | **时序知识图谱**（episodes→实体→社区），边带时间有效性（事实会过期失效） | 图搜索+混合检索；LongMemEval +18.5% | "掌握度会变化/遗忘"的学习建模：某知识点"曾掌握→当前薄弱"可带时间戳 |
| **Letta (MemGPT)** | OS 式分层记忆：核心记忆常驻、archival 按需调页，**agent 自己用工具编辑记忆** | 分层检索 | "AI 自我管理学习者档案"的架构参考 |
| **OpenAI Memory** | 2024-02 saved memories；2025-04 可引用全部历史聊天；"**Dreaming**"机制：周期性从聊天史综合沉淀记忆 | 隐式注入 | Dreaming=离线批量整理画像，可借鉴为"夜间整理困惑记录→更新画像→重排复习计划" |

来源：[对比文 1](https://plur.ai/blog/mem0-vs-letta-vs-zep)、[对比文 2](https://www.digitalapplied.com/blog/open-source-agent-memory-mem0-letta-zep-compared)、[OpenAI](https://openai.com/index/chatgpt-memory-dreaming)
**启示**：学习者画像不必发明新轮子——"事实抽取+更新决策"（Mem0 式）记目标与困惑，"时序有效性"（Zep 式）记掌握度衰减，"定期沉淀"（Dreaming 式）做离线整合。

### 4. Andy Matuschak 路线（"Central"证伪）

- "Central / withcentral.com"在 Web 检索、HN 全库、Wayback 中**均无任何可证实记录**；该域名现为停放页（curl 直取确认）。**不存在可验证的 Central 产品**。
- 可证实的最新事实（[andymatuschak.org](https://andymatuschak.org)）：当前焦点为"**一本主动帮读者理解、记住并应用所读内容的增强书**"；2025 下半年起 "para-academic leave"，与 Taylor Rogalski（YC W24 [Pico](https://andymatuschak.org/primer/)，"a conservatory for human attention"）合作。
- **关键实验 "Wizard-of-Oz 学习助理"**（[andymatuschak.org/woz-learning](https://andymatuschak.org/woz-learning)）：他亲自给单一学习者当"人肉 AI 学习助理"，结论：**LLM 写出的常是"形似卡片、实则脱靶"的 prompt，必须靠学习者真实反馈迭代；学习者对 prompt 的"困惑标注"是最高价值的改进信号**。
- 近期研究："机器生成 prompt 的早期工作"（[situated-idea-memory-system](https://andymatuschak.org/situated-idea-memory-system)）；"间隔重复的未来是：把 AI 指向一个材料，得到 prompts"；"读者应能控制收集哪些 prompt"（对作者独裁式预设的修正）。
- **启示**：方向已明——"AI 自动把材料变成检索练习+讲义即记忆媒介+学习者可编辑/可反馈"，且 prompt 质量必须由"学习者卡壳数据"闭环校准。

### 5. 费曼技巧/teach-back 产品化

- 尚无头部大产品把"AI 当困惑学生"做成主形态——**仍有空位的机制**，尤其适合领域学习。

### 6. 角色扮演式学习

- **Duolingo Max**：Roleplay 产出计 XP 并**编入学习路径**；Video Call 角色主动来电，用 "**structured LLM conversations**" 约束对话的适宜性与教学性。来源：[官方博客](https://blog.duolingo.com/video-call/)、[ZenML 案例](https://www.zenml.io/llmops-database/structured-llm-conversations-for-language-learning-video-calls)
- Speak：Learn→Practice→Apply 三段循环+实时反馈。
- Praktika：写实 avatar 一对一，按高频错误定制深练；Univerbal：20+ 语言对话中发音反馈；Character.AI：UGC 语言导师生态，核心价值"零压力练习、无犯错尴尬"。
- **启示**：角色扮演的可迁移内核=①AI 主动发起（来电/追问）降低启动成本；②结构化约束保教学性；③对用户错误的持续跟踪反哺个性化场景；④角色人设制造陪伴感。

## 二、中国市场（重点）

### 8. 网易有道：子曰大模型+硬件

- **子曰**（2023-07，国内首个教育垂域大模型）：首批六大应用=LLM 翻译、虚拟人口语教练、AI 作文指导、**语法精讲**、AIBox、文档问答。
- **Hi Echo 虚拟人口语私教**：多场景一对一；即时对话打分+完整对话报告；2.0 加**难度分级**；3.0 支持**按用户目标设定对话目标**、与雅思官方合作。来源：https://hiecho.youdao.com
- 词典笔 X7 Pro：拍照讲题、作文批改；跟读评分细到**发音/语调/流利度，生成薄弱音素报告**。
- **机制要点**：讲解粒度可下钻到"音素/语法点"级；"报告"把一次练习变成可复查的数据资产。

### 9. 科大讯飞 AI 学习机："精准学"三步闭环（本调研最重要的中国机制）

来源：[讯飞智慧教育](https://edu.iflytek.com/solution/family/learning-pad)、[四色知识图谱实测](https://zhuanlan.zhihu.com/p/2011952759667193604)、[T90 发布](https://edu.iflytek.com/about-us/news/company-news/2665.html)

- **核心闭环"测—学—练"**：
  1. **测（找弱项）**：AI 对话摸底学情+少量针对性习题（**实测约 10 道题即可定位薄弱点**），基于知识图谱与习得顺序推断漏洞；
  2. **可视化诊断**：**四色知识图谱**（红/黄/绿等标注各知识点掌握度），一眼看到"哪里会哪里不会"；
  3. **学（针对性）**：错题 100% 视频讲解+知识点互动微课，**只学薄弱点**（"减负增效"卖点）；
  4. **练（巩固）**：针对弱项推题，形成小闭环。
- **AI 1对1**：以"最近发展区"（ZPD）规划专属路径——先修可学的，跳过太难的。
- **启示**：讯飞把"修图"自动化了——**测验→定位→图谱变色→只学该学的是一台机器内的连续流**，没有任何"规划确认仪式"；"四色图谱"是掌握度可视化的行业标杆形态。

### 10. 学而思学习机：九章大模型

- 九章大模型（MathGPT）：数学垂域（解题/讲题/批改）；首批通过信通院教育大模型评估最高评级。来源：https://www.mathgpt.com
- **"随时问"**（免费）：7×24 拍照即问；**苏格拉底式分步讲题**——不直接给答案，启发式提问引导自己走完推理。
- **风险案例**：2025 年有老用户维权称"AI 精准学"诊断后**错题记录不可追溯、拍照录入的错题无法在机上订正**（[知乎专栏](https://zhuanlan.zhihu.com/p/1925947251831858434)）——**"错题/困惑数据必须可追溯、可回流到学习流"是硬需求，做不好会成公关事故**。

### 11. 作业帮 / 猿辅导

- 作业帮：自研银河大模型+百亿级学情数据 → "AI 超级老师"：模拟真人教学逻辑，**语音自然交互**。来源：[36氪](https://m.36kr.com/p/3044480009816707)
- 小猿学练机：墨水屏+电磁笔；"精准学系统"个性化推题；AI 批改；学情报告；**"智慧拍"错题管理**（拍纸质错题入库）。

### 12. 松鼠AI（近两年动态）

- 纳米级知识点拆分（宣称 3 万个，第三方[质疑](https://zhuanlan.zhihu.com/p/2032702223185097653)）；MCM 三维建模（思维/能力/方法）；**错因分析+遗忘追踪**（错题回溯关联基础知识漏洞，按遗忘曲线追踪复训）；2026-10 央广网报道其"按知识点关联网络而非固定章节推送内容"。来源：[央广网](https://www.cnr.cn/shanghai/tt/20261001/t20261001_527831235.shtml)

### 13. 成人职业考试赛道：粉笔、法考

- **粉笔**：公考垂域大模型+AI 老师"粉笔头"；**申论 AI 老师**（智能批改+学习规划）；**AI 面试对练**——**AI 面试点评用量是人工点评的 20 倍**（规模化陪练的直接证据）。来源：[36氪](https://m.36kr.com/p/3572434401278856)

- **启示**：成人付费意愿锚在"**批改/陪练这两件原来很贵的服务被 AI 打到白菜价**"上，而不是"讲义生成"。

### 14. 大模型 C 端学习功能

## 17. Top 8 可借鉴机制（中外合并）

> 对位图例：【画图】规划知识图 /【学】讲义卡学习 /【测】测验与困惑记录 /【修图】图谱补全拆解 /【巩固】间隔复习 /【动力】单人对话动力系统

1. **Co-STORM 式"圆桌生长图谱"：用过程取代仪式→【画图】**：用"多视角智能体后台对话+动态思维导图"替代三段审批。用户一句话 warm-start，图谱当场开始生长；用户可旁观或随时插话改向；想结束再落库。三阶段从"门禁"降级为"可选停靠点"。
2. **"研究轮"产物必须落成带溯源的结构化素材→【画图】【学】**：学 Gemini→NotebookLM 联动；讲义卡每条关键论断挂来源。
3. **讯飞"测-学-练"少题定位闭环+四色图谱→【测】【修图】【巩固】**：约 10 题定位薄弱点（诊断要便宜）；图用颜色编码掌握度（可视化一眼懂）；只学薄弱点的最近发展区路径（学习要聚焦）。修图从手动操作改为测验数据的自动后果：答错→归因到节点→图谱变色→自动补卡/拆卡。
4. **讲义即记忆媒介：讲义卡内嵌检索练习→【学】【巩固】**：AI 指向材料自动生成 prompts 嵌入讲义正文随读随测；用户可编辑/可拒绝收集（reader control）；用"学习者卡壳/困惑数据"迭代 prompt 质量（WOZ 实验核心教训：不迭代就会产出"形似卡片、实则脱靶"的废卡）。
5. **AI 学生（费曼 teach-back）：把"测"变成"讲"→【测】【动力】**：概念节点上提供"你讲我听"模式：AI 扮演困惑学生追问，从讲解里检测漏洞，漏洞自动写入困惑记录并触发修图。填补单人学习无听众的社交空洞（protégé effect）；市面只有 Blume 等小产品，属空位机制。
6. **双角色：结构化演练+陪伴人设→【学】【动力】**：借 Duolingo Video Call 三件套：AI 主动发起会话（"今天我们过一遍上次卡住的三个概念"）；structured LLM conversations 约束教学性；固定角色人设提供陪伴与连续性。领域学习演练场景=向"虚拟面试官/客户/带教导师"讲解与应答（粉笔 AI 面试验证成人付费意愿）。
7. **记忆框架三件套做跨会话学习者画像→【修图】【巩固】（基础设施）**：Mem0 式"事实抽取+ADD/UPDATE 决策"维护目标/背景/偏好；Zep 式时序知识图谱表达"掌握→遗忘→再学"；OpenAI "Dreaming"式离线沉淀：夜间把本周困惑记录压缩成画像更新并重排复习队列。
8. **低门槛"每天学点啥"+可追溯错题/困惑本→【动力】【测】**：用秘塔模式破掉固定仪式：零输入也能"今天给我上一课"（按画像推荐+一键成课+可选难度/风格）——固定三阶段留给想深度规划的人做成**可选模式**。以学而思事件为戒：困惑/错题记录必须可追溯、可回流、可在学习流内订正。

**落地优先级**：#3（测验驱动修图）与 #7（画像基础设施）是结构性地基；#1、#8 直接消灭"固定仪式"痛点；#4、#5 丰富讲义与测验形态；#2、#6 依次跟进。
