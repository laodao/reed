# 领域学习空间：知识点主序列化（2026-09-08）

## 需求背景

用户问"第 N 课课程是怎么来的？AI 组织还是人设计"。澄清 mock 的"课"只是演示容器后，深入讨论：
- 方法论评估（认知负荷/STORM over-association/Zettelkasten/概念图）：学习单元应=知识点（原子），"课程"降级为导读/总览两种补充。
- 用户确认：**知识点主序列**（一概念一讲义，标题=概念名）+ 依赖图自动排 + 没懂自动拆解；左栏可自由跳学。
- 设计文档新增决策 D8（知识点主序列 + 导读/总览形态）、D9（依赖图自动排 + 拆解）。
