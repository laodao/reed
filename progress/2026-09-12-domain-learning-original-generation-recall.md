## 0. 结论速览

这个功能里存在过**两版**"深度学习"知识点体系，做法完全不同：

| | A. 原型三层大纲版 | B. 真机首版（AI 生成） |
|---|---|---|
| 名称 | 机器学习 · 从基础到深度（含「深度学习」分支） | 学习空间「深度学习」 |
| 时间/位置 | 2026-09-08 前端原型 `mock-data.ts`（commit `704db3ac`，`a7055e06` 去 mock 时删除） | 2026-09-10 12:53 建空间后「生成首批知识」 |
| 规模 | 5 分支 / 14 模块 / **47 个知识点**（progress 旧文写"66 概念"，实为含分支+模块的节点总数 47+14+5=66） | **6 个主干概念** + 5 条前置边 + 1 份 9 区讲义 |
| 生成方式 | 人工写紧凑大纲表 `ML_GROUPS`（分支→模块→[概念, 英文, 类型, 定义]），`buildMlConcepts()`/`buildMlTree()` 展开成概念数组与三层树 | 空空间「领域起步研究」一轮内 S1–S5 生成（不是人写的） |
| 是否入库 | 从未入库（仅前端界面演示数据） | 入库：`dl_concept` / `dl_relation` / `dl_card` |

**共同点（也是"丰富"的真正来源）：先有完整大纲（分层、分模块/分层级），再落内容。**

## 1. A：原型版是怎么"生成"的

`ML_GROUPS` 是一张紧凑表，形如：

```ts
分支 → 模块 → [概念id后缀, 中文名, 英文术语, 类型, 一句话定义]
```

- 5 分支：数学基础 / 监督学习 / 无监督学习 / **深度学习** / 训练与评估；
- 深度学习分支下 3 模块：神经网络基础（感知机、多层感知机、反向传播、激活函数）、卷积网络（CNN、卷积层、池化）、序列与注意力（RNN、LSTM、注意力机制、Transformer）；
- `buildMlConcepts()` 展开为概念数组（`group`=模块名），`buildMlTree()` 展开为 `分支→模块→概念` 三层 `KnowledgeTreeNode[]`；
- 每个节点都有中文名 + 英文术语 + 类型（概念/方法/定理/技术）+ 一句话定义，由人（我）按领域知识拟定。

要点：这版的"体系感"来自**大纲先行 + 三层结构**；它是原型豁免的演示数据，`a7055e06`「前端接线真实数据——三视图去 mock」时随 `mock-data.ts` 一并删除，**没有任何生成路径继承过它的大纲能力**。

## 2. B：真机首版是怎么生成的（可复现证据）

时间线（`agent_trajectories`，空间 id `a13eb877-bf6d-4546-bc43-d08fc010367a`）：

- `12:53:19.876` 建空间「深度学习」（目标：工作应用）；
- `12:53:44.422` 首轮 research 会话（= 用户点「生成首批知识」，空空间）；
- `12:55:56.010` 结束。**约 2 分 12 秒一轮成型。**

触发机制：`dl-agent-harness.service.ts` 仅在 `mode === 'research' && snapshot.isEmptySpace` 时注入空空间起步指令 + `learning-space-bootstrap` 技能正文（由**带工具**的会话执行，绕开 `invoke_skill` 内层无工具的问题）。模型自述（轨迹原文）：

- `S1 · 正在读取资料…` → web_search 连续 HTTP 429，改走 arXiv API +《深度学习》第 2 章原文 + NumPy 广播官方文档 + PyTorch 文档；
- `S2 · 正在整理知识骨架…` *"已读到 3 份可直接引用的资料…现在落库 6 个主干概念到领域根目录"*；
- `S3 · 正在规划学习顺序…` 落 5 条 `prerequisite` 边：张量→自动微分与反向传播；自动微分→梯度下降与优化器；自动微分→多层感知机与激活函数；多层感知机→CNN；多层感知机→注意力机制与 Transformer；
- `S4 · 正在产出讲义…` 给最基础的「张量」出 9 区讲义（读者画像/数学前置/记号热身/可测目标/为什么学它/先例后律的真实形状示例/定义/三类运算规则/落到代码+自测）；
- `S5 · 正在自检…` 数值回算发现链式等式 `32×3×224×224=…` 被误读 → 改成"一步一个二元算式"后重发 v2（12:55:50）。

每个概念都带：一句话定义 + `attrs.evidence`（原文引文，如《深度学习》第 2 章 linear algebra 那句）+ `attrs.practicalUse`；无原文支撑的条目在 attrs / 讲义注记里标「先验待查证」。

## 4. 根因（四条，均有证据）

| # | 根因 | 证据 |

| 1 | **top-down 只发生一次**：起步研究仅在 `snapshot.isEmptySpace` 时注入；之后全是 bottom-up（逐概念研究 + 补地图），而补地图指令明确"本轮只补结构（知识点与前置关系），不改写已有概念、**不产出讲义**" | `dl-agent-harness.service.ts:197`；`src/shared/utils/domain-learning-mission.ts:50` |
