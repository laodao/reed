### 6.3 核心功能亮点

**AI对话（EPIC-001）：**
- 支持4个主流云端模型（通义千问、豆包、GLM、DeepSeek）
- 10+预设角色（IT、设计、文案、视频生成场景）
- 用户自定义角色系统
- 对话历史管理

**多媒体生成（EPIC-002）：**
- 图像生成：通义万项、火山引擎、智谱
- 视频生成：火山引擎
- 流程化创作支持（大纲→角色→场景→生成→导出）

**文档处理（EPIC-003）：**
- OCR：Tesseract-OCR、系统OCR、PaddleOCR
- 语音：火山引擎豆包语音（TTS/STT）
- 翻译：多语言支持

**知识管理（EPIC-004）：**
- 知识库创建与管理
- AI对话集成（RAG）
- 网络搜索

**系统基础（EPIC-005）：**
- 跨平台（Windows、Linux、Mac）
- Electron + Java Spring Boot
- 本地数据库 + 文件存储
