# 应用模块产品交互设计（方案 B：工作流发布为应用）

> 日期：2026-08-19 ｜ 前置讨论：应用=发布单元（来源：工作流/未来 harness），渠道=独立页/API/定时/会话
> 本文档为交互逻辑定稿，配套原型见 pencil 设计稿

## 一、信息架构

```
侧边栏新增「应用」入口（与工作流平级）
└── 应用列表页
    ├── 应用卡片（图标/名称/来源工作流/版本/渠道状态点/运行次数）
    ├── 新建入口 = 从已发布工作流创建（选择器）
    └── 应用详情页（Tabs）
        ├── 概览：基本信息 + 运行统计 + 最近运行记录
        ├── 渠道：四渠道开关与配置
        │   ├── 会话（开关）：开启后可「开始会话」
        │   ├── 分享链接（开关）：生成/重置/停用令牌（复用 C3 分享页）
        │   ├── API（常开）：调用地址/说明，密钥管理（V2）
        │   └── 定时：跳转工作流编辑器的触发器配置（复用 cron）
        ├── 版本：发布历史（v1/v2...，回滚 V2）
        └── 会话记录：该应用下所有会话列表 → 进入会话
```

**关键合并**：工作流编辑器的「发布」按钮升级为「发布」→ 选「仅更新工作流版本」或「同时更新应用」（应用存在时默认双更新）。

## 二、核心用户流程

### 流程 1：首次发布成应用
```
编辑器 → 点「发布」→ 发布成功提示条上出现「发布为应用 →」
  → 点开轻量创建框（预填：应用名=工作流名，图标/描述可选）
  → 创建成功 → 跳转应用详情页（概览 Tab）
```
原则：**不强制建应用**——纯自用自动化（定时/本地跑）的工作流永远不需要碰应用模块；应用是"要分发/要交互"时才出现的概念。

### 流程 2：开启会话渠道并使用（本方案核心增量）
```
应用详情 → 渠道 Tab → 打开「会话」开关
  → 详情页顶部出现「开始会话」主按钮
  → 点击 → 进入会话界面（全屏抽屉或独立页，与 AI 对话同构）
      首条消息 = start 输入表单卡片（有默认值则显示「直接运行」）
      → 用户填表提交 → 卡片折叠为参数摘要 → 运行中状态条
      → form-collect 挂起 → 对话流插入表单卡片（同渲染器）
      → human-review 挂起 → 审核卡片（批准/修改/驳回 | 选择型 | 编辑型）
      → message/report → 助手消息卡片（markdown 渲染 / 长图内联展示）
  → 会话可继续：发新消息 = 携带上次参数重新运行（多轮）
  → 会话记录沉淀在应用的「会话记录」Tab，可随时回看
```

### 流程 3：分享给别人用
```
渠道 Tab → 打开「分享链接」→ 生成链接（复用 C3 免登录页）
  → 复制/二维码（V2）/ 停用（令牌失效）
被分享者：打开链接 → 独立页（已是现状，无需改动）
```

### 流程 4：外部系统调用
```
渠道 Tab → API：展示 invoke/SSE 端点 + 示例 curl
  → 「在 API 文档中打开」（自动生成的调用说明）
```

## 三、会话界面交互细节

### 消息类型（assistant 消息按 metadata 分型渲染）
| 卡片类型 | 触发 | 交互 |
|---------|------|------|
| 启动表单 | 会话首次/用户点「重新运行」 | 动态字段（含文件上传）+「运行」按钮；提交后折叠为参数摘要 |
| 运行状态条 | startRun 后 | 节点进度（运行中/完成/失败），实时刷新；失败显示错误+「查看详情」（跳运行详情页） |
| 表单卡片（中途） | form-collect 挂起 | 同启动表单渲染器；提交/取消（走 reject 边） |
| 审核卡片 | human-review 挂起 | 三模式：批准/修改后批准(JSON编辑)/驳回；choose=选项按钮；input=编辑框 |
| 结果卡片 | message/report/report-image | markdown 渲染；长图内联；docx/pdf 附件下载链接；「查看运行」链接 |

### 状态与边界
- 同一工作流互斥：运行中再发消息 → 提示「当前运行进行中」+ 排队/取消选择（沿用引擎互斥=skipped 语义，改为前端引导）
- 挂起超时：卡片显示倒计时，超时后卡片置灰标注策略结果
- 应用停用（下线）：会话渠道关闭后现有会话变只读；分享链接即刻失效；API 返回 404
- 工作流被删除：应用详情页提示「源工作流已删除」，应用转为只读，可导出历史运行

## 四、导航与入口总览
- 侧边栏「应用」（新）
- 工作流编辑器「发布」成功后的引导入口（新）
- 应用详情「开始会话」（会话渠道开启后）
- AI 对话模块：**不改动**（助手体系保持原样）

## 五、V1 范围裁剪（防过度设计）
做：应用列表/详情（概览+渠道+会话记录）、发布即建应用的引导、会话渠道（表单/审核/结果卡片）、分享/API 归位到应用
不做（V2+）：版本回滚、API 密钥管理、二维码、应用模板市场、多人协作权限
