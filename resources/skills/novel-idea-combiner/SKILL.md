## 任务输入

- 方向 / 已有设定：{{param.direction}}
- 产出方向数：{{param.count}}
- 频道：{{param.channel}}

## 方法：两层结构

素材库分两层，使用时严格区分：

1. **素材层**：人物性格、人物身份、关系、金手指、世界观、冲突、题材元素、高频场景、看点爽点九大分类（见 `references/material-library.md`）。素材层不追求"看起来很怪"，而追求覆盖面足够全。
2. **组合层**：把素材层元素重新组合成有反差、有梗、有剧情推动力的设定。

核心原则：**素材阶段要尽量全，组合阶段才追求巧。创新发生在组合阶段，不在罗列阶段。**

## 何时读 references

references 下的素材库会在执行时全量加载，直接使用即可，重点场景：

1. 用户只给了模糊方向，需要发散题材或设定。
2. 用户要求"更抓人""更爆""更狗血""更爽""更下沉""更有新意"。
3. 用户要求设计人物、身份、CP、冲突、爽点、虐点、反转、悬念。
4. 用户要求多个方向、多个设定、多个开篇或多个卖点版本。

使用时必须重组和创新，不能机械照搬条目；**用户已有明确设定时，以用户设定为主，素材库只做补强，不覆盖。**

## 有效组合公式（七槽位）

每个创意方向必须填满七个槽位：

**题材入口 + 常见身份 + 反差规则 + 稳定误判 + 反复应验 + 持续梗 + 主线用途**

示例（女频）：题材入口=豪门；常见身份=玄学大师真千金；反差规则=豪门全家不信玄学，但她每次预警都应验；稳定误判=所有人以为她是乡下骗子；反复应验=她说老宅不能住，当晚祠堂出事；持续梗=嘴硬长辈每次都躲她身后；主线用途=通过玄学事件揭开豪门借命旧案。

## 有效组合六问

每个组合必须能回答：

1. 这个设定能不能引发剧情？
2. 这个身份能不能反复使用？
3. 这个金手指能不能制造误解、反差、打脸或悬念？
4. 这个世界观能不能带来持续冲突？
5. 这个人物设定能不能推动关系变化？
6. 这个梗能不能在前 10 章至少变体出现 3 次？

## 组合自检（12 条）

每个方向输出前逐条自检，不合格的回炉：

1. 这个设定是否只停留在简介里？
2. 这个身份能不能反复制造剧情？
3. 有没有稳定误判？
4. 有没有反复应验？
5. 有没有持续梗？
6. 有没有推动主线？
7. 有没有明确爽点、甜点、虐点、燃点或悬念点？
8. 这个组合是否服务人物关系变化？
9. 男频是否有升级、资源、势力、战斗、格局扩张？
10. 女频是否有情绪、关系、身份、处境、选择变化？
11. 是否避免了"硬凹怪概念"？
12. 是否做到"常见元素，新鲜用法"？

## 输出结构

按输入的产出方向数，给出差异化组合方案。每个方向包含：

1. **一句话定位**：题材入口 + 核心反差。
2. **七槽位拆解**：完整填出组合公式。
3. **六问回答**：逐条简答，答不出的槽位标出并补改。
4. **前三章看点**：该组合在前三章如何兑现第一个钩子与第一个爽点。
5. **自检结论**：12 条自检的通过情况，不通过的项说明修正方式。

## 与本系统的衔接

- 创意成果落地为长文写作模块的结构化资产：全书概要写入 `lw_story_overviews`、人物写入 `lw_story_characters`、情节骨架挂到大纲树 `lw_story_outlines` 节点；或作为故事研讨室"故事核阶段"的候选卡片，进入研讨室共识流程。
- 组合自检 12 条可并入章节设计卡自检的创意维度——与 R1-R10"不矛盾"一致性门禁互补：R1-R10 管"前后不冲突"，本自检管"够不够抓人"。

## 交付与门禁

- 当创意提案作为落盘交付物（markdown 文档）产出时，使用 `node scripts/creative-run-gate.cjs` 做阶段门禁与交付前校验，按 init → enter → accept → check → validate 流程推进；校验不通过时不得声称完成。
- 交付物缺少核心板块（七槽位拆解 / 六问 / 自检结论）、含占位符，或泄露内部检查过程/门禁日志时，不得回复"已完成"，必须先补齐或修正。
