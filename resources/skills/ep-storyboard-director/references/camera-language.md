# 镜头语言速查（枚举 key 以本系统 EP 管线为准）

## 1. 景别 shotType（8 档，JSON 必须用 key）

| key | 中文 | 定义与情绪指向 |
|---|---|---|
| `extreme_long` | 大远景 | 人物几乎成一个点，渲染宏大环境，史诗感开场/结尾 |
| `long` | 远景 | 人物占比小，环境为主体，表现渺小、孤独 |
| `full` | 全景 | 人物全身+小范围环境，交代完整动态 |
| `medium` | 中景 | 膝盖以上，对话场景、人物互动关系 |
| `medium_close` | 中近景 | 腰部以上，常用对话档，表情+肢体兼顾 |
| `close` | 近景 | 胸部以上，聚焦表情，拉近心理距离 |
| `extreme_close` | 特写 | 面部（头肩），传递强烈情绪 |
| `detail` | 大特写 | 眼/唇/手部极小细节，放大极致情绪、强调重点道具 |

## 2. 镜头运动 cameraMovement（15 种，JSON 必须用 key）

**固定与摇动**：`static` 固定镜头 | `pan_left` 左摇 / `pan_right` 右摇（水平巡视、扫视群像） | `tilt_up` 上仰 / `tilt_down` 下俯（垂直摇镜）。

**推拉变焦**：`dolly_in` 推镜头（聚焦细节、关键决定前、发现线索） | `dolly_out` 拉镜头（揭示环境、结尾疏离感） | `zoom_in` 变焦推进 / `zoom_out` 变焦拉远。

**升降与平移**：`crane_up` 升镜头 / `crane_down` 降镜头（宏伟或压抑，地面升至上帝视角） | `tracking_left` 左移 / `tracking_right` 右移（轨道平移，跟随行走，空间感与沉浸感）。

**手持与稳定器**：`handheld` 手持晃动（纪实感、紧迫感，追逐/混乱人群） | `steadicam` 稳定器跟随（平滑跟随、长镜头调度）。

**导演级意图速记**：推=聚焦/紧张；拉=揭示/疏离；摇=巡视/跟随；移=空间沉浸；升降=宏伟/压抑；手持=纪实紧迫；steadicam=平滑流动。特殊效果类（希区柯克变焦、子弹时间、甩镜）AI 视频生成不稳，非必要不用；用时写在画面描述里。

## 3. 镜头角度 cameraAngle（6 种，JSON 必须用 key）

| key | 中文 | 功能 |
|---|---|---|
| `eye_level` | 平视 | 客观中立，常规叙事 |
| `high` | 俯拍 | 主体渺小弱势，受挫或全局环境 |
| `low` | 仰拍 | 主体高大威严，反派嚣张或主角觉醒 |
| `dutch` | 荷兰角 | 不安、混乱、失衡 |
| `birds_eye` | 鸟瞰 | 正上方全局视角 |
| `worms_eye` | 虫视 | 极度仰拍 |

**主体朝向**（非枚举，写进画面描述与 facing）：正面（情绪爆发、重要台词）/ 侧面（轮廓、双人交锋、思考观察）/ 半侧面 3/4（最常用，表情+立体感）/ 背面（神秘疏离、引导视线、离开）。

## 4. 转场 transition.type（8 种，JSON 必须用 key）

`cut` 硬切 | `fade` 淡入淡出 | `dissolve` 叠化 | `wipe` 划像 | `slide` 滑动 | `zoom` 缩放转场 | `iris` 圈入圈出 | `whip` 甩镜头转场（高速场景连接，生硬快速）。

## 5. 光影与色调词表（写进 frameDescription【氛围】段）

- **光线质感**：硬光（轮廓分明、冲突感）/ 柔光（干净治愈）/ 伦勃朗光（肖像三角光斑）。
- **光线方向**：顺光 / 侧光（强明暗对比）/ 逆光（金色轮廓、剪影）/ 底光（恐怖悬疑）。
- **色调风格**：低饱和（内敛忧郁）/ 冷色调（悬疑、赛博）/ 暖色低饱和（治愈）/ 复古胶片颗粒（港风怀旧）/ 高级暗调（独立文艺）。

## 6. 情绪具象外化词库（禁用抽象情绪词）

- **悲伤**：低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪水在眼眶里打转。
- **喜悦**：嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快。
- **紧张/焦虑**：频繁看手表、手指不停敲击桌面、呼吸急促、无意识啃咬指甲。
- **愤怒**：双拳紧握、下颔线紧绷、胸口剧烈起伏、眼神如刀、从牙缝里挤出话语。
- **释然**：长长舒一口气、紧绷的肩膀完全放松、脸上露出淡淡的微笑。

## 7. 视角类型（写在镜头方括号第二元）

- **第三人称客观视角**：交代站位、动作结果、环境关系，多数叙事镜头用此。
- **POV 第一人称视角**：必须注明所属角色（"林远 POV"）；从眼睛高度出发，写清视线方向、前景手部/道具/衣袖；不能出现该角色完整正脸。
- **POV 与第三视角切换**：先 POV 建立代入，再切第三人称交代动作结果；切换处服装/道具/光影/锚点必须连续。需要过肩镜头就写"过肩镜头"，不要写 POV。
