## 澄清（动笔前）

确认或默认：题材类型、单集总时长（默认 6 分钟）、剧作基调（取 {{param.tone}}）、目标受众与情绪价值、主角身份与核心动机、中心冲突与对立力量、结局方向、禁用边界。用户只给模糊 idea 时问 1-3 个最关键问题；用户说"你来定"时选合理默认值并继续。

### 长篇幻觉风险声明（集数 >10 时强制前置）

集数超过 10 集时，必须先一次性向用户声明剧情漂移与人设漂移风险（伏笔遗忘、动机前后不一、道具/场景连贯性失守），声明模板：

> 提示：您要求生成 N 集完整剧本。当集数超过 10 集时，模型可能出现剧情或人设漂移（例如伏笔遗忘、角色动机前后不一、关键道具/场景失守）。生成过程中如发现矛盾，请随时指出，我会针对该处回填校正或整段重写。

用户确认后继续；产物四改为**分批输出、逐批确认**：每批 3-5 集（单集 ≤3 分钟可 5 集/批，≥5 分钟建议 3 集/批），首批在剧本头后立即复述声明，每批开头标注 `## 第 N 批：第 X 集 - 第 Y 集` 并复述上批关键事件与伏笔，每批结尾标注 `【伏笔待回收：XXX（预计第 X 集）】`，收到确认后才输出下一批。

## 四段产物契约（缺一不可，按序输出，段间 `---` 分隔）

### 产物一：剧情梗概（约 1500 字）

单一连贯叙事文本，3-5 个自然段落对应起承转合；必须包含主角核心动机、反派具体阻挠手段、主角关键抉择、结局形态。长篇（>10 集）梗概只覆盖全剧主线，另附**分集大纲表**（集号/集名/核心事件/情绪节拍/关键伏笔·回收），作为每集剧本的锚点。

### 产物二：人物小传

至少覆盖主角、配角、反派三类，每位一段：

```markdown
#### [角色名]（[主角 / 配角 / 反派]）
- **一句话定位**：[年龄 + 身份 + 关键人设标签]
- **性格**：[3-5 个具体性格特质，用行为倾向描述，避免抽象形容词]
- **动机**：[核心动机 + 底层驱动力（欲望/恐惧/执念）]
- **成长弧线**：[开场状态 → 中段动摇/受挫 → 结局蜕变，写清转折触发事件]
- **视觉方向**：[形象、气质与识别符号的大方向]
- **关键道具/记忆点**：[标志性物件或行为习惯]
```

反派必须额外写清：**合理性动机**（为什么这样做，避免脸谱化）与**惩罚落点**（剧中如何得到实质惩罚或明确失败）。微电影向允许对立面象征化（"父亲的沉默""褪色的门牌"），惩罚落点可写为象征性"打脸"。

**下游用途**：本清单是本系统 EP 管线 **character binding（角色绑定）的登记源**。角色名将作为资产名册的登记名，后续分镜、关键帧、视频生成全程以此名字引用，一字不差；角色名一旦定稿不要中途改名。

### 产物三：主要故事场景清单

短篇（≤10 集）核心场景 **2-4 个**；长篇（>10 集）**4-8 个**（次要场景也需登记）。格式：

```markdown
| 场景编号 | 场景名称 | 场景类型/功能 | 空间概念方向 | 情绪氛围基调 | 叙事性关键陈设 | 常见时间/内外景 |
|---|---|---|---|---|---|---|
| S01 |  | [主场景/次场景/回忆场景/梦境] | [材质/体量/光源/时代感大方向] | [压抑/温暖/悬疑…] | [与伏笔/反转直接相关的物件] | [日 内 / 夜 外 / …] |
```

**下游用途**：本清单是 EP 管线 **location binding（地点绑定）的登记源**，也是产物四场次表头 `场景名` 的唯一取用来源。

**场景血缘规则（强制）**：完整剧本每场戏的表头 `场景名` 必须严格取自本清单、一字不差；剧情确需新增场景时，先暂停剧本创作，回填本清单并说明必要性，再继续。场景登记不足（如短篇只有 1 个）时先补齐再动笔。

### 产物四：完整剧本（分集分场专业格式）

剧本头（每部剧本开头一次）：

```markdown
《[剧本标题]》
类型：[短篇短剧 / 微电影 / 剧情短片 / 动画短片 / 广告剧情 / 长篇短剧]（长篇注明总集数）
风格：[某某风格的电影 / 3d玄幻 / 2d水墨 等，取 {{param.style}}，禁止留白式写法]
标签：[题材关键词 + 情感关键词]
人设：[一句话高浓缩人设对撞]
单集时长：[X 分钟]  |  剧作基调：[微电影三幕式 / 短视频钩子驱动]
```

**风格字段硬约束**：无非真人强信号（用户直接指定画面形式，或内容无法真人拍摄）时默认走真人电影，写"某某风格的电影"，从 `references/style-anchors.md` 六大流派选 1 位大师；禁止写"影视级布光""电影风格""高级质感"等模糊表述。题材本身（仙侠/玄幻/科幻）不构成非真人信号。锚点一旦确定，后续资产、关键帧、prompt 阶段一字不差沿用。

场次格式：

```markdown
第X集

X-Y 场景名 日/夜 内/外
人物：角色A、角色BVO
△（景别提示）客观可拍的动作/调度/道具状态描述，不写心理活动，情绪通过动作外化。
角色A:（简短情绪/动作提示）台词内容
角色BVO: 旁白内容
【节拍：开场钩子/破冰/反转/爽点释放/悬念揭示/情感闭环…】
```

- 场次编号 `X-Y`（X=集号，Y=集内场次序号）；场景表头 = `场次编号 场景名 [日/夜] [内/外景]`。
- 对白 `角色名: 台词`；旁白 `角色名VO: 内容`；动作提示以 `△` 起首。
- **角色/场景/道具命名强一致**：剧本中所有角色、场景、道具统一使用产物二/产物三中登记的名称，与 EP 管线资产名册（binding）一字不差，禁止中途使用代词或别称替代角色名。
- **情绪节拍标记并存规则**：`【节拍：XXX】` 标记关键台词/动作的情绪节拍；本系统分集大纲纪律的 `【开场钩子】` `【本集爽点】` `【集尾卡点】` 三个系统标记与本标记并存——大纲级用系统标记（每集各一处），场次级用 `【节拍：】`。大纲标注的开场钩子/爽点/卡点必须如实落地，不得弱化或挪移；集尾卡点切在问题上，不切在答案上。
- 台词口语化短句（每句 ≤20-30 字），每场三句对白内浮出冲突。

**样例（微电影向，压缩版）**：

```markdown
1-1 旧公寓门口 日 外
人物：林远
△（远景）林远背对镜头推开吱呀作响的木门，停在门框中央三秒。
林远VO：父亲走后的第七天，我第一次踏进这里。【节拍：开场钩子】

1-3 旧公寓客厅 日 内
人物：林远
△（林远 POV，俯拍）书架下层，前景是林远的左手，深棕色铁盒静置层板中央。
△（大特写）铁盒表面浮出微小光斑，盒内传出规律的滴答声。【节拍：悬念揭示】
```

## 单集章节结构

每集切分 3-5 个叙事章节（6 分钟≈4 章节约 90 秒/章）。章节层不写进剧本正文，由场次排列顺序承担；在梗概或分集大纲中标注"第一章 场次 1-1 至 1-3…"映射，供分镜阶段切分对齐。章节功能分配：微电影三幕式 = 铺陈 20-25% → 冲突 40-50% → 高潮落点 25-30%；钩子驱动 = 钩子+铺垫 15-20% → 压迫蓄力 30% → 暴露/打脸 30% → 清算释放 20-30%。

## 写作法则

按 {{param.tone}} 选用 `references/writing-rules.md` 中的 A 组（短剧向）或 B 组（微电影向）法则；题材与受众心理速查同见该文件。铁律（两组通用）：短剧向黄金开局（前 15-30 秒抛核心矛盾）、反派当集实质惩罚；微电影向单一核心事件、允许留白、落点优先情感闭环。

## 与本系统管线的衔接

- 四段产物确认后，完整剧本正文流入 EP 管线 narrative 环节，由 `script-generator` 拆分为 **scene-script 实体**（结构化 JSON 场景：location/characters/dialogues/actions）。
- 产物二人物小传 = **character binding 名册登记源**；产物三场景清单 = **location binding 名册登记源**。拆分阶段按名册名称回退匹配 bindingId，所以名册登记名必须与剧本正文用词一字不差。
- 场景拆分会为每场填 `locationBindingId` / `characterBindingId` / `itemBindingId`；剧本中凭空出现的未登记角色/场景会导致 binding 落空（validator 标违例，需人工补绑）。
- 分集大纲中的 `【开场钩子】【本集爽点】【集尾卡点】` 会随 summary 流入章节生成纪律，剧本必须如实落地。
- 剧本头 `风格` 字段是全链路风格锚点，关键帧与视频 prompt 阶段会一字不差引用，禁止留白式写法。
