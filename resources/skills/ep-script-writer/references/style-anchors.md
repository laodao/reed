# 风格锚点库（剧本头"风格"字段取值参考）

## 风格路径判定

- **切换到"非真人"仅两条强信号**（命中任一即可）：①用户直接指定画面形式（3D/2D 动画/水墨/国漫/赛璐璐/绘本/皮克斯/毛毡定格/粘土动画等）；②内容本身无法真人拍摄（非人形主角、极端抽象、低龄绘本）。**题材本身（仙侠/玄幻/科幻/古风）不构成非真人信号**——《仙剑》《三体》《银翼杀手》皆为真人。
- **无非真人强信号时默认真人电影**：风格写"某某风格的电影"，从下方六大流派选 1 位大师；用户点名大师则一字不差沿用；一位大师有多个风格阶段可追加代表作限定（如"王家卫《花样年华》风格的电影"）。
- **模糊时主动澄清**画面形式偏好；实在无法推断默认 `是枝裕和风格的电影`。
- **非真人路径**：用动画流派锚点（京都动画风格/吉卜力风格/上美影水墨风格等），不套真人电影写法。

## 真人电影六大流派

### 一、东方生活流 / 家庭治愈
- **是枝裕和**：家庭日常、柔和自然光、餐桌戏、克制的情感高潮。
- **李安（早期华语时期）**：东方伦理细腻笔触、温润暖色、克制张力。
- **侯孝贤**：长镜头+自然光+生活流、少切镜多定机。
- **岩井俊二**：青春过曝、逆光空气感、蓝白清冷色、手持轻晃。

### 二、港风霓虹 / 怀旧胶片
- **王家卫**：手持慢速快门拖影、高饱和红绿蓝、暗调霓虹、偷窥式构图。
- **杜可风摄影美学**：低机位广角、失焦前景、绿光橙光对撞。
- **贾樟柯**：华北乡镇现实主义、纪实手持、宽银幕生活流、灰蓝色调。

### 三、极简对称 / 高饱和作者美学（广告剧情/品牌微电影/亮相戏）
- **韦斯·安德森**：绝对对称构图、马卡龙高饱和色板、章节化标题卡、正前方 push in。
- **保罗·托马斯·安德森（PTA）**：70 年代复古胶片、缓慢 zoom in、长镜头调度。
- **昆汀·塔伦蒂诺**：章节化叙事、复古 grindhouse、高饱和美学。

### 四、极简冷冽 / 精密构图（悬疑/高级暗调）
- **大卫·芬奇**：低调冷灰、精密对称构图、数字感质感、长焦压缩空间。
- **斯坦利·库布里克**：一点透视对称、缓慢推轨、冷冽疏离、广角低机位。
- **罗杰·迪金斯（摄影）**：极简大远景、逆光剪影、天光/落日美学。
- **克里斯托弗·诺兰**：IMAX 大远景+手持贴脸特写、冷冽金属感、宏大调度。

### 五、诗性自然 / 影展作者
- **泰伦斯·马利克**：广角低机位、麦浪金黄、诗性 VO、斯坦尼康移动。
- **阿彼察邦·韦拉斯哈古**：东南亚湿热气息、神秘长镜头、超现实梦境。
- **河濑直美**：日式生态叙事、山林光影、克制诗意。

### 六、社会现实主义 / 纪实感
- **达内兄弟**：手持贴身跟拍、社会边缘人物、原生光、几乎无配乐。
- **肯·洛奇**：英式工人阶级现实主义、素人演员、纪实自然对白。
- **贾樟柯（纪实向）**、**锡兰**（土耳其乡野人物志）可延伸。

## 题材/情绪 → 大师速查

治愈家庭→是枝裕和；青春逆光→岩井俊二；怀旧年代→王家卫/贾樟柯；极简对称广告→韦斯·安德森；悬疑独立文艺→大卫·芬奇/库布里克；社会议题→达内兄弟/肯·洛奇；影展诗意→马利克/阿彼察邦；赛博朋克科幻→雷德利·斯科特（《银翼杀手》）或非真人"赛博朋克风格"。

## 非真人动画流派（命中非真人强信号时使用）

- **3D 玄幻/3D 国风**：仙侠玄幻修真题材的三维写实路线。
- **2D 水墨/上美影水墨风格**：国画晕染、留白构图。
- **京都动画风格/2D 日漫赛璐璐**：细腻日常、柔光。
- **吉卜力风格**：手绘自然、温暖生活流。
- **皮克斯风格/毛毡定格/粘土动画**：低龄童话、绘本质感。
