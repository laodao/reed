## 2. 架构决策
- **挂载点**：`/episode-production` 路由重定向到新版首页；`/episode-production/:projectId/...` 全部新版。新版模块前缀重命名避免与旧版冲突（旧版组件/路由暂保留，通过 `legacy` 入口访问）。
- **三段式业务布局统一**：每个业务页面（剧本/资产/分镜/合成）都是「**左侧树/列表 + 中央工作区 + 右侧 agent 面板**」。右侧 agent 面板是**通用组件**（`EpAgentPanel`），context 感知（当前剧集/场景/角色），复用已建好的 `EpisodeProductionAgentService` 后端。
- **不做大顶栏**：业务页面的顶部导航（左上标题/右上操作按钮）做成**页面内轻量工具条**，样式贴合当前 El 主题。
- **首页即项目列表**：参考「导入剧本 + 最近项目」，替代现有 `EpisodeProjectListV2` 作为菜单真实入口。
- **agent 是全模块横向能力**：不是每页各建一个，而是**一个通用右侧面板**，通过 context（当前 tab + 当前选中对象）决定它调哪些动作、展示什么。

### M7 关键设计（用户确认：合并为全局任务中心）
- **不是**剧集制作私有的任务队列，而是**全应用任务中心**。
- 两类任务对象统一注册：
  1. **工作流运行**（含 cron/事件定时/手动触发）→ 任务对象，状态复用 `workflow_runs`（pending/running/succeeded/failed/waiting_review/...）。
  2. **剧集制作生成任务**（剧本/分镜/定妆/合成）→ 任务对象，写同一注册表。
- **怎么启动仍留在各自模块**（workflow 的 trigger/scheduler 不动；剧集生成在生成服务里），任务中心只通过**事件订阅**汇总状态 + 进度，不重复造调度。
- 三桶：进行中 / 已完成 / 已清除；下方「任务流量」实时流水。
- 阶段 D 落地：届时先接 workflow 运行（现成 `wf:run-event` + `wf:list-runs`），再接入剧集生成任务（新增任务注册表 + 生成服务上报）。
