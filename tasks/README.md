## 任务执行流程

### 每个任务的执行步骤

1. **开始任务**
   - 将任务状态更新为进行中
   - 阅读任务描述和实现要点

2. **实现代码**
   - 创建/修改指定文件
   - 遵循项目代码规范

3. **验证结果**
   - 运行应用检查界面/功能
   - 确保满足完成标准

4. **完成任务**
   - 更新任务状态为已完成
   - 记录任何问题或注意事项

### 验证检查清单

每个任务完成后，需要验证：

- [ ] 代码编译无错误
- [ ] 应用启动正常
- [ ] 功能符合需求
- [ ] 界面显示正确（如适用）
- [ ] 无控制台错误
