# 消息操作功能实施计划

## 功能概述

参考 Cherry Studio，为对话消息增加以下操作功能：

### 1. 代码块增强
- **复制按钮**：代码块右上角增加复制图标，点击复制代码内容到剪贴板
- **行号显示**：代码块左侧显示行号

### 2. 用户消息操作
- **编辑**：编辑已发送的消息内容
- **复制**：复制消息内容到剪贴板
- **删除**：删除该条消息

### 3. AI 回答操作
- **重新回答**：使用相同模型重新生成回答
- **换模型重答**：选择其他模型重新生成回答
- **复制**：复制回答内容到剪贴板
- **删除**：删除该条回答（同时删除对应的用户消息？）

## 技术要点

### 代码块行号实现
```vue
<template>
  <div class="code-block">
    <div class="code-header">
      <span class="language">{{ language }}</span>
      <el-button @click="copyCode" size="small" text>
        <el-icon><CopyDocument /></el-icon>
      </el-button>
    </div>
    <div class="code-content">
      <div class="line-numbers">
        <span v-for="n in lineCount" :key="n">{{ n }}</span>
      </div>
      <pre><code>{{ code }}</code></pre>
    </div>
  </div>
</template>
```

### 消息编辑流程
1. 点击编辑按钮
2. 显示编辑框（textarea）
3. 用户修改内容
4. 点击保存
5. 调用 `updateMessage(messageId, newContent)`
6. 如果需要，删除后续 AI 回答
7. 重新发送请求获取新回答

### 重新回答流程
1. 点击重新回答按钮
2. 找到该 AI 回答对应的用户消息
3. 删除当前 AI 回答
4. 重新发送用户消息
5. 显示新的 AI 回答
